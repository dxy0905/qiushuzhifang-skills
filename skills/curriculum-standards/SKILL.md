## 一、课程性质

**数学的定义：** 数学是研究数量关系和空间形式的科学。数学源于对现实世界的抽象，通过对数量和数量关系、图形和图形关系的抽象，得到数学的研究对象及其关系；基于抽象结构，通过对研究对象的符号运算、形式推理、模型构建等，形成数学的结论和方法。

**数学的三大功能：**
1. **运算和推理的工具**
2. **表达和交流的语言**
3. **承载思想和文化，人类文明的重要组成部分**

**数学课程定位：**
- 数学是自然科学的重要基础
- 义务教育数学课程具有**基础性、普及性和发展性**
- 数学素养是现代社会每一个公民应当具备的基本素养

**2011版→2022版/2025修订的关键升级：**
- "双基"→"四基"（基础知识、基本技能、**基本思想、基本活动经验**）
- "两能"→"四能"（分析问题、解决问题 → **发现问题、提出问题、分析问题、解决问题**）
- 新增核心素养导向

## 三、课程目标

### （一）核心素养内涵

核心素养具有**整体性、一致性和阶段性**，在不同阶段具有不同表现。

**核心素养14个主要表现（2025修订版表1完整）：**

| 表现 | 学段 | 核心内涵 |
|:-----|:----|:---------|
| **数感** | 小学 | 对数与数量、数量关系及运算结果的直观感悟 |
| **量感** | 小学 | 对事物的可测量属性及大小关系的直观感知 |
| **符号意识** | 小学 | 感悟符号的数学功能 |
| **抽象能力** | 初中 | 从现实世界中抽象得到数学研究对象的能力 |
| **运算能力** | 小学+初中 | 根据法则和运算律进行正确运算的能力 |
| **几何直观** | 小学+初中 | 运用图表描述和分析问题的意识与习惯 |
| **空间观念** | 小学+初中 | 对空间物体或图形的形状、大小及位置关系的认识 |
| **推理意识** | 小学 | 对逻辑推理过程及其意义的初步感悟 |
| **推理能力** | 初中 | 从事实和命题出发推出其他命题或结论的能力 |
| **数据意识** | 小学 | 对数据的意义和随机性的感悟 |
| **数据观念** | 初中 | 对数据的意义和随机性有比较清晰的认识 |
| **模型意识** | 小学 | 对数学模型普适性的初步感悟 |
| **模型观念** | 初中 | 对运用数学模型解决实际问题有清晰的认识 |
| **应用意识** | 小学+初中 | 用数学的概念与方法解释现实世界的意识 |
| **创新意识** | 小学+初中 | 发现和提出有意义的数学问题的意识 |

**2025修订亮点：** 小学11个表现（数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识、数据意识、模型意识、应用意识、创新意识），初中9个表现（抽象能力、运算能力、几何直观、空间观念、推理能力、数据观念、模型观念、应用意识、创新意识）。

### （二）总目标

通过义务教育阶段的数学学习，学生逐步：
1. **会用数学的眼光观察现实世界**（数学抽象）
2. **会用数学的思维思考现实世界**（逻辑推理）
3. **会用数学的语言表达现实世界**（数学模型）

总目标可概括为：获得"四基"（基础知识、基本技能、基本思想、基本活动经验），发展"四能"（发现问题、提出问题、分析问题、解决问题的能力），形成正确的情感、态度和价值观。

### （三）学段目标

| 学段 | 年级 | 数与代数 | 图形与几何 | 统计与概率 | 综合与实践 |
|:----|:-----|:---------|:-----------|:-----------|:----------|
| 一 | 1-2 | 整数认识、加减法 | 图形认识、分类 | 数据分类 | 主题活动 |
| 二 | 3-4 | 四则运算、分数初步 | 测量、图形性质 | 数据整理 | 项目学习 |
| 三 | 5-6 | 小数分数百分数、比例 | 几何形体、变换 | 概率初步 | 跨学科项目 |
| 四 | 7-9 | 代数式、方程、函数 | 证明、推理 | 统计概率系统 | 综合实践 |

详见各章文件。

## 五、学业质量

### （一）学业质量内涵

学业质量是学生在完成课程阶段性学习后的学业成就表现，反映核心素养要求。学业质量标准是以核心素养为主要维度，结合课程内容，对学生学业成就具体表现特征的整体刻画。

### （二）学业质量描述

| 学段 | 质量标准要点 |
|:----|:-------------|
| 第一学段（1-2） | 能进行简单整数运算，认识常见图形，能数据分类 |
| 第二学段（3-4） | 能进行四则运算，认识分数，掌握基本测量技能 |
| 第三学段（5-6） | 能解决小数分数百分数问题，认识几何形体，能表达可能性 |
| 第四学段（7-9） | 能运用代数、几何、统计概率知识解决实际问题，具备初步推理和建模能力 |

## 六、课程实施

### （一）教学建议

1. **制订指向核心素养的教学目标**
2. **整体把握教学内容**
3. **选择能引发学生思考的教学方式**
4. **发挥评价的育人导向作用**
5. **充分利用现代信息技术**

### （二）评价建议

- 评价维度：核心素养的达成情况
- 评价方式：纸笔测试 + 表现性评价 + 过程记录
- 评价主体：教师评价 + 学生自评 + 同伴互评

### （三）教材编写建议

- 体现核心素养导向
- 遵循学生认知规律
- 注重内容的整体性和结构性
- 融入数学文化与信息技术

### （四）课程资源开发与利用

- 文本资源
- 信息技术资源
- 社会教育资源
- 环境与工具资源

### （五）教学研究与教师培训

- 校本教研
- 区域教研
- 网络教研
- 教师专业发展

|:-----|:---------|:-----|
| 了解（知道/认识） | 了解、知道、认识、识别 | 从具体事例中知道或举例说明对象的相关特征 |
