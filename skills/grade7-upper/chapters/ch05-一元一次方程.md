# 第五章 一元一次方程

## 核心内容

本章从方程的概念出发，学习等式的性质，掌握一元一次方程的解法，并运用方程解决实际应用问题，建立方程思想。

## 各节知识点

### 5.1 从算式到方程

- **方程**：含有未知数的等式
- **一元一次方程**：只含有一个未知数（元），未知数的次数都是 $1$，等号两边都是整式的方程
  - 一般形式：$ax + b = 0$（$a \neq 0$）
- **解方程**：求方程的解的过程
- **方程的解**：使方程中等号左右两边相等的未知数的值

### 5.2 等式的性质

- **性质1**：等式两边同时加（或减）同一个数（或式子），结果仍相等
  - 如果 $a = b$，那么 $a \pm c = b \pm c$
- **性质2**：等式两边同时乘同一个数，或除以同一个不为 $0$ 的数，结果仍相等
  - 如果 $a = b$，那么 $ac = bc$
  - 如果 $a = b$（$c \neq 0$），那么 $\frac{a}{c} = \frac{b}{c}$

### 5.3 解一元一次方程

**一般步骤**：

| 步骤 | 操作 | 依据 |
|------|------|------|
| 1. 去分母 | 方程两边乘各分母的最小公倍数 | 等式性质2 |
| 2. 去括号 | 去括号法则 | 乘法分配律 |
| 3. 移项 | 把含未知数的项移到一边，常数项移到另一边 | 等式性质1 |
| 4. 合并同类项 | 合并同类项 | 乘法分配律逆用 |
| 5. 系数化为1 | 两边同除以未知数的系数 | 等式性质2 |

**移项注意事项**：
- 移项要变号
- 通常把含未知数的项移到左边，常数项移到右边

### 5.4 实际问题与一元一次方程

**常见模型**：

#### (1) 行程问题
- 基本关系：$s = v \times t$（路程 = 速度 × 时间）
- 相遇问题：$s_甲 + s_乙 = s_总$
- 追及问题：$s_快 - s_慢 = s_距$

#### (2) 工程问题
- 基本关系：工作量 = 工作效率 × 工作时间
- 通常把总工作量看为 $1$

#### (3) 销售问题
- 售价 = 标价 × 折扣
- 利润 = 售价 - 进价
- 利润率 = $\frac{\text{利润}}{\text{进价}} \times 100\%$

#### (4) 分配问题
- 总量相等或各部分满足一定比例关系

#### (5) 数字问题
- 两位数：$10a + b$（$a$ 为十位数字，$b$ 为个位数字）

## 典型题型

1. **判断一元一次方程**：识别是否为一元一次方程
2. **利用等式性质变形**：判断等式变形是否正确
3. **解一元一次方程**：按步骤解方程
4. **列方程解应用题**：设未知数→找等量关系→列方程→解方程→检验作答
5. **含参问题**：已知方程的解求参数值

## 易错点

1. ❌ 去分母时漏乘不含分母的项
   - ✅ 去分母时**方程两边每一项**都要乘最小公倍数
2. ❌ 移项时忘记变号
   - ✅ 移项必须变号，"$+$"变"$-$"，"$-$"变"$+$"
3. ❌ 系数化为1时，两边应同除以系数而非同减
4. ❌ 去分母时未给单个数字加括号
   - ✅ $\frac{x}{2} - 3 = \frac{x}{3} + 1$ 去分母应写为 $3x - 18 = 2x + 6$
5. ❌ 实际问题中忘记检验答案是否合理
   - ✅ 人数、长度等必须为正数
