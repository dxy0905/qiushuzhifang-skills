## 📐 核心知识点速查

### 第十九章 二次根式

- **定义**：形如 $\sqrt{a}(a \ge 0)$ 的式子
- **性质**：$(\sqrt{a})^2 = a (a \ge 0)$；$\sqrt{a^2} = |a|$
- **乘除**：$\sqrt{a}\cdot\sqrt{b} = \sqrt{ab}$；$\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$
- **最简二次根式**：被开方数不含分母、不含能开得尽方的因数
- **分母有理化**：$\frac{1}{\sqrt{a}} = \frac{\sqrt{a}}{a}$

### 第二十章 勾股定理

- **勾股定理**：$a^2 + b^2 = c^2$（直角三角形两直角边平方和等于斜边平方）
- **逆定理**：若 $a^2 + b^2 = c^2$，则三角形为直角三角形
- **勾股数**：满足 $a^2 + b^2 = c^2$ 的正整数，如 $(3,4,5)$、$(5,12,13)$
- **应用**：最短路径（展开图法）

### 第二十一章 四边形

- **平行四边形**：对边平行且相等、对角相等、对角线互相平分
- **矩形**：对角线相等、四个角都是直角
- **菱形**：四边相等、对角线互相垂直平分
- **正方形**：兼具矩形与菱形所有性质
- **三角形中位线**：平行于第三边且等于第三边的一半

### 第二十二章 函数

- **变量与常量**：在变化过程中数值发生/不发生变化的量
- **函数定义**：对于 $x$ 的每一个确定的值，$y$ 有唯一确定的值与之对应
- **函数图像**：所有满足函数解析式的点 $(x,y)$ 组成的图形
- **正比例函数**：$y = kx$（$k$ 为常数，$k \ne 0$），图像过原点

### 第二十三章 一次函数

- **一般形式**：$y = kx + b(k \ne 0)$
- **图像**：一条直线；$k$ 决定增减性，$b$ 决定与 $y$ 轴交点
- **待定系数法**：设解析式 → 代入已知点 → 解方程求 $k,b$
- **与方程/不等式**：$y=0 \Leftrightarrow$ 解方程 $kx+b=0$；$y>0 \Leftrightarrow$ 解不等式 $kx+b>0$

### 第二十四章 数据的分析

- **平均数**：$\bar{x} = \frac{x_1+x_2+\cdots+x_n}{n}$；加权平均数 $\bar{x} = \frac{x_1w_1+x_2w_2+\cdots+x_nw_n}{w_1+w_2+\cdots+w_n}$
- **中位数**：排序后中间的数（奇数个取中间，偶数个取中间两数平均）
- **众数**：出现次数最多的数据
- **方差**：$s^2 = \frac{1}{n}\sum_{i=1}^n(x_i-\bar{x})^2$，衡量数据波动大小
