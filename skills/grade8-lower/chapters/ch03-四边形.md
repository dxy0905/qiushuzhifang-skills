# 第二十一章 四边形

## 一、核心内容

本章学习平行四边形的性质和判定，以及矩形、菱形、正方形等特殊平行四边形，是几何推理和证明能力培养的重要章节。重点包括各种四边形的判定方法、性质的综合运用以及三角形中位线定理。

---

## 二、各节知识点

### 21.1 平行四边形的性质

**1. 平行四边形的定义**

两组对边分别平行的四边形叫做平行四边形。平行四边形 $\mathrm{ABCD}$ 记作 $\square \mathrm{ABCD}$。

**2. 平行四边形的性质**

- **边**：对边平行且相等
  $$AB \parallel CD, AD \parallel BC, AB = CD, AD = BC$$
- **角**：对角相等，邻角互补
  $$\angle A = \angle C, \angle B = \angle D$$
  $$\angle A + \angle B = 180^\circ$$
- **对角线**：对角线互相平分
  $$AO = OC, BO = OD$$
- **对称性**：中心对称图形（对称中心是对角线的交点）

### 21.2 平行四边形的判定

**判定方法**（满足以下条件之一即可）：

1. 两组对边分别平行的四边形是平行四边形（定义法）
2. 两组对边分别相等的四边形是平行四边形
3. 一组对边平行且相等的四边形是平行四边形
4. 对角线互相平分的四边形是平行四边形
5. 两组对角分别相等的四边形是平行四边形

### 21.3 三角形中位线

**1. 三角形中位线的定义**

连接三角形两边中点的线段叫做三角形的中位线。

**2. 三角形中位线定理**

三角形的中位线平行于第三边，且等于第三边的一半。

在 $\triangle ABC$ 中，$D$、$E$ 分别为 $AB$、$AC$ 的中点，则

$$DE \parallel BC, \quad DE = \frac{1}{2}BC$$

> **注意**：三角形有三条中位线，它们构成一个与原三角形相似的三角形（面积比为 $1:4$）。

### 21.4 矩形

**1. 矩形的定义**

有一个角是直角的平行四边形叫做矩形。

**2. 矩形的性质**

- 具备平行四边形的所有性质
- 四个角都是直角（$90^\circ$）
- 对角线相等：$AC = BD$

**3. 矩形的判定**

- 有一个角是直角的平行四边形是矩形
- 对角线相等的平行四边形是矩形
- 有三个角是直角的四边形是矩形

### 21.5 菱形

**1. 菱形的定义**

有一组邻边相等的平行四边形叫做菱形。

**2. 菱形的性质**

- 具备平行四边形的所有性质
- 四条边都相等
- 对角线互相垂直：$AC \perp BD$
- 对角线平分一组对角：$\angle BAC = \angle DAC$
- 面积公式：$S = \frac{1}{2} \times$ 对角线乘积 $= a h$（$a$ 为边长，$h$ 为高）

**3. 菱形的判定**

- 一组邻边相等的平行四边形是菱形
- 对角线互相垂直的平行四边形是菱形
- 四条边都相等的四边形是菱形

### 21.6 正方形

**1. 正方形的定义**

有一组邻边相等且有一个角是直角的平行四边形叫做正方形。

**2. 正方形的性质**

正方形兼具矩形与菱形的所有性质：
- 四条边相等
- 四个角都是直角
- 对角线相等、互相垂直平分、平分一组对角

**3. 正方形的判定**

- 有一组邻边相等的矩形是正方形
- 有一个角是直角的菱形是正方形
- 对角线相等且垂直的平行四边形是正方形

## 三、典型题型

### 题型1：平行四边形性质的应用

**例1**：在 $\square ABCD$ 中，$\angle A = 50^\circ$，求其它各角的度数。

**解**：$\because \square ABCD$，
$\therefore \angle A = \angle C = 50^\circ$，$\angle B = \angle D$
又 $\because \angle A + \angle B = 180^\circ$，
$\therefore \angle B = 180^\circ - 50^\circ = 130^\circ = \angle D$

### 题型2：平行四边形的判定

**例2**：在四边形 $ABCD$ 中，$AB = CD$，$AB \parallel CD$，求证：四边形 $ABCD$ 是平行四边形。

**证明**：$\because AB = CD$ 且 $AB \parallel CD$，
$\therefore$ 四边形 $ABCD$ 是平行四边形（一组对边平行且相等的四边形是平行四边形）。

### 题型3：三角形中位线定理的应用

**例3**：在 $\triangle ABC$ 中，$D$、$E$、$F$ 分别是 $AB$、$BC$、$CA$ 的中点，$AB = 10$，$AC = 8$，$BC = 12$，求 $\triangle DEF$ 的周长。

**解**：$\because D$、$E$、$F$ 是中点，
$\therefore DE = \frac{1}{2}AC = 4$，$EF = \frac{1}{2}AB = 5$，$DF = \frac{1}{2}BC = 6$
$\therefore C_{\triangle DEF} = 4 + 5 + 6 = 15$

### 题型4：矩形性质的应用

**例4**：矩形 $ABCD$ 的对角线 $AC$、$BD$ 交于点 $O$，$\angle AOB = 60^\circ$，$AB = 4$，求对角线的长。

**解**：$\because$ 矩形对角线相等且互相平分，
$\therefore OA = OB = OC = OD$
又 $\because \angle AOB = 60^\circ$，
$\therefore \triangle AOB$ 为等边三角形，
$\therefore OA = AB = 4$，
$\therefore AC = 2 \times OA = 8$

### 题型5：菱形性质与面积

**例5**：菱形 $ABCD$ 中，对角线 $AC = 10$，$BD = 24$，求菱形的边长和面积。

**解**：$\because$ 菱形对角线互相垂直平分，
$\therefore OA = \frac{AC}{2} = 5$，$OB = \frac{BD}{2} = 12$
在 $\mathrm{Rt}\triangle AOB$ 中，$AB = \sqrt{OA^2 + OB^2} = \sqrt{5^2 + 12^2} = 13$
面积 $S = \frac{1}{2} \times AC \times BD = \frac{1}{2} \times 10 \times 24 = 120$

### 题型6：正方形的综合证明

**例6**：正方形 $ABCD$ 中，$E$ 是 $CD$ 上一点，$AE$ 平分 $\angle DAB$，求证：$BE = DE$。

**证明**：$\because$ 四边形 $ABCD$ 是正方形，
$\therefore AB = AD$，$\angle BAD = 90^\circ$
$\because AE$ 平分 $\angle DAB$，
$\therefore \angle BAE = \angle DAE = 45^\circ$
又 $\because AE = AE$，
$\therefore \triangle ABE \cong \triangle ADE$（SAS）
$\therefore BE = DE$

## 四、易错点

### ❌ 易错1：判定条件混淆

**错**："对角线相等的四边形是矩形"。
**对**："对角线相等的**平行四边形**是矩形"。对角线相等的四边形不一定是矩形（如等腰梯形的对角线也相等）。

**错**："对角线垂直的四边形是菱形"。
**对**："对角线互相垂直的**平行四边形**是菱形"。

### ❌ 易错2：对角线性质张冠李戴

| 图形 | 对角线性质（仅对边平行时特有） |
|:---|:---|
| 平行四边形 | 互相平分 |
| 矩形 | 互相平分 **且** 相等 |
| 菱形 | 互相平分 **且** 垂直 |
| 正方形 | 互相平分、相等 **且** 垂直 |

### ❌ 易错3：三角形中位线与中线混淆

- **中位线**：连接两边中点的线段，平行于第三边且等于第三边的一半
- **中线**：连接顶点与对边中点的线段

### ❌ 易错4：证明逻辑链不完整

证明四边形是特殊平行四边形时，需先证明它是平行四边形，再证明其特殊性（矩形/菱形/正方形），不能一步跳。

### ❌ 易错5：忽略菱形面积两种算法

菱形面积 $S = \frac{1}{2}d_1d_2$（对角线乘积的一半），也可以用底×高 $S = ah$。
**错**：用边长乘另一条边长。
**对**：菱形邻边不垂直，不能用邻边相乘。
