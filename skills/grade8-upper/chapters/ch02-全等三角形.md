# 第十四章 全等三角形

## 核心内容

全等三角形是初中几何"证明推理"的起点，重点掌握五种判定方法（SSS、SAS、ASA、AAS、HL），并能灵活运用全等三角形证明线段相等和角相等。本章还介绍了角平分线的性质定理及其逆定理。

---

## 各节知识点

### 14.1 全等三角形

**定义：** 能够完全重合的两个三角形叫做全等三角形。
- 重合的顶点叫做 **对应顶点**
- 重合的边叫做 **对应边**
- 重合的角叫做 **对应角**

**表示：** $\triangle ABC \cong \triangle DEF$（读作"三角形 ABC 全等于三角形 DEF"）

**性质：**
1. 全等三角形的对应边相等：$AB = DE$，$BC = EF$，$CA = FD$
2. 全等三角形的对应角相等：$\angle A = \angle D$，$\angle B = \angle E$，$\angle C = \angle F$
3. 全等三角形的周长相等、面积相等
4. 全等三角形的对应高、对应中线、对应角平分线相等

> **注意：** 表示全等时，对应顶点要写在对应位置上。

---

### 14.2 三角形全等的判定

#### 判定1：SSS（边边边）

**定理：** 三边对应相等的两个三角形全等。

> **简记：** "SSS" 或 "边边边"

> **应用：** 三边长度确定后，三角形形状唯一确定（三角形稳定性原理）

#### 判定2：SAS（边角边）

**定理：** 两边和它们的夹角对应相等的两个三角形全等。

> **简记：** "SAS" 或 "边角边"

> **⚠️ 易错：** 角必须是 **夹角**（两边所夹的角），不是任意角！

#### 判定3：ASA（角边角）

**定理：** 两角和它们的夹边对应相等的两个三角形全等。

> **简记：** "ASA" 或 "角边角"

#### 判定4：AAS（角角边）

**定理：** 两角和其中一角的对边对应相等的两个三角形全等。

> **简记：** "AAS" 或 "角角边"

> **注意：** ASA 和 AAS 的区别在于"边"的位置不同——ASA 的边是两角的夹边，AAS 的边是其中一角的对边。

#### 判定5：HL（斜边、直角边）——仅限直角三角形

**定理：** 斜边和一条直角边对应相等的两个直角三角形全等。

> **简记：** "HL" 或 "斜边、直角边"

> **注意：** HL 是直角三角形 **专用** 判定方法，不能用于一般三角形！

---

### 判定方法总结

| 方法 | 条件 | 适用三角形 | 图示 |
|------|------|-----------|------|
| SSS | 三边对应相等 | 任意三角形 | 边→边→边 |
| SAS | 两边及其夹角对应相等 | 任意三角形 | 边→角→边 |
| ASA | 两角及其夹边对应相等 | 任意三角形 | 角→边→角 |
| AAS | 两角及其中一角的对边对应相等 | 任意三角形 | 角→角→边 |
| HL | 斜边和一条直角边对应相等 | 直角三角形专用 | 斜边→直角边 |

> **不会产生全等的情况：** SSA（两边及非夹角）和 AAA（三角对应相等）不能判定全等。

### 14.3 角的平分线的性质

#### 角平分线的画法

用尺规作角平分线：
1. 以 O 为圆心，适当长为半径画弧，交 OA 于 M、OB 于 N
2. 分别以 M、N 为圆心，大于 $\frac{1}{2}MN$ 为半径画弧，两弧交于点 C
3. 作射线 OC，即为 $\angle AOB$ 的平分线

#### 角平分线的性质定理

**定理：** 角的平分线上的点到角的两边的距离 **相等**。

> 数学语言：$\because$ OC 平分 $\angle AOB$，PD $\perp$ OA，PE $\perp$ OB $\quad\therefore$ PD = PE

> **应用：** 证明两条垂线段相等

#### 角平分线的判定定理

**定理：** 角的内部到角的两边距离相等的点在角的平分线上。

> 数学语言：$\because$ PD $\perp$ OA，PE $\perp$ OB，PD = PE $\quad\therefore$ OC 平分 $\angle AOB$

**推论：** 三角形的三条角平分线交于一点，这点到三角形三边的距离相等（内心）。

## 典型题型

### 题型一：选择判定方法

**例1：** 已知 $AB = DE$，$\angle A = \angle D$，$\angle B = \angle E$，求证 $\triangle ABC \cong \triangle DEF$。
> **分析：** 两角及其夹边对应相等 → **ASA**
> 或：两角及其中一角的对边对应相等 → **AAS**

**例2：** 已知 $AB = DE$，$BC = EF$，$AC = DF$，求证 $\triangle ABC \cong \triangle DEF$。
> **分析：** 三边对应相等 → **SSS**

### 题型二：全等三角形的证明

**例3：** 如图，$AB = AD$，$BC = DC$，求证 $\angle B = \angle D$。
> **证明：** 连接 AC
> 在 $\triangle ABC$ 和 $\triangle ADC$ 中，
> $\begin{cases} AB = AD \ (\text{已知}) \\ BC = DC \ (\text{已知}) \\ AC = AC \ (\text{公共边}) \end{cases}$
> $\therefore \triangle ABC \cong \triangle ADC \ (\text{SSS})$
> $\therefore \angle B = \angle D$

### 题型三：利用角平分线性质

**例4：** 在 $\triangle ABC$ 中，AD 平分 $\angle BAC$，DE $\perp$ AB，DF $\perp$ AC，垂足分别为 E、F。求证 DE = DF。
> **证明：** $\because$ AD 平分 $\angle BAC$，DE $\perp$ AB，DF $\perp$ AC
> $\therefore$ DE = DF（角平分线上的点到角两边距离相等）

### 题型四：HL 判定

**例5：** 在 Rt$\triangle ABC$ 和 Rt$\triangle DEF$ 中，$\angle C = \angle F = 90^\circ$，$AB = DE$，$AC = DF$，求证 $\triangle ABC \cong \triangle DEF$。
> **证明：** 在 Rt$\triangle ABC$ 和 Rt$\triangle DEF$ 中，
> $\begin{cases} AB = DE \ (\text{斜边}) \\ AC = DF \ (\text{直角边}) \end{cases}$
> $\therefore \triangle ABC \cong \triangle DEF \ (\text{HL})$

## 易错点

1. **SSA 误作判定**：两边及其中一边的对角对应相等（SSA）**不能** 判定全等，反例是等腰三角形的情况。只有直角三角形中 SSA 才有效（即 HL）。

2. **AAA 误作判定**：三角对应相等只能推出相似，不能推出全等。

3. **SAS 中角的位置错误**：角必须是两边的夹角。如果角不是夹角，则变为 SSA。

4. **HL 的适用范围**：HL 只适用于直角三角形，不可用于一般三角形。

5. **对应顶点书写顺序**：表示全等时 $\triangle ABC \cong \triangle DEF$ 意味着 A↔D、B↔E、C↔F，顺序暗示对应关系。

6. **角平分线性质混淆**：性质定理和判定定理容易混淆——性质：平分线上的点到两边距离相等；判定：到两边距离相等的点在平分线上。

7. **证明过程不规范**：全等证明需要写清楚三组条件，并标明理由（已知/公共边/对顶角等），不可跳步。
