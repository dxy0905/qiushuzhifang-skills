# 九年级下册·术语表

- **比例线段** — 四条线段$a:b=c:d$，内项积等于外项积$ad=bc$（ch01）
- **相似三角形** — 对应角相等，对应边成比例的三角形（ch01）
- **相似比** — 相似三角形对应边的比（ch01）
- **位似** — 对应点连线交于同一点的相似变换（ch01）
- **位似中心** — 位似变换中所有对应点连线的交点（ch01）
- **正弦(sin)** — 直角三角形中对边比斜边（ch02）
- **余弦(cos)** — 直角三角形中邻边比斜边（ch02）
- **正切(tan)** — 直角三角形中对边比邻边（ch02）
- **锐角三角函数** — $\sin A$、$\cos A$、$\tan A$统称（ch02）
- **解直角三角形** — 已知两边或一边一角求其余未知量（ch02）
- **仰角** — 视线在水平线上方与水平线的夹角（ch02）
- **俯角** — 视线在水平线下方与水平线的夹角（ch02）
- **坡度** — 斜坡的竖直高度与水平距离的比（ch02）
- **投影** — 光线照射物体在平面上留下的影子（ch03）
- **平行投影** — 平行光线下的投影（如太阳光）（ch03）
- **中心投影** — 点光源发出的光线下的投影（如灯光）（ch03）
- **正投影** — 投影线垂直于投影面的投影（ch03）
- **主视图** — 从正面看立体图形得到的视图（ch03）
- **左视图** — 从左面看立体图形得到的视图（ch03）
- **俯视图** — 从上面看立体图形得到的视图（ch03）
- **三视图** — 主视图、左视图、俯视图的合称（ch03）
- **概率** — 事件发生的可能性大小的数值度量（ch04）
- **列举法** — 直接列出所有等可能结果求概率（ch04）
- **列表法** — 用表格列举两步试验的所有结果（ch04）
- **树状图** — 用树形分支列举多步试验的所有结果（ch04）
- **频率估计概率** — 大量重复试验用频率近似概率（ch04）
