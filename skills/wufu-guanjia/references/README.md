# 五福管家 (Wufu Guanjia)

帮普通老百姓把每一分钱都安排好的记账提醒工具。

## 项目定位

**记账提醒工具，不是理财平台。** 钱一直在用户自己银行卡里，不帮投资理财、不推荐股票基金、不代销保险、不托管资金。

## 五账户比例

| 账户 | 比例 | 存法 |
|:-----|:----:|:-----|
| 🏠 日常花销 | 60% | 活期 |
| 🛡️ 看病救急 | 10% | 保险¥169/年+活期备用 |
| 🎓 孩子读书 | 15% | 5年定期 |
| 👴 养老钱 | 5% | 3-5年定期 |
| 📈 钱生钱 | 10% | 5年定期（懂理财可改）|

## 保险方案

惠民保¥69/年 + 综合意外险¥100/年 = **¥169/年**（每天≈5毛钱）

## 消费者保护

自愿加入 · 7天冷静期 · 应急提取 · 通胀提示 · AES加密
