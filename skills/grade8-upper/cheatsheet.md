## 第十三章 三角形

### 三边关系
$$a + b > c, \quad a + c > b, \quad b + c > a$$
$$|a - b| < c$$

### 内角和
$$\angle A + \angle B + \angle C = 180^\circ$$

### 外角性质
$$\angle ACD = \angle A + \angle B$$

### 多边形内角和
$$S = (n - 2) \times 180^\circ$$

### 多边形外角和
$$S_{\text{外}} = 360^\circ$$

### 正 n 边形每个内角
$$\frac{(n - 2) \times 180^\circ}{n}$$

### n 边形对角线数
$$\frac{n(n-3)}{2}$$

## 第十四章 全等三角形

### 全等判定

| 方法 | 条件 |
|------|------|
| **SSS** | 三边对应相等 |
| **SAS** | 两边及其夹角对应相等 |
| **ASA** | 两角及其夹边对应相等 |
| **AAS** | 两角及其中一角的对边对应相等 |
| **HL** | 斜边和一条直角边对应相等（Rt△专用） |

### 角平分线性质
$$\text{OC 平分} \angle AOB \xrightarrow{\text{PD}\perp\text{OA},\ \text{PE}\perp\text{OB}} \text{PD} = \text{PE}$$

### 角平分线判定
$$\text{PD} = \text{PE},\ \text{PD}\perp\text{OA},\ \text{PE}\perp\text{OB} \Rightarrow \text{OC 平分} \angle AOB$$

## 第十五章 轴对称

### 坐标对称
- 关于 x 轴对称：$(x, y) \to (x, -y)$
- 关于 y 轴对称：$(x, y) \to (-x, y)$

### 线段垂直平分线
- 性质：$\text{PA} = \text{PB}$
- 判定：$\text{PA} = \text{PB} \Rightarrow$ P 在 AB 中垂线上

### 等腰三角形
- 性质：$\angle B = \angle C$，三线合一
- 判定：$\angle B = \angle C \Rightarrow AB = AC$

### 等边三角形
- 三边相等，三角 $= 60^\circ$
- 判定：三角相等 或 等腰 + 一角 $60^\circ$

### 30° 角 Rt△
$$30^\circ \text{对边} = \frac{1}{2} \times \text{斜边}$$

## 第十六章 整式的乘法

### 幂的运算

| 运算 | 公式 |
|------|------|
| 同底数幂乘法 | $a^m \cdot a^n = a^{m+n}$ |
| 幂的乘方 | $(a^m)^n = a^{mn}$ |
| 积的乘方 | $(ab)^n = a^n b^n$ |
| 同底数幂除法 | $a^m \div a^n = a^{m-n}$ |
| 零指数幂 | $a^0 = 1 \ (a \neq 0)$ |
| 负指数幂 | $a^{-n} = \dfrac{1}{a^n} \ (a \neq 0)$ |

### 整式乘法
- 单项式 × 单项式：系数乘，同底幂乘
- $m(a+b+c) = ma + mb + mc$
- $(a+b)(c+d) = ac + ad + bc + bd$

### 乘法公式
$$(a + b)(a - b) = a^2 - b^2$$
$$(a + b)^2 = a^2 + 2ab + b^2$$
$$(a - b)^2 = a^2 - 2ab + b^2$$

## 第十七章 因式分解

### 提公因式法
$$ma + mb + mc = m(a + b + c)$$

### 平方差公式
$$a^2 - b^2 = (a + b)(a - b)$$

### 完全平方公式
$$a^2 + 2ab + b^2 = (a + b)^2$$
$$a^2 - 2ab + b^2 = (a - b)^2$$

### 一般步骤
**① 提公因式 → ② 套用公式 → ③ 检查是否彻底**

## 第十八章 分式

### 分式基本性质
$$\frac{A}{B} = \frac{A \times C}{B \times C} = \frac{A \div C}{B \div C} \quad (C \neq 0)$$

### 分式乘除
$$\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}, \qquad \frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c} = \frac{ad}{bc}$$

### 分式乘方
$$\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$$

### 分式加减
$$\frac{a}{c} \pm \frac{b}{c} = \frac{a \pm b}{c}$$
$$\frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm bc}{bd}$$

### 分式方程解法
**去分母 → 解整式方程 → 检验（去增根）**

### 科学记数法（小数）
$$0.\underbrace{000\cdots 01}_{n\text{位}} = 1 \times 10^{-(n+1)}$$
$$0.000\text{xxx} = a \times 10^{-n} \quad (1 \le a < 10)$$
