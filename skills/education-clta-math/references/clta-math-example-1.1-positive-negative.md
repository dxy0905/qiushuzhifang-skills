## 二、框架结构（7步法）

此案例严格遵循CLTA 7步框架：

```markdown
课标摘录 → 课标分解 → 教材分析 → 学情分析 → 目标叙写(ABCD) → 评估任务 → 教学过程 + 教学反思
```

### 关键设计决策

| 步骤 | 内容 | 亮点 |
|:----|:-----|:-----|
| 课标摘录 | 摘录3条：内容要求+学业要求+教学提示，标注学段与主题 | 来源明确、一课一标 |
| 课标分解 | 拆分为3条：学什么/学到什么程度/怎么学 | **动词替换法**：理解→识别/说出，掌握→写出/判断 |
| 教材分析 | 承上（小学自然数/分数）→启下（有理数运算） | 定位清晰 |
| 学情分析 | 七年级学生特点+生活经验+常见错误（正负混淆、0的归属） | 具体不笼统 |
| 学习目标 | 3条目标，ABCD法，含可测量标准 | 每条目标有准确率/正确数指标 |
| 评估任务 | 3个评估任务，各对应1条目标 | 目标-评估一一对应 |
| 教学过程 | 5个环节（导入→探究→练习→拓展→小结），表格形式 | 学生活动≥28min |
| 教学反思 | 含目标达成度数据+改进方向 | 真实反思 |

## 三、动词替换实操（核心技巧）

这是本案例最重要的教学设计技巧——将课标笼统动词替换为可观测行为动词：

| 课标原文（笼统） | 替换后（可观可测） | 评估方式 |
|:-----------------|:-------------------|:---------|
| 理解正数和负数的意义 | **识别**实际情境中的正数和负数，**说出**各自含义 | 课堂提问+书面判断 |
| 掌握有理数的分类 | **写出**正数/0/负数的实例，**判断**一个数所属类别 | 分类练习 |
| 了解相反意义量 | **举例说明**生活中相反意义的量 | 举例子检验 |

---

## 四、教学反思要点

反思部分包含三个维度：

| 维度 | 内容 |
|:-----|:------|
| 目标达成 | 目标1达成率约85%（基于课堂提问数据）、目标2约90%（练习正确率）、目标3约75%（开放性举例） |
| 存在问题 | 部分学生对0的特殊性理解不到位；用正负数表示相反意义量时方向感混淆 |
| 改进方向 | 下次增加0的角色讨论环节；用"东走vs西走"等更贴近生活的例子强化方向感 |

---

## 五、可复用要素

以下设计要素可直接复制到其他CLTA教学设计中：

1. **动词替换对照表**（见第三节）— 每一次CLTA设计都先做动词替换
2. **目标-评估对应表** — 设计3条目标，每条配1个评估任务
3. **教学过程五环节表格** — 导入5min→探究15min→练习10min→拓展10min→小结5min
4. **教学反思三要素** — 达成度/问题/改进方向

## 六、经验教训

| 教训 | 说明 |
|:----|:------|
| 不要在教案中写重复内容 | 初稿同时写了「重点」「难点」和「学习目标」，被要求删除——CLTA框架已通过目标和活动覆盖重难点 |
| 教学过程必须用表格 | 初稿用文字描述→改表格后清晰度提升300% |
| 评估任务不能过度拆分 | 初稿拆了6条→精简为3条（每个目标对应1条），更易操作 |
| 反思必须基于数据 | 不能用「感觉良好」→用正确率/达标人数说话 |
