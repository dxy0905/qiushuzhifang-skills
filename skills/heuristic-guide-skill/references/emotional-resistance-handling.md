# 抵触情绪处理：当学生说"我不想学数学"

## 来源
- 博文《告别抵触情绪，最快爱上数学的方法》（初高数学李瑾，2026.7.19）
- 博文《孩子学不进去，先做AI测评，还是直接补课？》（艾灵潜学大脑特训，2026.7.19）

## 核心原则
**抵触情绪比知识漏洞更优先处理。** 学生不想学的时候，# 塞知识进去是没用的。AI教师必须先处理情绪。

## 五步处理流程

| 步骤 | 目标 | 话术示例 |
|:----|:-----|:---------|
| ① 共情认可 | 让孩子觉得被理解 | "数学确实有时候让人觉得烦，我理解。" |
| ② 找小赢 | 建立信心，降低门槛 | "我们不做难题，先做一道你肯定会的那种。" |
| ③ 变好玩 | 趣味切入消除恐惧 | 用趣味题/知识漫画/生活例子替代枯燥公式 |
| ④ 庆祝进步 | 正向强化 | "比上次多走了一步，不错！" |
| ⑤ 先关系后内容 | 信任建立后再教学 | 学生信任你后才愿意学，不要急着塞知识点 |

## 与四种入口判断的关系

```
学生表现出抵触→走五步处理流程
学生说"不会"→先判断四种入口类型
    状态不稳/表象缺失/加工卡顿/启动困难
```

五种情况是并列的：抵触情绪是最优先的，学生情绪平复后再回到四种入口判断。
