# 特殊学校教材设计方法论

## 适用场景
为基础薄弱、厌学、有抵触情绪的特殊学校学生编写教材。

## 八大设计铁律

| 铁律 | 内容 |
|:-----|:------|
| 铁律1 | 第一印象必须"不像课本"——封面不写"数学"，写"工资怎么算""买菜不被坑" |
| 铁律2 | 每节课从"你行"开始——先给一个他肯定能答对的问题建立信心 |
| 铁律3 | 说人话——不用"综上所述"，用"你发现没"；不用"小明"，用"你" |
| 铁律4 | 每个知识点回答"这有什么用"——正负数→记工账，函数→算打车费 |
| 铁律5 | 即时成就感——每学一个马上练，练完马上给答案 |
| 铁律6 | 游戏化——不叫"第1节"叫"第1关"，闯关集星标 |
| 铁律7 | 图形配生活场景——函数图像叫"你的工资走势" |
| 铁律8 | 每节课结尾"记住这一句"——核心知识压缩成一句话 |

## 每节课标准格式（45分钟）

```
先听我说（橙色·3min）→ 生活场景引入
你先试试（蓝色·7min）→ 给一个必会题建立信心
来学一招（绿色·15min）→ 启发五步法引导
闯关练习（米色·15min）→ 第1关⭐(基础)→第2关⭐⭐(提升)→第3关⭐⭐⭐(挑战)
记住这一句（金色·5min）→ 核心知识点压缩成一句话
```

## 78学时6学期分配

| 学期 | 学时 | 内容 | 学期主题 |
|:-----|:----:|:------|:---------|
| 七上 | 13 | 正负数→四则→乘方→线段角 | 数学帮你算清楚钱 |
| 七下 | 13 | 整式→方程→方程组→三角形 | 数学帮你做对决定 |
| 八上 | 13 | 整式乘除→分式→全等→勾股 | 数学帮你看透套路 |
| 八下 | 13 | 坐标系→函数→统计图 | 数学帮你预测未来 |
| 九上 | 13 | 统计→概率→反比例→二次函数 | 数学帮你抓住机会 |
| 九下 | 13 | 机动4节+综合复习+结业 | 数学你其实会了 |

## 配图要求
几何/函数题必须有图。建议用网络画板（NetPad）绘制后嵌入PDF。不可纯文字。

## 称呼规范
- 不用"小明""小红"，用"你""你同事""你老板"
- 场景优先顺序：发工资/租房/吃饭AA/打车/买菜/超市购物

## 生成工具链
- HTML生成 → Python脚本（fpdf2/weasyprint）
- PDF输出 → fpdf2（支持中文TTF字体嵌入）
- 图形绘制 → 网络画板导出PNG，嵌入PDF
