评审编号：WF-2026-001
评审日期：2026年6月22日
评审地点：邱数智方（福建）科技股份有限公司
评审对象：五福管家——面向普通老百姓的资金管理记账提醒工具


一、项目基本信息

| 项目 | 内容 |
|:-----|:------|
| 项目名称 | 五福管家 |
| 项目定位 | 记账提醒工具（非理财平台） |
| 目标用户 | 月收入3000-15000元的普通老百姓 |
| 开发单位 | 邱数智方（福建）科技股份有限公司 |
| 迭代版本 | V8（历经8轮迭代完善） |


二、最终方案概要

2.1 五账户比例与存法

| 账户 | 比例 | 存法 | 说明 |
|:-----|:----:|:-----|:------|
| 🏠 日常花销 | 60% | 活期 | 吃饭坐车交水电 |
| 🛡️ 看病救急 | 10% | 保险+活期备用 | 惠民保¥69+意外险¥100=¥169/年 |
| 🎓 孩子读书 | 15% | 5年定期 | 利率最高，到期自动转存 |
| 👴 养老钱 | 5% | 3-5年定期 | 长期储备 |
| 📈 钱生钱 | 10% | 5年定期（懂理财可自行改） | 提高投资意识 |
| 合计 | 100% | | |

2.2 核心技术

| 项目 | 内容 |
|:-----|:------|
| 加密 | AES-128-CBC + HMAC（Fernet） |
| 认证 | JWT（PyJWT库） |
| 验证 | 三级验证：L1姓名手机 / L2+身份证 / L3+人脸 |
| 数据库 | SQLite，全部参数化查询 |
| 审计日志 | 链式哈希，防篡改 |
| 应急提取 | 书面申请 + 电子签名 |

2.3 消费者保护

| 机制 | 说明 |
|:-----|:------|
| ✅ 自愿加入 | 首屏声明，不勾选不可注册 |
| ✅ 保险条款阅读 | 强制阅读15秒 |
| ✅ 7天冷静期 | 7天内可随时退出，不产生损失 |
| ✅ 通胀提示 | 诚实告知1.35%利率低于物价上涨 |
| ✅ 应急提取通道 | 真有急事可以申请 |
| ✅ 资金安全 | 钱一直在用户自己的银行卡里 |

四、评审结论

经专家组全面评审，一致认为：

| 评审项 | 结论 |
|:-------|:-----|
| 🎯 项目定位 | ✅ 清晰——记账提醒工具，非理财平台 |
| 👥 消费者保护 | ✅ 完善——自愿加入、冷静期、应急提取 |
| 🏛️ 合规性 | ✅ 合规——不碰资金、不代销、不持牌 |
| 🔒 技术安全 | ✅ 基础达标——加密、认证、防注入 |
| 📊 理财科学性 | ✅ 合理——符合老百姓实际 |
| 📋 整体评价 | ✅ **达到上线标准** |

最终评审意见：

> **五福管家项目定位清晰，五账户分立理念让普通老百姓听得懂、学得会、用得上。¥169/年的保险方案降低保障门槛，7天冷静期和通胀提示保护消费者权益。资金一直在用户自己银行卡里，平台不碰钱、不代销、不提供投资建议，合规基础扎实。**
>
> **专家组一致同意：项目达到上线标准，可按计划推进。建议上线后持续收集用户反馈，不断优化完善。**
