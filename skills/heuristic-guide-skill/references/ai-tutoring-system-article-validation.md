## 核心数据（验证学霸基本法方向正确）

| 对比组 | 同类题二次正确率 |
|:-------|:----------------|
| **引导式对话**（苏格拉底式） | **82%** ✅ |
| 直接给答案+解析 | 54% ❌ |

→ 学霸基本法的五步引导法方向被数据验证。

## 5条可直接借鉴的结论

### 1. BKT贝叶斯知识追踪——比"掌握/未掌握"更精细

每个知识点维护4个参数：
```
初始掌握概率  学习转移概率  猜测概率  失误概率
   0.45         0.8          0.1       0.1
```
学生每做一题，概率贝叶斯更新。做对3道→0.45→0.72→0.91→判定掌握。

**学霸基本法现有43节点知识图谱可叠加此模型。**

### 2. Elo Rating动态难度校准——比"基础/提升/挑战"固定分层更好

每道题当成"选手"，学生也是"选手"，做题=对局。
- 做对→学生加分、题目降分
- 做错→学生降分、题目加分

实测：学生"跳过不做"率从23%降到9%。

### 3. 引擎层拆为4个独立模块

| 模块 | 迭代节奏 |
|:-----|:---------|
| 大模型对话辅导 | 每月可能换提示词 |
| 自适应学习算法 | 半年调一次参数 |
| 多模态识别（OCR等） | 按模型更新节奏 |
| 评估推荐 | 按题库更新节奏 |

→ 拆开才能独立部署和灰度。

### 4. 教学策略提示词三条原则

1. **不直接给答案** — "除非学生连续三次无法回答才给出完整解题过程"
2. **根据水平调语言** — 注入学生画像（年级+掌握水平）到上下文
3. **情绪感知** — 连续错3道或出现"不会""太难了"→切换到鼓励模式

### 5. 知识图谱（1200+节点/3400+边）

他们的初中数学图谱有1200多个知识点节点、3400多条依赖边。用Neo4j存储。"这个活没有捷径，得找有经验的教研老师一条条确认。"
