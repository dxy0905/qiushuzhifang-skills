# 龙岩市八年级《三角形》第13章 校本作业修订实战案例

## 背景

龙岩市初中数学校本作业——八年级第13章《三角形》是一份已经投入使用的分层作业，
包含课前测+课中测+课后测（基础/提高/挑战）三层结构。
本次修订依据《义务教育数学课程标准（2022版）》、
人教版八年级上册教师用书（2025秋）和学教评一致性（CLTA）理念。

## 修订流程（全流程实录）

### Step 1: 读取四源资料

课程标准：E:/课程标准/义务教育数学课程标准2022版.pdf
教师用书：E:/数学资料/八年级下学期/人教版数学八年级上册教师用书（2025秋） .pdf
原校本作业：E:/数学资料/八年级下学期/第13章《三角形》.docx
原答案：E:/数学资料/八年级下学期/第十三章 《三角形》答案.docx

### Step 2: docx转Markdown

用markitdown库转换。注意docx中的插图会被忽略，需从docx中单独提取。

### Step 3: 提取原docx插图

docx本质是zip文件，图片在word/media/下：
unzip -o "第13章《三角形》.docx" "word/media/*" -d temp_dir
提取后得到image1.png~image94.png共94张图。

### Step 4: 按四源评估法逐项检查

发现问题：缺学习目标（P0）、课前测是预习检测（P2）、三层定位需校准（P0）、
缺核心素养题（P1）、缺自评（P2）、答案缺解析（P1）。

### Step 5: 生成修改意见报告

保存为"修改意见/第13章三角形_修改意见.md"（7KB, 8条建议）

### Step 6: 用python-docx生成带图的修订版

关键：设置宋体字体、按原图顺序插入图片、每图后空行

### Step 7: 修订后保存

校本作业修订版123KB（含86张插图），答案修订版38KB（含解析和易错点标注）

## 关键教训

| 教训 | 说明 |
|:-----|:------|
| docx插图必须重新插入 | markitdown转md会丢失所有图片，修订版需从原docx提取后逐一插入 |
| 图片编号与题目顺序对应 | 从image1.png开始按题目顺序逐一插入 |
| 答案要同步修订 | 提高题/挑战题答案必须加解析 |
| 学习目标不入校本作业 | 按约定暂不入（在修改意见中注明即可） |
| docx字体设置 | python-docx默认字体是Calibri，必须手动改为宋体 |
