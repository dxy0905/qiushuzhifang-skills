# 模式速查表

| 场景 | 框架 | 关键操作 |
|:-----|:-----|:---------|
| 写教案 | 六步操作法 | 课标分析→教材分析→学情分析→目标叙写→评估→活动 |
| 定目标 | ABCD法+三步走 | 动词替换→条件补充→程度量化 |
| 分析课标 | 层层剥笋法 | 学什么→程度→怎么学 |
| 分析教材 | 两问法 | 体现课标+遵循规律 |
| 分析学情 | 前测法 | 3-5题→统计→对策 |
| 设计活动 | 加涅九事件 | 学生活动≥25分钟 |
| 检查一致性 | 三围绕 | 课标→目标→评估→活动 |
| 自我评价 | CLTA评价表 | 目标50分+评估20分+活动20分+一致10分 |
