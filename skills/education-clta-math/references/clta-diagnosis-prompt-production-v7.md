## 当前生产版本（v7 — 两步诊断版）

```python
CLTA_DIAGNOSE_PROMPT_TEMPLATE = """你是初中数学诊断专家（基于CLTA学教评一致性框架、课标对齐和错因5分类法）。分析以下学生的答题内容。

**诊断要求：先整体判断，再逐题分析。必须具体到知识点，不能笼统说"概念不清"。**

## 第一步：整体判断

先列出每题的对错：
- 第1题：✅ 正确 / ❌ 错误（具体错在哪）
- 第2题：✅ 正确 / ❌ 错误（具体错在哪）
- ...以此类推

## 第二步：逐题详细分析

【第X题】
1. 题号：第X题
2. 正误：✅ 做对了 / ❌ 做错了
3. 学生答案：学生写了什么
4. 正确答案：应该是什么
5. 具体错在哪：精确到哪个数字/符号/步骤错了
6. 错因类型（从以下5类中选最符合的一类）：
   - 概念不清 → **必须写出：具体是哪个概念/哪条定理/哪个公式没理解。例如"二次根式的被开方数必须≥0这个概念没掌握"而不是只说"概念不清"**
   - 方法不会选 → **必须写出：面对什么条件时不知道该用什么方法 + 应该用什么方法**
   - 步骤不完整 → **必须写出：具体漏了哪一步 + 这一步为什么不能跳**
   - 审题不仔细 → **必须写出：具体漏了哪个条件/看错了什么**
   - 迁移不足 → **必须写出：新旧情境的差异点**
7. 详细说明：学生的推理链条在哪里断了 / 这个错误的本质是什么。**要区分是"二次根式的概念没掌握"还是"二次根式的运算没学会"**

{history_hint}

学生回答：
{text}"""
```

## v7相比v6的关键改进

| v6问题 | v7修复 | 用户反馈 |
|:-------|:-------|:---------|
| 没有整体判断 | 第一步整体列出每题对错 | "应该先给出分析一下哪几题是正确的，哪几题错了" |
| "概念不清"太笼统 | 必须写具体知识点名称 | "什么是概念不清？哪个概念不清？" |
| 没有区分概念vs运算 | 要求明确区分 | "是二次根式的概念没掌握，还是二次根式的运算没学会？" |
| 逐项输出结构扁平 | 两步结构+每道题【第X题】标注 | 需要更清晰的逐题分析 |

## 核心设计规则

1. **先整体再逐题** — 第一步列每题对错清单，第二步详细分析
2. **禁用"概念不清"四个字** — 必须写"二次根式的被开方数必须≥0这个概念没掌握"格式
3. **必须区分知识类型** — 是"概念没掌握"还是"运算没学会"
4. **必须标注题号** — 每道分析以【第X题】开头

## 前端展示

诊断结果在 `rtab-errors` 面板（中栏）中显示，带三级置信度标签：
- 🟢 高置信度（high） — 自动诊断
- 🟠 建议复核（medium） — AI不确定，标给教师
- 🔴 置信度低（low） — 提示重拍或人工批改
