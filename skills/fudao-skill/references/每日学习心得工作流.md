## 二、文章轮换制

无新文章时，按以下顺序轮换深度研读：

```
第1轮 → 036.五步法总结（综合温习，适合开场）
第2轮 → 034.把错题复盘透（聚焦复盘四环节）
第3轮 → 035.把思考还给孩子（聚焦教师克制力）
第4轮 → 036 再次（换角度：从AI教师执行层面审视）
第5轮 → 034 再次（换角度：从变式验证环节深挖）
第6轮 → 035 再次（换角度：从三条引导语精细拆解）
```

**原则：**
- 可重复、可反复、可回顾。目标是内化，不是学完
- 每次阅读应有新角度、新深度——记录"第N次读，这次看到的是..."
- 每次心得必须包含：**三句话收获 + 自我反思表**（见下方模板）

## 五、已知陷阱

- ⚠️ **文章目录可能不存在** — `D:\邱数智方\教育部\清简有数学习\文章\` 可能从未创建。没有新文章时，直接从 fudao-skill 技能内容中选已学文章深度研读
- ⚠️ **心得路径需要 mkdir -p** — 首次运行时 `D:\邱数智方\教育部\清简有数学习\心得\AI教师\` 可能不存在，需先创建
- ⚠️ **cron 环境 memory 不可用** — `memory()` 工具返回"Memory is not available"，这是 cron 会话隔离的正常行为。轮换进度靠心得文件的"明日学习预告"字段记录，不依赖 memory
- ⚠️ **MSYS 路径陷阱** — 在 Windows git-bash 中，`mkdir -p` 用 `/d/邱数智方/...` 格式可行，但 `write_file` 必须用原生 `D:\邱数智方\...` 格式
- ⚠️ **第三次阅读才算真正开始内化** — 前两次读的是表面内容，第三次及以后才开始看到结构、关系和盲区。不要因为"读过"就换篇目
