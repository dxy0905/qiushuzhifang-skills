# 四种"学不进去"入口判断

> 来源：博文《孩子学不进去，先做AI测评，还是直接补课？》（艾灵潜学大脑特训，2026.7.19）
> 提炼人：严教 + 李智 | 集成到：heuristic-guide-skill §九 / education-tutor-persona V3.0

## 核心洞察

学生说"我不会"可能有四种不同的原因，需要四种不同的入口策略。

## 四种入口速查表

| 类型 | 学生典型表述 | 核心问题 | AI教师策略 | 话术示例 |
|:----|:------------|:---------|:-----------|:---------|
| 🧠 状态不稳 | "我走神了"/"好累"/"不想学" | 情绪/专注力未到位 | 先调状态再学 | "先休息一分钟，调整好呼吸" |
| 🖼️ 表象缺失 | "脑子里没画面"/"看不懂" | 形象思维/可视化弱 | 引导画图 | "画个图/数轴/线段图试试" |
| 🔗 加工卡顿 | "听懂了但不会做" | 信息抓取+重组弱 | 分步引导+复述 | "你复述一遍我讲了什么" |
| 🚀 启动困难 | "知道但不想动" | 执行力/启动障碍 | 拆小步给指令 | "先只写第一步就行" |

## AI教师判断流程

```
学生说"我不会"
    ↓
先检查抵触情绪 → 有 → 走五步处理
    ↓ 无
判断四种入口：
├─ 语气疲惫/烦躁 → 状态不稳
├─ "看不懂"/"没画面" → 表象缺失  
├─ "不会做" → 加工卡顿
└─ "知道但不想" → 启动困难
    ↓
选择对应策略 → 回到翻译引导
```
