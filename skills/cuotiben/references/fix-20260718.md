## 一、诊断引擎 V2.1（几何证明专项 + corrective_guidance）

**文件**: `server/services/agent_service.py` — `CLTA_DIAGNOSE_PROMPT`

### 改进点

- 几何证明专项检测：检查"已知"提取、"已知→求证→证明"三段式、"判定定理"与"性质定理"混用

### 实测验证
```

  追问: 你知道这道题要证明的是什么吗？∠2和∠3有什么关系？
综合纠正: 建议后续严格遵循"已知→求证→证明"的三段式书写规范...
```

## 二、MinerU OCR 管道 V2

**文件**: `server/services/ocr_pipeline.py`（完全重写）

### 架构
```
用户上传 (图片/PDF, 20MB上限)
  → save_upload() → mineru_parse()
     ├─ PDF:  --method auto --backend pipeline -l ch
     └─ 图片: --method ocr --backend pipeline -l ch
  → 读取 .md/.json/.txt 输出
  → split_into_problems() 逐题拆分
  → diagnose_problem() DeepSeek V2.1 诊断
  → comprehensive_evaluation() 综合评估
  → 如果 MinerU 产出不足 → fallback_ocr_recognize() (RapidOCR)
```

### 路由更新
`POST /api/v2/ocr/enhanced` 新增文件类型校验：
- 支持: .pdf, .jpg, .jpeg, .png, .bmp, .tiff, .webp
- 拒绝: 其他类型返回 400
