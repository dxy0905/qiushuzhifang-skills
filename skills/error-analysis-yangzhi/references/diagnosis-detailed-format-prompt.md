# 错因诊断·详细格式Prompt模板（生产级）

> 2026-07-06 实战经验蒸馏
> 来源：学霸基本法 邱董反馈 - "错因只写了'概念不清'，最好是写出哪个概念不清"

## 核心铁律

**禁止笼统归因。** 不能只说"概念不清"，必须：
1. 说出具体是哪个概念/定理/公式
2. 用通俗语言解释正确理解
3. 设计引导性问题让学生自己发现错误
4. 给出变式练习

## Prompt模板

```
你是初中数学诊断专家（基于CLTA学教评一致性框架、课标对齐和错因5分类法）。
分析以下学生的答题内容。

**诊断要求：必须写出完整的因果关系，不能只贴标签。**

按以下格式逐项输出：

1. 错因类型（从以下5类中选最符合的一类）：
   - 概念不清 → **必须写出：具体是哪个概念/哪条定理/哪个公式没理解 + 正确理解应该是什么**
   - 方法不会选 → **必须写出：面对什么条件时不知道该用什么方法 + 应该用什么方法 + 为什么用这个方法**
   - 步骤不完整 → **必须写出：具体漏了哪一步 + 这一步为什么不能跳 + 完整步骤应该是什么**
   - 审题不仔细 → **必须写出：具体漏了哪个条件/看错了什么 + 正确理解题目要求是什么**
   - 迁移不足 → **必须写出：新旧情境的差异点 + 为什么本质相同但学生没看出来**

2. 判断依据：学生的原话或解题过程错在哪里。

3. 正确理解（重点）：用通俗语言解释这个概念的正确答案和推理过程。

4. 追问引导（重要）：设计1-2个引导性问题，让学生自己发现错误，
   例如"二次根式的被开方数有什么要求？""什么数才有平方根？"

5. 变式练习：设计1道同类但不同情境的题目。

学生回答：
{text}
```

## 实测效果

测试"二次根式√(x-3)有意义求x范围"案例：
- ✅ 具体概念：二次根式有意义的条件——混淆了"x≥0"和"x-3≥0"
- ✅ 正确理解：根号下是x-3这个整体，不是x本身
- ✅ 追问引导："二次根式的被开方数有什么要求？"
- ✅ 变式练习：若√(2x+4)有意义，求x的取值范围
