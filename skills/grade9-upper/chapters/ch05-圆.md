# 第二十九章 圆

## 一、核心内容

本章是初中几何的收官内容之一，学习圆的概念、基本性质以及重要的垂径定理和圆周角定理，为下一章直线与圆的位置关系打下基础。

---

## 二、各节知识点

### 29.1 圆的概念

#### 圆的定义

- **动态定义**：线段 $OA$ 绕端点 $O$ 旋转一周，另一个端点 $A$ 所形成的图形叫做**圆**。
- **静态定义**：到定点 $O$ 的距离等于定长 $r$ 的所有点组成的图形叫做**圆**。
- **圆心**：定点 $O$
- **半径**：定长 $r$

#### 圆的有关概念

| 概念 | 定义 |
|:---:|:---:|
| 弦 | 连接圆上任意两点的线段 |
| 直径 | 经过圆心的弦（最长的弦） |
| 弧 | 圆上任意两点间的部分 |
| 半圆 | 直径的两个端点分圆成的两条弧 |
| 劣弧 | 小于半圆的弧（用两个字母表示，如 $\widehat{AB}$） |
| 优弧 | 大于半圆的弧（用三个字母表示，如 $\widehat{ACB}$） |
| 等圆 | 能够重合的两个圆 |
| 同心圆 | 圆心相同、半径不同的圆 |

### 29.2 垂径定理

**定理**：垂直于弦的直径**平分弦**，并且平分弦所对的两条弧。

**推论**：平分弦（不是直径）的直径**垂直于弦**，并且平分弦所对的两条弧。

用数学语言表述：
$$
\begin{aligned}
&\text{若 } CD \text{ 为直径, } CD \perp AB \text{ 于 } E \\
&\text{则 } AE = EB,\; \widehat{AC} = \widehat{BC},\; \widehat{AD} = \widehat{BD}
\end{aligned}
$$

**应用**：已知弦长、弦心距、半径中的任意两个，可求第三个。
$$
r^2 = d^2 + \left(\dfrac{l}{2}\right)^2
$$
其中 $r$ 为半径，$d$ 为弦心距，$l$ 为弦长。

### 29.3 圆周角定理

**定义**：顶点在**圆上**，并且两边都与圆**相交**的角叫做圆周角。

**圆周角定理**：一条弧所对的圆周角等于它所对的圆心角的**一半**。

$$
\angle ACB = \dfrac{1}{2} \angle AOB
$$

**推论 1**：同弧或等弧所对的圆周角相等。

**推论 2**：半圆（或直径）所对的圆周角是直角；$90^\circ$ 的圆周角所对的弦是直径。

$$
\text{若 } AB \text{ 为直径, 则 } \angle ACB = 90^\circ
$$

### 29.4 点和圆的位置关系

设 $\odot O$ 的半径为 $r$，点 $P$ 到圆心 $O$ 的距离为 $d$：

| 位置关系 | 条件 | 图示特征 |
|:---:|:---:|:---:|
| 点在圆内 | $d < r$ | 点 $P$ 在圆的内部 |
| 点在圆上 | $d = r$ | 点 $P$ 在圆上 |
| 点在圆外 | $d > r$ | 点 $P$ 在圆的外部 |

#### 确定圆的条件

- **不在同一直线上的三点确定一个圆**。
- 三角形有且只有一个外接圆。
- 三角形的**外心**：三条边的中垂线交点，到三个顶点距离相等。

## 三、典型题型

### 题型1：垂径定理的应用

**例**：在 $\odot O$ 中，弦 $AB = 8$，圆心 $O$ 到 $AB$ 的距离为 $3$，求半径 $r$。

**解**：设 $OE \perp AB$ 于 $E$，则 $AE = 4$。
$$
r = OA = \sqrt{3^2 + 4^2} = 5
$$

### 题型2：圆周角定理

**例**：如图，$\odot O$ 中，$\angle AOB = 100^\circ$，求 $\angle ACB$ 的度数。

**解**：$\angle ACB = \dfrac{1}{2} \angle AOB = 50^\circ$。

### 题型3：直径所对的圆周角

**例**：如图，$AB$ 为 $\odot O$ 的直径，$\angle ABC = 30^\circ$，求 $\angle BAC$。

**解**：$\because AB$ 为直径，$\therefore \angle ACB = 90^\circ$。
$\angle BAC = 90^\circ - 30^\circ = 60^\circ$。

### 题型4：点和圆的位置关系

**例**：$\odot O$ 半径为 $3$，点 $P$ 到圆心 $O$ 的距离为 $4$，点 $Q$ 到圆心距离为 $2$。判断 $P, Q$ 与 $\odot O$ 的位置关系。

**解**：$4 > 3 \implies P$ 在圆外。$2 < 3 \implies Q$ 在圆内。

### 题型5：利用垂径定理求弦长

**例**：$\odot O$ 半径为 $10$，弦 $AB$ 的弦心距为 $6$，求 $AB$ 的长。

**解**：
$$
AB = 2 \times \sqrt{10^2 - 6^2} = 2 \times 8 = 16
$$

## 四、易错点

1. **忽视圆的对称性条件**：垂径定理中"垂直于弦的直径"缺一不可。
2. **弦和直径混淆**：直径是特殊的弦（经过圆心的弦），但不是所有弦都是直径。
3. **圆弧表示不规范**：劣弧用两个字母，优弧用三个字母，不可混淆。
4. **圆周角定理"一半"关系记反**：圆周角等于圆心角的一半，不是圆心角等于圆周角的一半。
5. **"三点确定一个圆"忽略不共线**：共线的三点不能确定圆。
6. **外心位置搞错**：锐角三角形的外心在三角形**内**，直角三角形的外心在**斜边中点**，钝角三角形的外心在三角形**外**。
7. **同弧所对圆周角相等的条件不能忘**：必须是"同弧"或"等弧"。
