## 四、技术方案

- 前端：纯HTML/CSS/JS，PWA支持
- 加密：AES-128-CBC+HMAC（Fernet）
- 认证：JWT（PyJWT库）
- 数据库：SQLite，全部参数化查询
- 验证：三级验证（L1姓名手机/L2+身份证/L3+人脸）
- 审计：链式哈希审计日志
- 托管：GitHub Pages（免费）
