# OCR数学符号纠错全表（2026-07-12扩充版）

## 第1层：基本字符串替换（精确匹配，执行顺序在前）

| OCR输出 | 修正后 | 说明 |
|:--------|:-------|:-----|
| `V` | `√` | 大写V误识为根号 |
| `J` | `√` | 大写J误识为根号 |
| `士` | `±` | 正负号误识 |
| `! =` | `≠` | 不等号（有空格） |
| `!=` | `≠` | 不等号（无空格） |
| `< =` | `≤` | 小于等于（有空格） |
| `<=` | `≤` | 小于等于（无空格） |
| `> =` | `≥` | 大于等于（有空格） |
| `>=` | `≥` | 大于等于（无空格） |
| `~~` | `≈` | 约等于 |
| `~=` | `≈` | 约等于（变体） |
| `>Q.X7` | `√` | 极端根号误识 |
| `VX` | `√` | 根号变体 |
| `JX` | `√` | 根号变体 |
| `)√` | `) √` | 选项括号后空格 |
| `)×` | `) ×` | 选项括号后空格 |
| `兀` | `π` | 圆周率误识 |
| `TT` | `π` | π大写误识 |
| `n` | `π` | π小写误识（⚠ 仅在数学上下文中，可能误伤英文n） |
| `△` | `Δ` | 三角形误识为希腊字母Δ |
| `0/0` | `%` | 百分号误识 |
| `°/°` | `%` | 百分号误识 |
| `0/o` | `%` | 百分号误识 |
| `进步1）` | `进步！）` | 感叹号误识为1（全角括号版） |
| `进步1)` | `进步！)` | 感叹号误识为1（半角括号版，全角转半角后） |

**⚠ 不要**在基本替换中直接删掉 `·`（中点乘号）。应留给第3层用上下文判断。

## 第2层：全角符号转半角

| 类别 | 全角→半角 |
|:-----|:----------|
| 数字 | `０１２３４５６７８９` → `0123456789` |
| 大写字母 | `ＡＢＣＤ...Ｚ` → `ABCD...Z` |
| 小写字母 | `ａｂｃｄ...ｚ` → `abcd...z` |
| 运算符 | `＋－×÷＝＜＞` → `+-×÷=< >` |
| 括号 | `（）｛｝` → `(){}` |
| 标点 | `．，：` → `.,:` |

## 第3层：正则上下文修复

### 1. 乘号修复
```
(\d)\s*[xX]\s*(\d)    →  \1×\2      例: 5x3 → 5×3
(\d)\s*·\s*(\d)        →  \1×\2     例: 3·5 → 3×5  (⚠第1层不要删·)
```

### 2. 上标（字母/数字后跟数字或^）
| 正则 | 替换 | 示例 |
|:-----|:-----|:------|
| `(\d)\s*\^\s*2\b` | `\1²` | `5^2` → `5²` |
| `(\d)\s*\^\s*3\b` | `\1³` | `5^3` → `5³` |
| `([a-z])\s*\^\s*2\b` | `\1²` | `x^2` → `x²` |
| `([a-z])\s*\^\s*3\b` | `\1³` | `x^3` → `x³` |
| `([a-z])2\b` | `\1²` | `x2` → `x²` |
| `([a-z])3\b` | `\1³` | `x3` → `x³` |
| `([a-z])\s*\^\s*-1\b` | `\1⁻¹` | `x^-1` → `x⁻¹` |

### 3. 分数横线
```
_{2,} → ─    例: ___ → ─
-{3,} → ─    例: --- → ─
```

### 4. 小数点空格
```
(\d)\.\s+(\d) → \1.\2    例: 0. 01 → 0.01
```

### 5. 变量x被识别为数字1
```
(?<!\d)(1)(?=[≤≥<>=](?:\s*\d|\s*x|\s*√|\s*[a-z]))  →  x
```
例: `1≤3` → `x≤3` ✅, `12` → `12` ✅（后顾断言保护）, `x=1` → `x=1` ✅（不在不等式前）

```
(?<=[≤≥<>=])\s*1\s*\) → x)    例: 2≤1) → 2≤x)
(取值范围是)\s*1\s*([≤≥]) → \1x\2  例: 取值范围是1≤3 → 取值范围是x≤3
(?:^|(?<=[，。；\n]))\s*1\s*(?=[≤≥<>=]) → x  例: 「1<-5」→「x<-5」
```

### 6. 大写X→小写x（数学上下文中）
```
(?<=[≤≥<>=+\-×÷√(])\s*X\b → x     运算符后的X
\bX\s*(?=[≤≥<>=])          → x     不等式前的X
^X\b                        → x     行首X（答案行）
```
例: `X≥0` → `x≥0`, `X≤3` → `x≤3`

### 7. √括号补全
```
√([a-z])\s*([≤≥<>=+\-×÷])\s*(\d)  →  √(\1\2\3)     √x+4 → √(x+4)
√(\d+)\s*([+\-])\s*(\d)            →  √(\1\2\3)     √4-3 → √(4-3)
√\(([^)]+)$                         →  √(\1)         √(x+4( → √(x+4())
```

### 8. 选项后加空格
```
([A-Za-z])\.([√×±]) → \1. \2     A.√7 → A. √7
([A-Za-z])\.(\d)     → \1. \2     A.8 → A. 8
```

### 9. 括号平衡
```
open_c = text.count('(') - text.count(')')
if 0 < open_c < 5: text += ')' * open_c
```
仅补末尾缺失括号，不过度补（open_c≥5时不补，可能是误判）。

## 修复顺序陷阱（常见bug来源）

```
❌ 错误顺序：
   第1层: ("·", "")      ← 直接删中点
   第3层: 3·5 → 3×5     ← 匹配不到了！

❌ 错误顺序：
   第1层: ("进步1）", "进步！）")  ← 全角括号版
   第2层: 全角→半角
   结果: 进步1）→ 进步！)         ← 全角转半角把）变成)了
   ✅ 正确：在修复表同时加半角版 "进步1)"→"进步！)"

✅ 正确顺序：
   第1层基本替换  →  第2层全角转半角  →  第3层正则修复
```
