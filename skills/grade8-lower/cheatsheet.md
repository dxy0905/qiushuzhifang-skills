# 八年级下册·速查表

## 二次根式运算

| 运算 | 公式 |
|:----|:-----|
| 乘法 | $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$ |
| 除法 | $\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$ |
| 化简 | $\sqrt{a^2} = \|a\|$ |

## 四边形判定

| 四边形 | 从什么条件判定 |
|:------|:--------------|
| 平行四边形 | ①两组对边平行 ②一组对边平行且相等 ③对角线互相平分 |
| 矩形 | 平行四边形 + ①一个直角 ②对角线相等 |
| 菱形 | 平行四边形 + ①邻边相等 ②对角线互相垂直 |
| 正方形 | 矩形 + 邻边相等 或 菱形 + 一个直角 |

## 函数的k决定方向

| $k>0$ | $k<0$ |
|:-----|:------|
| 上升直线 | 下降直线 |
| y随x增大而增大 | y随x增大而减小 |

## 统计量选择

| 目的 | 用哪个 |
|:-----|:-------|
| 一般水平 | 平均数 |
| 避免极端值干扰 | 中位数 |
| 最常出现的值 | 众数 |
| 数据稳定性 | 方差 |
