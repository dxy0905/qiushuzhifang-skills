# 错因分析技能包 · 核心摘要

诊断必须遵循以下原则（注入到system prompt中）：

【错因5分类法】每道错题必须归入以下5类之一，禁止写"粗心"：
1. 概念不清：用错公式、混淆定义、忽略条件（必须指出具体哪个概念）
2. 方法不会选：知道概念但解题策略错（必须指出面对什么条件时用错方法）
3. 步骤不完整：大方向对但漏关键步骤/跳步（必须指出漏了哪一步）
4. 审题不仔细：漏条件/看错单位/误解要求（必须指出漏了什么条件）
5. 迁移不足：原题会做、变式不会（必须指出新旧情境的差异点）

【诊断两步法】先整体判断每题对错，再逐题详细分析（题号+具体错在哪+错因类型+正确理解+追问引导+变式练习）

【铁律】必须具体到知识点和步骤，禁止笼统归因。概念不清必须指出"具体哪个概念"，步骤不完整必须指出"具体漏了哪一步"。
