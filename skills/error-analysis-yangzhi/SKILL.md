## 二、策略一：错因5分类法（归因诊断）

### 核心原则

学生做错一道题，原因不可能是"粗心"两个字能概括的。必须精确到以下5类之一：

| 错因类型 | 学生表现 | 判断方法 | 讲评重点 | 对应训练 |
|:--------:|:---------|:---------|:---------|:---------|
| **① 概念不清** | 混淆两个概念、定义记错、公式用错 | 问"这是什么概念？"学生说不清 | 重新辨析概念边界，追溯定义源头 | 概念辨析题+举例说明题 |
| **② 方法不会选** | 知道公式但不知道什么时候用 | 问"为什么用这个方法？"学生答不上 | 建立"条件→方法"映射关系 | 方法判断题+多解法对比 |
| **③ 步骤不完整** | 大方向对但漏关键步骤、跳步 | 看过程：思路方向正确但中间有断点 | 补足完整解题流程，标注关键步骤 | 步骤填空题+流程排序题 |
| **④ 审题不仔细** | 漏条件、看错单位、误解要求 | 重新读题后学生能自己发现错误 | 训练"圈条件、标问题"的审题习惯 | 审题专项+信息标注练习 |
| **⑤ 迁移不足** | 原题会做、变式不会、换情境就错 | 同知识点换包装后无法识别 | 找变式与原题的共同结构 | 同类变式组+结构对比题 |

### 诊断流程（五步法）

```
Step 1: 定位错因 → 从5类中选一种，禁止写"粗心"
Step 2: 判断依据 → 为什么归为此类？学生的具体表现？
Step 3: 讲评策略 → 该类型对应什么讲评方式？
Step 4: 变式训练 → 设计同类错因的不同情境题
Step 5: 验证过关 → 变式题正确率 ≥ 80%
```

### 直接可用的AI提示词（生产级）

**铁律：必须具体到知识点和步骤，禁止笼统归因。** 不能只说"概念不清"，必须指出"不理解角平分线定理中'距角两边'的'两边'具体指哪两条边"。

```
我是一名初中数学老师，以下是一道学生的错题：

【题目】[粘贴题目]
【学生答案】[粘贴学生答案]
【正确答案】[粘贴正确答案]

请你按以下要求分析，**必须具体到知识点和步骤**：

1. 错因类型（从以下5类中选最符合的一类）：
   - 概念不清：**必须指出具体哪个概念不理解**，如"不理解角平分线定理""混淆了配方法和公式法"
   - 方法不会选：**必须指出面对什么条件时不知用什么方法**，如"已知两边及夹角应选用余弦定理但用了正弦定理"
   - 步骤不完整：**必须指出漏了哪一步**，如"配方法写到一半没继续完成""设未知数后没列方程"
   - 审题不仔细：**必须指出具体漏了什么条件**，如"没注意到'保留两位小数'的要求""把'无实数根'理解为'有两个实数根'"
   - 迁移不足：**必须指出新旧情境的差异点**

2. 判断依据：**必须引用学生的原话或解题过程**
3. 讲评重点：该类型应该怎么讲？**给出具体的追问问题**，如"点M到BA和BC的距离相等吗？BA和BC是同一个角的两边吗？"
4. 设计1道同类变式题（同一知识点，换情境）
5. 设计1个追问问题（引导学生自己发现错误）
```

### 实战陷阱（2026-07-06经验）

| 陷阱 | 表现 | 对策 |
|:-----|:------|:------|
| **笼统归因** | 只说"概念不清"不说是哪个概念 | Prompt中加粗强调"必须指出具体哪个概念" |
| **不引用学生原话** | 判断依据写得像教案 | 要求"引用学生原话" |
| **错因与依据脱节** | 说"审题不仔细"但依据是"公式记错了" | 要求"引用学生原话"作为判断锚点 |
| **api_v2响应未解包** | 前端收到`{code:0, data:{analysis}}`但直接读`analysis`为undefined | 前端先判断`data.code !== undefined`则取`data.data` |
| **openai + jiter版本冲突** | `ImportError: cannot import name 'from_json' from 'jiter'` | `pip install --ignore-installed jiter==0.15.0` |
| **PaddleOCR兼容性** | PaddleOCR v6 + PaddlePaddle版本冲突 → NotImplementedError | 改用RapidOCR（`rapidocr-onnxruntime`） |

## 三、策略二：练习课5类题设计法（训练架构）

### 核心理念

好的练习课不是难度堆叠，而是一条思维路径。

### 5类题设计表

| 环节 | 题型 | 作用 | 设计重点 | 题量建议 |
|:----:|:----:|:-----|:---------|:--------:|
| 第1步 | **唤醒题** | 帮学生回忆关键知识 | 简单、短、能快速进入状态 | 2-3道 |
| 第2步 | **辨析题** | 暴露易错点和概念混淆 | 设计相似情境、错误选项 | 2-3道 |
| 第3步 | **变式题** | 发现变化中的不变关系 | 改条件/改问法/改情境 | 3-4道 |
| 第4步 | **解释题** | 让学生说清楚为什么 | 要求写理由、讲方法、找依据 | 1-2道 |
| 第5步 | **迁移题** | 把方法用到新情境 | 生活化、综合化、有陌生感 | 1-2道 |

### 练习课设计提示词

```
我是一名初中数学老师，正在设计一节练习课。
本节练习课的核心知识点是：[填写]
学生已掌握情况：[填写]
学生常见错误：[填写]

请你帮我设计一节练习课，包含以下5类题（每题附答案和讲解要点）：
1. 唤醒题（2道）— 帮学生快速回忆关键知识
2. 辨析题（2道）— 暴露典型的易错点
3. 变式题（3道）— 条件递进，让学生看到不变的本质
4. 解释题（1道）— 让学生说清"为什么这样做"
5. 迁移题（1道）— 把方法用到生活化情境中

每道题请标注：题型、考察点、参考答案、讲评要点。
```

## 四、策略三：错误变学习资源法（讲评流程）

### 核心理念

讲评课最重要的不是讲错题，而是分错因。按题号讲，学生记住的是一道题的做法；按错因讲，学生学会的是一类问题的解决方法。

### 讲评五步流程

```
① 错误分析
   → 把零散错误按错因5分类整理
   → 统计：哪类错因最多？哪类最严重？

② 分类讲评
   → 按错因类型讲，不按题号讲
   → 先讲最常见的错因，再讲个别的

③ 课堂追问
   → 每类错因设计1个引导追问
   → 追问目的：引导学生自己发现错误原因

④ 变式练习
   → 每类错因设计1道同类变式题
   → 当场检测学生是否真的听懂了

⑤ 方法提醒
   → 每节课总结一句学生能带走的方法
   → 例如："看到二次函数顶点式，先看a的符号"
```

### 讲评设计提示词

```
我是一名[学段+学科]老师，刚完成一次课堂练习。

本节课学习目标是：[填写]
练习题/题型是：[简单描述]
学生常见错误包括：
1. [错误表现1]
2. [错误表现2]
3. [错误表现3]

请你不要直接给答案解析，而是帮我把这些错误变成一次有价值的讲评设计。

请按以下结构输出：
1. 把学生错误分成几类错因（用错因5分类法）
2. 判断每类错误背后可能缺失的知识、方法或思维步骤
3. 每类错误设计1个课堂追问
4. 每类错误设计1道变式练习
5. 帮我安排一个10分钟讲评流程
6. 最后生成一句学生能带走的方法提醒
```

### 错因5分类 × 课堂追问对照表

| 错因类型 | 课堂追问示例 |
|:--------:|:------------|
| 概念不清 | "这道题考的是什么概念？这个概念的定义是什么？能用你自己的话说说吗？" |
| 方法不会选 | "题目给了什么条件？这些条件让你想到哪些方法？为什么这个方法是合适的？" |
| 步骤不完整 | "你的大方向是对的。但看看从这一步到这一步，中间跳过了什么？我们来补上。" |
| 审题不仔细 | "先不急着做，把题目重新读一遍。用笔圈出关键条件。现在看看有没有新发现？" |
| 迁移不足 | "这道题和刚才做对的那道题，有什么相同的地方？有什么不同的地方？" |

## 五、策略四：学生问题行为分析法（学情诊断）

### 核心理念

同一个行为背后可能有多个原因，定性太快方法就少。

### 三步分析法

```
第一步：评价 → 事实
   把"不认真""态度差"等评价性语言
   改写为可观察、可记录的行为事实

第二步：单因 → 多因
   从多个角度分析行为背后的可能原因
   （规则理解/表达需求/任务难度/情绪冲动等）

第三步：多入口 → 最小入口
   从一堆可能原因中找出最容易试的那个
```

### 行为分析提示词

```
学生在课堂上经常[描述具体行为，如"上课插嘴""独立练习时走神""作业拖拉"]。

请你不要给学生贴标签，而是帮我从多个角度分析这个行为背后的可能原因。

请从以下角度分析：
1. 规则理解
2. 表达需求/任务启动
3. 获得关注/寻求帮助
4. 任务难度匹配
5. 情绪冲动/自控力
6. 教师反馈方式
7. 同伴反应/环境影响

每个角度请说明：可能原因是什么、还需要观察什么、老师可以先尝试什么调整。
```

## 十一、2026-08-02 V2.1 升级：变式三形式 + 错题生命周期（墨安AI复习系统精华）

> 蒸馏来源：公众号「墨安的AI工坊」《很多人问我这个AI复习系统怎么做》
> 核心启发：错题要产生复利——**同构保底、变条件练迁移、反向练逆向，错题库→组卷→标记→专攻闭环**

### 11.1 变式三形式标准（升级策略一·错因5分类的变式训练）

**每道错题的变式题必须标注形式，禁止只写"变式题"笼统输出：**

| 形式 | 定义 | 目的 | 设计要点 | 适用错因 |
|:----:|:-----|:-----|:---------|:---------|
| **① 基础同构** | 换数字/换名称，结构与原题完全相同 | 保底巩固，确认真的懂了 | 只改数值，不改条件结构和问法 | 概念不清、步骤不完整 |
| **② 条件变化** | 改条件/改问法/改情境，保持知识核心 | 检验是否掌握本质而非背题 | 改一个条件或换情境包装 | 方法不会选、迁移不足 |
| **③ 反向综合** | 逆向设问/多知识点综合 | 训练逆向思维和综合运用 | 已知结论求条件、多知识点串联 | 迁移不足、审题不仔细 |

**诊断Prompt变式部分升级为：**
```
4. 设计3道变式题（必须标注形式）：
   - 基础同构1道：换数字不换结构（确认基础）
   - 条件变化1道：改条件/改情境（检验迁移）
   - 反向综合1道：逆向设问/综合（训练思维）
```

### 11.2 错题生命周期管理（升级策略三·错误变学习资源）

**核心：错题不能分析完就结束，要进入"错题库→组卷→标记→专攻"循环**

```
┌─────────────────────────────────────────────────┐
│            错题生命周期（五阶段闭环）              │
├─────────────────────────────────────────────────┤
│                                                   │
│  ① 错题入库   诊断后错题+错因+变式写入错题库       │
│  ② 自动组卷   按错因类型/知识点从错题库组练习卷    │
│  ③ 练习检测   学生完成组卷，AI批改判定掌握度       │
│  ④ 标记留存   未掌握题标记"需专攻"（掌握<80%）     │
│  ⑤ 下轮专攻   新卷优先包含标记题，直到掌握过关     │
│                                                   │
└─────────────────────────────────────────────────┘
```

**与学霸基本法BKT对接**：
- 掌握概率 ≥ 80% → 移出错题库（过关）
- 掌握概率 < 80% → 保持"需专攻"标记，下轮组卷优先
- 每轮组卷配比建议：标记题60% + 新错题30% + 已过关题10%巩固

**组卷提示词（升级策略二）：**
```
我有一批已诊断的错题，错因类型如下：
[粘贴错题列表：题号/知识点/错因/掌握概率]

### 12.1 间隔重复节奏表（升级错题生命周期，核心新增）

**错题不能分析完就结束，必须按记忆曲线间隔拉练：**

| 复习轮次 | 间隔 | 目的 | 触发方式 |
|:--------:|:----:|:-----|:---------|
| 第1轮 | 当天 | 趁热巩固，当场练3道变式 | 诊断后立即 |
| 第2轮 | 第2天 | 检验短期记忆 | 自动提醒 |
| 第3轮 | 第4天 | 巩固中期记忆 | 自动提醒 |
| 第4轮 | 第7天 | 检验是否真掌握 | 自动提醒 |
| 第5轮 | 第15天 | 长期巩固，防止遗忘 | 自动提醒 |

**铁律：错得越狠的题，前面几次间隔越短（压缩到1/2/4天）。**
- 概念不清/思路中断（根本性错误）→ 当天+第2天+第4天 密集拉练
- 计算失误/审题偏差（局部错误）→ 当天+第4天+第7天 常规节奏

### 12.2 对话式辅导模式（"平均速度式"盯人法，核心新增）

**AI（老师）辅导不是甩答案，而是"点错因→递思路→当场练→验证"四步：**

```
Step 1 点错因：先指出具体错在哪（如"你把'平均速度'当成了'速度平均'，这是审题问题"）
Step 2 递思路：把正确思路拆成Step1/Step2/Step3，一步步递给学生
Step 3 当场练：给3道同类型题，不直接给答案，让学生算完告诉AI
Step 4 验证：学生给答案后判定对错，再给下一批变式
```

**对话模板（学生直接可用）：**
```
我是[年级]学生，刚做错了一道题，照片在上面。请帮我：
1）找出我到底错在哪（概念不清 / 计算失误 / 审题问题）
2）用我能懂的话讲清楚正确思路
3）出 3 道同类型题让我当场练，别直接给答案，一步步提示
```

### 12.3 三类错因快速定位（升级策略一·简化版）

| 错因 | 判断标志 | 讲法 |
|:-----|:---------|:-----|
| 概念不清 | 不知道用什么定理/公式 | 先补概念，用例子讲定义 |
| 计算失误 | 方法对但算错 | 指出哪一步算错，练同类计算 |
| 审题问题 | 漏条件/误解题意 | 圈条件重读题，确认理解 |

**与错因5分类法的关系**：5分类是精细版（教学用），3分类是快速版（学生对话用）。

**每道错题分析必须包含：**

第一步：整体判断
列出每题对错：第1题✅正确/❌错误（具体错在哪）...

第二步：逐题详细分析
【第X题】
- 题号：第X题
- 具体错在哪：学生写的是什么 / 正确答案是什么

- 详细说明：推理链条哪里断了 / 区分"概念没掌握"还是"运算没学会"
- 正确理解：正确知识
- 追问引导：引导学生发现错误的问题
- 变式练习：同类题
```

## 十三、2026-08-06 V2.3 升级：家庭辅导场景 · 拍照讲题流水线（严教+李智联合蒸馏）

> 蒸馏来源：公众号博文《辅导作业别吼了：我用 AI 搭了条拍照讲题+错题本的流水线》
> 核心启发：**讲思路不答答案（脚手架梯度）· 情绪价值是辅导的一部分 · 讲解深度按年级调节 · 错题本四块模板 · AI 输出必须人工核对**
> 定位：v2.2 管「诊断与复习」（怎么归因、何时练）；v2.3 新增部分管「讲解与记录」（怎么讲、讲时说什么、记什么）。两者闭环：拍照OCR → 四块模板入库(§13.5) → 五分类归因(策略一) → 三级提示讲题+情绪语言(§13.2/13.3) → 双状态标记进间隔重复(§12.1) → 正确性核对收口(§13.7)

### 13.1 拍照讲题五步流水线（家庭辅导场景标准流程）

拍照讲题不是"上传→诊断"直连，拆五步，每步职责单一、可独立替换：

```
Step 1 拍照：打印题/手写题均可，光线充足、画面清晰（别拍孩子姓名学校，隐私红线）
Step 2 识字(OCR)：照片→OCR抽题目文字；手写体置信度低时必须提供「人工修正」入口，
        禁止把OCR原文直接喂给诊断模型（错字会带偏归因）
Step 3 讲思路(诊断)：输入=题目+年级+薄弱点；输出=分步思路，禁止直接给答案
        指令模板：「别直接给答案，先用孩子能懂的话讲第一步思路，
        卡住时给个提示不剧透，最后出一道类似的让他练」
Step 4 格式化：诊断结果按四块模板(§13.5)规整，统一Markdown结构后再入库
Step 5 入库：按科目/日期归档，标「已搞懂/还糊涂」；复习只拉「还糊涂」的
```

### 13.2 讲题提示三级梯度（升级 §12.2 对话式辅导·Step2"递思路"）

**铁律：永远不替学生跨最后一步。** 学生卡住时按三级逐级递提示，每级之间停下等学生反应：

| 级别 | 提示内容 | 示例（几何证明题） | 适用 |
|:----:|:---------|:-------------------|:-----|
| L1 方向提示 | 只指方向不指具体步骤 | "想想这道题和'中点'有关的定理有哪些？" | 学生完全无头绪 |
| L2 半步提示 | 点出第一步留其余 | "连接BD这条辅助线，然后呢？" | L1后仍卡住 |
| L3 换路提示 | 换一种思路重看题目 | "换个思路试试：从结论往回推，要证∠A=∠C需要什么？" | 原思路走死 |

**Prompt 强制要求：** 每次只给 1 条提示，提示后必须停下等学生回应，禁止连给三级；学生说出正确方向立即进入"当场练"，不重复讲解。判断标准：提示后学生能自己完成剩余步骤=辅导成功；直接讲完=失败。

**口语化提示金句：** "先说说你读题后想到了什么？" → "你的第一步是对的，卡住的是第二步" → "如果把条件换个顺序看呢？" → "你离答案很近了，再走半步"

### 13.3 讲题过程情绪语言（补 §10.2 家长视角的"过程语言"维度）

**原则：情绪价值是辅导的一部分，不是附加项。** §10.2 是结果报告语言（诊断输出怎么说），本节是讲题过程语言（讲题中怎么鼓励怎么接话）。

**三句金句（好未来1.8亿次讲题验证）：**
- "再想想" —— 学生答错时，不否定，给二次机会
- "你很接近了" —— 学生思路对了一半，先肯定再递提示
- "换个思路试试，第一步是对的" —— 学生走死路时，锚定已有正确部分再转向

**话术对照表（禁止→鼓励）：**

| 禁止（吼/否定） | 鼓励（过程语言） |
|:----------------|:-----------------|
| "这题上课没听吗？" | "这题确实有点绕，我们一步一步来" |
| "怎么又错了？" | "错了没关系，错在哪正是我们要找的" |
| "答案是42，抄吧" | "你先说说到哪一步卡住了？" |
| "这么简单都不会" | "你第一步已经对了，继续" |

**Prompt 要求：** 讲题输出中必须包含情绪语言，每步思路前先给一句肯定/鼓励；学生反复受挫（≥2次卡住）时先安抚情绪再讲题（"先歇10秒，这道题我们换个角度"）。

**角色分工铁律：AI 负责讲题与情绪稳定的陪练语言，家长负责夸奖与陪伴（AI 替不了的"爱心评语"）。** AI 的输出应让家长"坐旁边听他哦那一声就行"，不替代亲子互动。

### 13.4 讲解深度三档调节（学习进阶适配）

**原则：年级决定语言层级，薄弱点决定停留时长。** 每次辅导前先确认两个参数：

**参数一：年级 → 语言层级**

| 学段 | 语言要求 | 示例（讲分数除法） |
|:----:|:---------|:-------------------|
| 小学 | 不用术语，用生活例子 | "把3/4块蛋糕平均分给2个人" |
| 初中 | 允许术语但需先解释 | "除以一个数等于乘它的倒数，倒数就是分子分母颠倒" |
| 高中 | 术语+原理推导 | "从有理数运算律验证'除以=乘倒数'" |

**参数二：薄弱点清单 → 停留机制**
- 家长/老师事先给 1-3 条薄弱点（如"应用题读不懂题意"）
- 讲题时凡触及薄弱点，**讲解放慢多停留一轮**：先确认理解→再往下走；未触及的正常速度带过

**Prompt 升级（在 §12.2 对话模板上追加）：**
```
我是[年级]学生，薄弱点是[1-3条]。
请按我的年级调整讲解语言（小学不用术语/初中术语需解释/高中可推导），
凡讲到与我的薄弱点相关的步骤，请放慢并先确认我理解再继续。
```

**铁律：禁止用高年级语言讲低年级内容（"别用初中的话说给小学生听"）。**

### 13.5 错题本四块记录模板 + 双状态标记（升级 §11.2 入库环节）

**每条错题按固定四块入库，禁止自由发挥：**

| 块 | 内容 | 填写要求 |
|:--:|:-----|:---------|
| ① 原题 | 截图或文字 | 完整题面，可回溯 |
| ② 卡在哪 | **孩子原话**（如"我不知道为什么这里是乘不是加"） | 禁止教师转述，必须是学生亲口表述；说不出时用追问引出（"你做到哪一步觉得不对了？"） |
| ③ 讲题思路 | 分步思路（含错因5分类标记） | 每步之间留白，标注学生当时卡在哪一步 |
| ④ 同类题一道 | 变式题（标注形式：同构/变条件/反向） | 按 §11.1 变式三形式标准 |

**与 BKT 对接：** 状态标记「已搞懂」= BKT 掌握≥80%；「还糊涂」= <80% 保持"需专攻"。周末复盘只复习"还糊涂"；"已搞懂"进入 §12.1 间隔重复的长间隔轮次（第7/15天）。

**"卡在哪"进阶用法：** 收集 10 条以上孩子原话后可做高频卡点统计（"孩子总说'不知道从哪下手'→方法选择类错因为主"），反哺薄弱点清单。

**Prompt 模板：**
```
请把这道错题按四块模板整理成错题本条目：
① 原题：[题面]  ② 卡在哪：[孩子的原话，没有就问]
③ 讲题思路：分步写出，标注卡点位置和错因类型（5分类）
④ 同类题1道：标注变式形式（同构/变条件/反向）
末尾标注状态：「已搞懂 / 还糊涂」
```

### 13.6 双模型成本路由（reasoning / default 分步）

- **reasoning（强模型）**：讲思路、判断卡在哪、定讲解深度、验算核对 —— 上游决策，值得多花token
- **default（弱/便宜模型）**：OCR文本整理、错题本批量生成、格式化、变式题量产出 —— 量大，不烧推理

**路由规则：同一次诊断内按步骤切换，禁止全流程都用强模型。**
```
API调用顺序：OCR后处理(default) → 题意理解+错因判定(reasoning)
→ 验算核对(reasoning或default二次调用) → 变式+格式化(default)
```

### 13.7 AI 输出正确性核对（质量底线 + 幻觉防护四层）

**铁律：AI 讲完的每道题，学生或家长必须自己算一遍确认，尤其是计算题和冷门知识点。AI 输出≠标准答案。**

**核对流程（讲题后 1 分钟内完成）：**
1. 重算一遍，与 AI 答案比对
2. 不一致时：以重算为准，并检查 AI 推理链哪一步错（新错因："AI 误导"，同样按5分类归因，多归为方法不会选/迁移不足的知识性问题，而非学生错因）
3. 计算题、冷门知识点（低频概念/超纲题）必核；常规题抽核

**工程落地四层（学霸基本法生产）：**

| 层级 | 措施 | 实现要点 |
|:----:|------|---------|
| ① 计算题程序验算 | 诊断输出数值答案用 sympy/白名单eval 独立求值比对；不一致→降级"待人工核对"不直接展示 | 数学学科覆盖 80% 计算题；代数式 sympy 化简对比 |
| ② 双模型交叉验证 | 答案字段第二次独立调用（换模型或换角色："请独立验算，不要参考上一步结论"）；两次一致才标"已核对" | 验算用 default 模型+短prompt；冷门知识点强制走此层 |
| ③ 输出结构强制 | 诊断每条必须带「验算步骤」字段；冷门知识点模型须自我标注"此知识点较冷门，请人工核对" | 呼应"必须具体到知识点"铁律，加答案可信度标注 |
| ④ 前端兜底+回流闭环 | 诊断结果页固定显示"AI生成，请核对"；「答案存疑」一键标记→该题回流错题库并降 BKT 掌握概率 | 与「需专攻」打通，形成 存疑→复核→重练 闭环 |

**产品提示词（诊断端）：** 诊断输出末尾固定附：
"⚠️ 以上分析由 AI 生成，请人工核验答案与关键步骤后再用于教学。"

**防幻觉补充：** 讲题时 AI 不确定的知识点必须明说"这个点我不确定，需要查课本确认"，禁止编造；禁止虚构"常见错误"统计数据。

### 13.8 实战陷阱（v2.3 新增）

| 陷阱 | 表现 | 对策 |
|:-----|:------|:-----|
| 直接甩答案 | 学生照抄，流水线变抄作业工具 | 讲思路指令强制"提示不剧透"+三级梯度 |
| 提示一次给太多 | 三级连发，学生没有思考时间 | 每次只给1条，停下等回应 |
| 高年级语言讲低年级题 | 小学生听不懂术语 | 年级参数强制匹配语言层级（§13.4） |
| 错题本自由发挥 | 记录结构乱，无法统计复盘 | 四块模板固定，禁止自由发挥 |
| AI 输出全信 | 错答案教给孩子，纠正成本极高 | 核对铁律+四层幻觉防护（§13.7） |
| OCR 错字直接喂模型 | 识别错字带偏归因 | 手写体置信度低时人工修正入口 |

## 十二、V2.4 升级：粗心归因三分类（家庭场景 + AI 诊断）

### 14.1 归因总纲：粗心 = 尚未查清的原因（v2.4 新增）

> 蒸馏来源：清简《059.错题管理第二讲：孩子做错了，先别急着说粗心》
> 核心命题：**粗心不是原因，是诊断未完成的托词**。错误原因不同，处理方法就不同；停留在"粗心"上，订正必然失灵。
> 三问口诀（定位→分类→对症）：**错从哪一步开始？这一步是不知道、想错了，还是执行出了偏差？问清楚，订正才算真正开始。**

**铁律A「第一错误步定位」**：订正第一步不是看正确答案，而是重读学生原始解题思路，**从头到尾反向找第一个走错处**——归因从"结果对错"转向"过程断点定位"，落到步骤级。
- 例证（博文）："小明比小红多5张卡片，小明有15张，小红几张？"孩子写 15+5=20。**15+5 本身算对了**，错在计算之前：看到"多5"却未区分已知量/所求量，应为 15−5=10。
- 工程启示：错误常发生在**计算之前的建模层**，禁止从错误答案倒推归因。

**铁律B「三问正交分类」**：对第一错误步追问"不知道？想错？还是执行偏差？"——三选一、互斥、不叠加。

### 14.2 第一错误步定位法（反向查思路）

| 步骤 | 动作 | 要点 |
|:----:|------|------|
| ① | 读原始解题过程（不是答案） | 还原孩子当时思路，含草稿 |
| ② | 拆成有序步骤序列 | 读题→建模→选条件→列式→计算→写答 |
| ③ | 正向扫描找第一个偏离正确路径的步骤 | 常见于建模/选条件层（例：15+5 错在建模） |
| ④ | 记录证据 | 引用孩子原步骤原文，不概括 |

### 14.3 错因三分类判定表（K/P/A）

| 类型 | 判定（这一步的错因是？） | 对症处理 | 禁止 |
|:----:|------------------------|---------|:----:|
| **K 知识缺口型** | 概念/规则/方法本身不懂（平均分、周长=两长+两宽、长度与面积单位混淆） | 退回知识点 → 孩子**用自己的语言解释** → 基础题检验 | 抄答案 |
| **P 思路路径型** | 知识懂，但选条件/理关系/定步骤走错（年龄差用无关数字、"一共"就加、"甲比乙多"误读为"乙比甲少"） | 重走**审题链四问**：问题弄清了吗？条件选对了吗？数量关系说清了吗？步骤顺序对吗？ | 直接给新题 |
| **A 执行动作型** | 思路对，书写/计算过程偏差（进位漏写、单位漏掉、数字抄错、草稿乱看串） | 给**具体可重复动作**：进位数固定写在竖式上方；列式后校对数字；写答案后查单位；草稿从左往右分行 | "认真点"空话 |

*口诀：知识缺口补知识 · 思路路径走思路 · 执行动作建动作*

### 14.4 三分类 × 五分类双标签映射（课堂衔接）

| 三分类（认知过程） | 五分类（内容能力）映射 | 用法 |
|:----:|:----:|:----:|
| K 知识缺口型 | 概念不清 + 方法不会选（不知方法） | 诊断先出三分类，讲评再落五分类 |
| P 思路路径型 | 审题不仔细 + 方法选错 + 步骤不完整（思路层） | 双标签记录：K/P/A + 五分类代码 |
| A 执行动作型 | 步骤不完整（执行层）+ 计算失误 | **五分类盲区**——"会做但写错"，三分类补位 |

### 14.5 家庭辅导话术（替代"又粗心"金句库）

家长三步问（替代第一句"又粗心了"）：
1. "错从哪一步开始？"（定位第一错误步，看草稿/过程）
2. "这一步是不知道、想错了，还是写的时候出岔子？"（三问分类）
3. "那我们下次具体怎么做？"（对症建动作）

金句替换：不说"认真点"，说"具体点"——"进位写这儿、写完查单位、草稿从左往右分行"。

### 14.6 AI 诊断 Prompt（生产级 JSON 结构化输出）

```
你是初中数学诊断引擎。把学生解题过程拆成有序步骤，与正确路径逐步骤比对，
输出第一个偏离步骤（注意：错误常在计算之前的建模层，禁止从错误答案倒推归因）。
三问分类只选一类：
- knowledge_gap：该步概念/规则/方法不懂
- path_error：知识懂但条件选择/关系梳理/步骤顺序走错
- execution_error：思路正确但书写/计算偏差
对症措施：knowledge_gap→退回知识点+孩子自述解释+2道基础检验题；
path_error→重走审题链四问；execution_error→1条可重复动作(禁"认真点")。
输出：{first_error_step, error_type, error_evidence(引用学生原步骤), remedy, check_question}
```

示例（题"小明比小红多5张卡片，小明15张，小红几张？"学生过程"15+5=20"）：
- first_error_step=列式前的数量关系建模
- error_type=path_error（把"多"直接映射为"加"，未区分已知量/所求量）
- remedy=重走审题链：翻译等式"小红+5=小明"，故 15−5=10
- check_question=把"小红比小明少5张"做一遍，对比两式

### 14.7 实战陷阱（v2.4 新增）

| 陷阱 | 表现 | 对策 |
|:-----|:------|:-----|
| 笼统归因"粗心" | 诊断输出只写"粗心/马虎"，无定位无分类 | 强制三问流程：先定位第一错误步→三分类→对症；输出含"粗心"即视为未完成 |
| 从答案倒推 | 看到 15+5=20 直接说"加法算错" | 步骤比对，错误常在建模层（15+5 本身算对） |
| 执行偏差当知识缺口 | 漏写单位被当"不懂单位"狂补知识点 | 三问分类：思路对→A 执行动作型→给具体动作 |
| 空话"认真点" | 对症措施无操作性 | A 型必给可重复动作（进位固定位/校对数字/查单位/草稿分行） |
| 分类叠加 | K+P+A 都选，无从下手 | 三问互斥三选一；第一错误步只有一个 |

## 十三、V2.5 升级：错题本入库筛选与四项记录

> 蒸馏来源：清简《060.错题管理第三讲：错题本不是什么都抄》
> 核心命题：**错题本不是收纳箱，是"未解决问题清单"**——只留还没解决的问题。少而精，比多而全有用。

### 15.1 入本筛选总原则（三类原地订正豁免）

| 豁免类型 | 判定 | 处理 |
|:----:|------|------|
| ① 即时自纠 | 孩子自己马上能发现并能说清怎么改（漏单位/抄错数字/横式不写答案） | 就地订正画"过"，当天闭环 |
| ② 新题首错 | 第一次没做出来，讲解后理解 | **不做标记直接抄**——先标记，隔几天独立重做，做对就通过 |
| ③ 字迹潦草 | 0 写成 6、7 写成 1 | 解决书写问题本身，不是再抄一遍（路由书写训练） |

**区分"听懂"与"会做"**：听懂了 ≠ 会做，须延迟重测验证。

### 15.2 四类值得入本（判定标准）

| # | 类型 | 判定特征 | 入本理由 |
|:-:|------|---------|---------|
| 1 | **反复出现** | 同类错误跨题复现（两次不进位、换题仍误判"比谁多"） | 同一问题未解决 |
| 2 | **不知为何错** | 问起错在哪只能答"不知道/粗心"，找不到第一错误步 | 元认知缺失，必复发 |
| 3 | **隔几天又不会** | 对着答案能改对、独立做又错 | 记住的是答案而非思路 |
| 4 | **过程不稳定** | 做对但反复擦拭试探、几道题间试来试去偶然得对 | 靠运气做对，未真正掌握 |

*共同特征：都提出了一个尚未解决的问题。*

### 15.3 四项记录规范（少而精，每题 ≤3 行）

| # | 记录项 | 规范 | 禁止 |
|:-:|--------|------|:----:|
| 1 | **题目在哪里** | 剪切/粘贴/打印，或页码+题号+图片链接 | 抄题浪费时间 |
| 2 | **我原来怎么想** | 保留原误算式/主要错误判断（"看到多 5 就用加法"），**孩子原话** | 家长转述加工 |
| 3 | **错在哪一步** | 步骤级具体断点（"没分清谁多谁少就把数据全塞进公式"） | 笼统写"粗心/审题不清" |
| 4 | **下次做什么** | 一个可执行动作+暂停信号（"竖式做完单独查进位数"） | "下次认真" |

*错题本让孩子留下三件事：我原来怎么想、错从哪里开始、下次走到这里要做什么。*

### 15.4 与 v2.4 三分类衔接（059→060 咬合）

| 咬合点 | 内容 |
|:----:|------|
| ① | 四类判定中"说不出为什么错" = 铁律A无法定位第一错误步 → 三问分类进行不了 → **必须入本专攻** |
| ② | "错在哪一步" = 第一错误步定位的记录化（复用 first_error_step） |
| ③ | "下次做什么" = K/P/A 对症处理的动作化（P 型"先说明谁多谁少"、A 型"检查进位数"） |

**操作顺序**：入本前先跑三问定位分类（§14.3），四项记录就是归因结论的落纸。

### 15.5 每日错题筛选流程（家长版五步）

1. 订正前先自述三问：哪错了？为什么错？怎么改？能说清 → 原地订正画"过"
2. 说不清/只会说"不知道、粗心" → 进候选区
3. 追问"这题上次是不是也错过？"反复出现 → 入本
4. 遮答案独立重做：做对 → 标记观察隔几天再验；仍错 → 入本
5. 入本只填四项、每题 ≤3 行，尽量用孩子原话，家长可代写但不得转述加工

### 15.6 入本判定 AI Prompt（生产级 JSON 结构化输出）

```
你是错题本筛选引擎。输入=诊断结果+复现历史+学生自纠问答。
三道闸门顺序判定：
第一闸（豁免不入本）：能自述原因并解释改正→self_corrected 当天闭环；
字迹/誊抄类→handwriting 路由书写训练；新题首错讲解后理解→pending 进延迟重测。
第二闸（延迟重测 3-5 天后独立重做）：做对→出通道不入本；失败→delayed_fail 入本。
第三闸（四类入本）：recurrence 同知识点同错因复现≥2次；
unexplained 说不出错在哪只答"不知道/粗心"；delayed_fail 隔几天重做失败；
unstable 做对但过程反复涂改试探。
输出：{in_book, reason_code, original_thought(学生原思路原文),
error_step(第一错误步), next_action(具体动作+暂停信号)}
```

### 15.7 BKT 掌握度衔接（入本/出本阈值）

| 动作 | 条件 |
|:----:|------|
| 入本 | 掌握度 <60%，或命中四类判定（reason_code 非空） |
| 出本 | 连续 2 轮延迟重测独立做对 且 掌握度 ≥80% |
| 复习节奏 | 挂 §12.1 间隔重复（review_round 递增） |

### 15.8 平台错题本模块落地（筛选→记录→复习闭环）

```
诊断输出 → 入本判定(AI Prompt §15.6) → 四类标注(reason_code)
    → 四项记录入库(original_thought/error_step/next_action)
    → 延迟重测调度(3-5天后) → 通过出本 / 失败重入 → BKT 掌握度更新
```
- 记录字段与 §14.6 诊断 JSON 对齐：error_step 复用 first_error_step；next_action 由 remedy 升级（具体动作+暂停信号）
- 原地订正题不进本，仅更新 BKT 掌握度

### 15.9 实战陷阱（v2.5 新增）

| 陷阱 | 表现 | 对策 |
|:-----|:------|:-----|
| 错题本当抄题本 | 只抄题+答案，本子越来越厚 | 四项记录规范：不抄题，只留位置+原思路+错步+动作 |
| 入本无判定 | 所有扣分题都抄 | 三道闸门：先自纠豁免→延迟重测→四类判定 |
| 记录写"粗心" | 四项记录笼统无信息 | 强制步骤级：错在哪一步必须具体到断点 |
| 新题直接入本 | 听懂就当掌握 | 先标记→隔几天独立重做→做对即过 |

## 十四、V2.6 升级：错题复测三时段（什么时候再做一次）

> 蒸馏来源：清简《062.错题管理第五讲：错题什么时候再做一次》
> 双视角提炼：严教（教学法）+ 李智（工程调度）| 2026-08-07
> 系列定位：059→v2.4（粗心三分类：为什么错）、060→v2.5（入本筛选：什么值得入本）、**062→v2.6（复测节奏：入本之后什么时候验、怎么验）**
> 核心命题：**判断"真会"的唯一标准是"忘记答案之后还能独立做对"。**

### 16.1 错题复测三时段（教学法总表）

| 时段 | 时间窗口 | 检验目的 | 操作要求 | 判通过 | 判失败 |
|:----:|:---------|:---------|:---------|:-------|:-------|
| **第1次：当天纠正** | 发现错误当天 | **无检验功能**——只做整理归因，为后两次建档 | ①找错误第一次出现处（=v2.4铁律A第一错误步）②判断知识/思路/执行（=K/P/A三分类）③四项记录（=v2.5）④当天弄清原因，**禁止反复按答案修改多遍** | 本时段不设判定；两类出口：原因说清→进第2时段；说不清→按v2.5入本(reason_code=unexplained) | 原因说不清→入本专攻 |
| **第2次：隔几天独立重做** | **3-7天**（优先3-5）| **真掌握检验关（权重最高）**：检验"忘记答案后能否独立解题" | ①**遮住答案/批注/订正**，从读题开始独立重做 ②凭自己判断条件、关系、方法 ③家长全程不提示 | **独立做对**（正确思路自主建立）→进入第3时段 | 再做错→定位**本次卡住处**（不重复上次归因）→再次K/P/A处理→**继续留错题清单**（入本） |
| **第3次：单元结束综合复测** | 一个单元学完 | **综合识别关**：脱离类型提示，自己判断考什么/选什么条件/用什么方法（考试不按学习顺序） | ①未解决错题+**普通题混合**组卷 ②**打乱顺序**不按原序 ③**不预告**每题类型 ④混入**1道简单变式**（改数字/改表达/加无关条件，对接§11.1） | **独立完成**且识别出变式数量关系 → 该题**暂时退出**清单（出本，对应BKT≥80%） | 再错一次→**进入下一轮管理**：留清单，回到三时段重新走 |

*口诀：当天归因不检验 · 隔几天独立做对才算真掌握 · 单元综合复测防背题*

### 16.2 核心思想三条（金句区）

1. **刚改完会做=可能是记住了；隔几天独立完成=才算真掌握**——所有"当场做对"只算"已听懂"，必须经第2时段延迟检验后才算"已掌握"
2. **每一次重做，都是在加深路径**——复测=检索练习（提取效应）：做对加深正确路径，做错暴露未解问题，两头都有收益；复测不是"过关仪式"而是"加深过程"
3. **考前集中翻错题本的误区**——眼熟≠会做（识别记忆≠独立提取），答案在眼前产生"熟悉感错觉"；错误不一定在错题本上，也可能在复习方法上。**对策：考前复习要"做"不要"看"——遮答案当新题做一遍，且复习应分布在三时段，不集中突击**

### 16.3 家长/教师话术库（复测过程语言，补§10.2结果语言）

| 场景 | 话术 |
|:-----|:-----|
| 第2时段开场（家长版）| 「来，把答案和订正都盖上，像考试一样从头做一遍。不看刚才写的，就凭你自己现在的想法。」 |
| 第2时段开场（教师版）| 「遮住订正过程，从读题开始独立完成。做不出来没关系，但不要偷看——我们要检验的是你脑子里的思路，不是纸上的答案。」 |
| 孩子抗拒 | 「这道题隔了几天，正好看看你是不是真的会了。会了是你的本事，不会正好说明它还得再练。」 |
| 判通过 | 「隔了这么多天还能自己做出来，说明你是真会了，不是碰巧记住的。」／「上次是跟着答案走的，这次是你自己走通的——这次的路才是你的。」 |
| 判失败 | 「又卡在同一个地方了——这正好说明问题还没真正解决，我们把它留下，再处理一次。这次卡在哪一步？」（→定位本次新断点） |

### 16.4 工程调度字段与状态机（李智设计）

**字段设计：**

| 字段 | 语义 |
|:---|:---|
| `review_round` | 0=当天整理（只归因不检验）/ 1=独立重做(3-7天) / 2=单元综合复测 / 3+=passed后长间隔巩固 |
| `interval_days` | round0=0；round1=3~7（默认5，root型压缩3、local型5~7）；round2=单元结束日-今天（动态）；巩固=15~30 |
| `next_review_at` | 调度引擎每日扫描到期；round2 由单元结束事件覆盖 |
| `state` | `pending`→`active`→`passed`→`archived`；**failed 不占状态位**，落 `last_result`+`fail_count`+`last_fail_point`（第二次卡点）|
| 其他 | `schedule_mode`(family/fine)、`pass_count`（≥2且BKT≥0.80才archived）、`error_severity`(root/local)、`unit_id`、`variant_ids`、`review_history` |

**状态机：**

```
pending(round0当天整理) ─整理完成→ active(round1) ─独立重做通过→ active(round2) ─单元综合复测通过+变式对→ passed(暂时退出)
                          ↑                    │                          │                       │
                          └──fail：记第二次卡点┘                          └──fail→下一轮管理───────┘
passed → 巩固轮(15-30天抽验) → BKT≥0.80+连续2轮 → archived(出本)；巩固轮fail→回active(round1)
```

### 16.5 统一调度模型（三套机制咬合）

| 机制 | 职责 | 关系 |
|:-----|:-----|:-----|
| v2.5 延迟重测（3-5天）| **入本前筛选闸门**（管"进不进本"）| 失败入本后 round1 从入本日起算（距首错7-11天），天然错开 |
| **v2.6 三时段** | **入本后复测调度**（管"何时重做"）| 本升级核心 |
| §12.1 间隔重复（1-2-4-7-15天）| 精细版节奏 | **三时段=间隔重复表的轮次聚合**：round1 聚合第2/3轮，round2 汇聚第4/5轮+单元事件；`schedule_mode=fine` 展开精细版、`family` 走简版，同一字段/状态机，仅 interval 序列不同 |

## 十七、V2.7 升级：错题复发机制（为什么订正过了还会错）

> 蒸馏来源：清简《063.错题管理第六讲：为什么订正过了，还会在同一个地方出错》
> 双视角提炼：严教（教学法）+ 李智（工程）| 2026-08-07
> 系列定位：059→v2.4（为什么错）、060→v2.5（什么入本）、062→v2.6（何时复测）、**063→v2.7（怎么治——让错误不再复发）**
> 核心命题：**订正记忆的是"答案"，复发源于"错误反应未被替换"——治标要治在"错误行为发生之前"。**

### 17.1 三大核心机制

**机制一：错误反应未替换（记住答案 ≠ 改掉反应）**
- 记忆有两层：①正确答案的记忆（短效，刚复习时管用）②错误反应的条件反射（长效，时间一长自动回潮）。只订正答案=只更新第①层
- 例：小明比小红多5张，小明15张，小红几张？首错写 15+5；订正记得"用减法、答案10"；下次见"比……多"仍条件反射写加法
- **治疗铁律**：仅仅把正确答案再抄一遍不够——必须在错误行为发生之前增加一个判断动作，用"新判断"卡住"旧反应"
- 一句话：错误是"路径"不是"点"——改的是答案，路径没变，走到那儿还会拐错

**机制二：信号停顿法（固定触发条件 + 看到就停一停 + 判断再下笔）**
- 重复错误几乎都有固定触发条件：看到"一共"就写加法、"平均"就做除法、一堆数字就想全塞进算式
- 操作公式三步：①锁定触发信号（看到什么就条件反射）②设置停顿规则（看到XX先停一停）③规定判断内容（停下来的几秒钟判断什么——不是空想"仔细点"）
- 信号→判断对照表（prompt 示例）：
  - "比……多/少" → 判断谁和谁比、谁多谁少、已知的是谁、要求的是谁
  - 很多数字堆在一起 → 判断哪些条件和问题有关（无关数字剔除）
  - 竖式计算完成 → 先检查进位
  - 写出答案之后 → 检查单位
- 价值：只花几秒钟，把"习惯性下笔"变成"有根据的判断"——判断动作插在错误反应触发点之前

**机制三：对比题训练法（相似但解法不同的题并排比较）**
- 标准题对（可直接复用）：
  - 题A：小明有15张卡片，比小红多5张。小红有多少张？→ 小红少，求较少量：15−5=10
  - 题B：小明有15张卡片，小红比小明多5张。小红一共有多少张？→ 小红多，求较大量：15+5=20
- 比较引导四问：这两道题有什么不一样？谁的多谁的少？知道的是谁的？为什么一道用减法、一道用加法？

### 17.2 复发检测规则（工程化）

**触发**（调度引擎每日扫描）：`state==passed AND now<=observation_expires_at AND last_result==fail`——复测/作业/考试全通道判错统一进 last_result。

**same_pattern 三比对**（复发 vs 新错因判定）：
| 比对项 | 一致 → | 不一致 → |
|:---|:---|:---|
| signal.trigger_word | reaction_not_replaced=true | 新错因 |
| first_error_step（v2.4 第一错误步） | 同上 | 常规 K/P/A 处理 |
| error_evidence（错误算式/模式） | 同上（强信号） | 常规处理 |

*只记"又错了"不比对模式 = 把复发当新题，治标不治本。*

**复发五连**：① fail_count++、recurrence_count++ ② same_pattern=true → reaction_not_replaced=true 落库 ③ 状态回退 passed→active(round1)，next_review_at=now+interval（压缩）④ 触发专项练习（contrast_mode + signal_card）⑤ recurrence_count≥2 → 换装全新同构题复测（改数字/改情境，原题冻结）——识别"背题"。

**字段增量**：reaction_not_replaced(bool) / recurrence_count(int) / same_pattern(bool) / observation_days=30 / observation_expires_at / last_recurrence_at / signal / contrast_pair

### 17.3 信号词库 v1 + 信号判断卡（练习端核心交互）

**信号词库 v1（小学数学应用题）**：
| 信号词 | category | 危险反应 | 停顿检查 | 运算规则 |
|:---|:---|:---|:---|:---|
| 一共/总共/合起来 | total_sum | 立即加法 | 相加的两个量是同类吗？求的是总数吗？ | 同类量才可直接相加 |
| 平均 | average | 立即除法 | 总数是多少？分成几份？求每份还是求总数？ | 总数÷份数=每份 |
| 比……多/比……少 | compare_more/less | 多→加、少→减 | 谁和谁比？谁多谁少？已知谁的？求谁的？ | 知多求少→减；知少求多→加 |
| 还剩/剩下 | remainder | 立即减法 | 从总数去掉的是一部分吗？ | 总数−去掉=剩余 |
| ……的几倍 | multiple | 立即乘法 | 谁是一份？求几份还是求一份？ | 求几份→乘；求一份→除 |
| 同样多 | equal | — | 两边相等如何列式？ | 桥接量，先找等量 |
| 竖式进位 | carry_check | 进位写错 | 竖式做完单独查进位 | 进位数固定写上方 |
| 写答案 | unit_check | 漏单位 | 写出答案后查单位 | 单位必写 |

**提取规则**：诊断时 error_type=P（思路路径型）且 first_error_step 在建模层/选条件层，必须提取 signal 字段；K/A 型可不提取。

**信号判断卡（先判断后做题，作答顺序强制：信号卡→原题，禁止跳过）**：
① 圈词（题干信号词高亮）→ ② 说意（"这个词让我想到什么"，不列式；答错提示1次再判）→ ③ 判关系（stop_check 4问，全对解锁原题）→ ④ 确认（说出运算方向后才列式；2次仍错标记 signal_fail 回流诊断）
- **计分**：信号判断独立计分，不计入做题正确率（防"蒙对判断、做错题"被掩盖）

### 17.4 对比题组卷（contrast_mode）

**配对结构**：reverse_quantity 正反序配对（结构相似、数量关系方向相反）：
- pair_a（知多求少→减）：小明有15张，比小红多5张。小红几张？→ 15−5=10
- pair_b（知少求多→加）：小明有15张，小红比小明多5张。小红一共几张？→ 15+5=20

**作答流程**：信号卡 → 做 pair_a → 回答比较题 → 做 pair_b → 复述规则（"知道多的求少的用减，知道少的求多的用加"）。

**触发规则**：reaction_not_replaced=true → 必配 contrast_pair；复发回退 round1 → 即出 signal_card+contrast_pair；普通错题（已提取 signal）→ 附带对比题作预防。

### 17.5 与 v2.6 融合（30 天观察期）

```
v2.6:  pending(r0) → active(r1) → active(r2) → passed → 巩固轮(15-30天) → archived
v2.7:  pending(r0) → active(r1) → active(r2) → passed ──观察期30天──→ archived
                          ↑                    │            │
                          └─fail:记第二次卡点───┘            ├─观察期内再错=复发→
                          ↑                                  │   fail_count++/recurrence++
                          └──换装题复测(rec≥2)←──────────────┘   reaction_not_replaced标记
                                                               回退 active(round1) + contrast_mode
```

- passed 后进入观察期（30 天），到期评估：无复发 + pass_count≥2 + BKT≥0.85 → archived（出本）
- 观察期内任何判错 = 复发事件：same_pattern 比对 → reaction_not_replaced → 回退 round1 + 间隔压缩（root:3/local:5）+ 观察期重新计时
- recurrence_count≥2 → 换装全新同构题（改数字/改情境），原题冻结不再用于检验
- BKT 联动：复发上报 correct=false；reaction_not_replaced 题 BKT 降级显示（橙<50% 档）+ 错题本卡片 ⚠反应未替换 徽标
- 三时段（r0/r1/r2）仍是主干调度，v2.7 只给 passed 之后加"观察期+复发检测"，不动 r0-r2 节奏

### 17.7 实战陷阱

| 陷阱 | 表现 | 对策 |
|:---|:---|:---|
| 只抄答案 | 记住了答案，反应没换 | 必须走信号判断卡+对比题，不满足只抄订正 |

## 十八、V2.8 升级：员工实践精华（059-063 进课堂·进家庭·进制度）

> 来源：教育部 5 篇岗位学习心得（张训晨/朱老师/邓老师/麻老师/严教，2026-08-07）
> 定位：v2.4-v2.7 管「诊断对、入本严、复测狠、治本早」；v2.8 管「怎么让方法真正进课堂/家庭/制度」——补足落地最后一公里
> 统领十六字：**定位要准，入本要严，复测要狠，治本要早**；总铁律：**对策必须落在动作上，不能落在态度上**

### 18.1 教学落地准则（五条）

| 准则 | 核心说明 | 课堂示例 | 家庭示例 |
|:--|:--|:--|:--|
| ① 对策落动作，不落态度 | 诊断/指导语必须含可执行动作（判断对象+动作）；"仔细点"无判断对象=正确的废话 | 说"看到'比……多'先停，圈谁和谁比再定加减"；禁说"仔细点" | 说"草稿纸分栏、抄完对一眼"；禁说"别粗心" |
| ② 改对不算改完（三验闭环） | 独立重做+说出理由+变式，缺一步=没改完；记住答案≠改掉反应 | 订正后遮答案重做，讲不出理由打回（入评审表） | 只问"讲给我听为什么"，再口头变一个数 |
| ③ 三时段复测靠"替换"不靠"新增" | 复测嵌入已有环节零新增：当天归因挂订正、3-7天挂每周小测、单元挂单元卷 | 小测从错题本抽一题（不预告）；单元卷放一题变式 | 周末错题题号写进作业单，遮答案独立做 |
| ④ 诊断语言四要素 | 写全"第几步/看到什么/写了什么/应先判断什么"；说不具体=没查完案就结案，一律打回 | 不说"审题不清"，说"第二步把'比小红多5张'译成加法，应先判基准" | 把"又马虎"换成"第一步你读到了什么条件？" |
| ⑤ 先判断再下笔，口令化+卡片化 | 反应前插入判断动作并具体到"判断什么"；口令+桌角卡片固化成习惯 | 师喊"停一停"→放笔→手指题→说关键词→说考点→再下笔 | 桌角贴信号判断卡（圈词→说意→判关系→确认） |

### 18.2 课堂与家庭落地工具

**课堂工具（朱老师）**
1. **课堂口令「停一停」**：口令要短、要有动作——放笔、手离桌面、指着题说"我看到的关键词是……""这道题考的是……"，最后才下笔。信号判断卡（圈词→说意→判关系→确认）做成小卡片贴桌角。
2. **评审表新增两项评分**（评课=落地检验）：①"订正环节"项——独立重做/说出理由/变式缺一不算过；②"对比呈现"项——两题并排板书、差异点红笔圈（如"比小红多5张"vs"小红比小明多5张"，一减一加并排摆）。评审总标准：**"学生有没有形成先判断再下笔的动作"写进每一项**。
3. **替换式排课表**（三时段零新增任务）：

| 复测时段 | 替换进哪个已有环节 | 动作 |
|:--|:--|:--|
| 当天归因 | 订正时顺带 | 说一句"我错在哪一类"（K/P/A） |
| 3-7天独立重做 | 每周小测 | 从错题本抽一道原题（不预告） |
| 单元结束综合复测 | 单元卷 | 从错题本挑一题变式放入 |

4. **事前预防标注（邓老师）**：拆题/出题时额外标注"易错点＋第一错误步"位置，条件类题目标出基准关系；课件/视频直接提醒"这道题最容易在第 X 步翻车"——错因分析从"事后诊断"变"事前预防"。

**家庭工具（张训晨/麻老师）**
1. **"记录+反馈"双环节**：任何落地工具必须同时具备记录（问题可见）与反馈（进步可测）——错题本=记录，三时段复测+BKT=反馈，缺一不成闭环。
2. **材料写法转换**：写"此处易错，请留意"不如写"遮住答案，独立重做一遍"；"听懂"≠"会做"，材料必须驱动输出。
3. **家长话术对照表**："下次仔细点"（情绪安慰）→"读到'比……多'先圈出谁和谁比"（操作指令）；"你怎么又马虎"→"这道题你第一步读到了什么条件？"

**制度工具（严教）**
1. **每日一讲**：结合当天学生错题现场演练 K/P/A 分类。
2. **晚检日志**：每人每天记一条真实错因案例，注明"定位步骤+处理动作"，攒一月即成教研素材。
3. **周六 KPI 简报**：错因分布变化作指标——一周内"粗心"类归因占比降幅、"执行动作型→知识缺口型"转化数，量化进步。

### 18.3 诊断语言标准（K/P/A 统一语言）

1. **统一语言**："粗心=诊断未完成"为部门统一表述；诊断只许用 K/P/A 三分类（知识缺口补知识·思路路径走思路·执行动作建动作），再落到五分类具体概念；**禁止写"粗心""不认真""态度不端正"等空话**——写进教学标准与诊断模板，让每位老师/教研员说同一套话。
2. **诊断四要素**（麻老师抽检标准）：一句话必须写全 ①第几步 ②看到了什么 ③写了什么 ④应该先判断什么。例：合格——"第2步，看到'比……多'直接写加法，应先判断谁和谁比、谁是被比基准（思路路径型·需对比题训练）"；不合格——"审题不清/概念不牢"。
3. **"说不具体一律打回"**：AI 诊断报告、人工评语复核时，凡错因说不具体、无法照着做的，一律打回重写。诊断不对努力白费；**诊断对了说不清，努力照样白费**。
4. **判断动作要具体到"判断什么"**："停一停"必须配判断对象——"看到'比'字就问：谁和谁比？谁多谁少？已知谁？求谁？"；无判断对象的停顿等于白停。
5. **第一错误步防误判**（邓老师）：答案反推会掩盖错因——必须从前往后逐行对齐正确过程，第一个对不上处才是第一错误步；例：两题同写 15+5，答案看似"计算粗心"，拆开实为"文字翻译成数量关系"层的审题/断层错因，不在计算维。

### 18.4 常见落地陷阱

| 陷阱 | 表现 | 对策 |
|:--|:--|:--|
| "粗心"帽子一扣 | 归因到态度，问题消失 | 禁词清单+统一 K/P/A 语言；"粗心=没查完案就结案" |
| 对策落在态度上 | "下次仔细点"，孩子停下一秒不知想什么 | 对策落动作：给判断对象+动作（准则①） |
| 改对就算完 | 抄上正确答案，问为什么答不上 | 三验闭环进评审表：重做+理由+变式，缺一打回（准则②） |
| 三时段喊没时间 | 一听"三次"就放弃 | 替换不新增：挂订正/挂小测/挂单元卷（准则③） |
| 对比题口头一问带过 | 问"有什么不一样"就过，无比较 | 两题并排+红笔圈差异+必答 4 个比较引导题（对接 §17.4） |
| 诊断对了说不清 | 写"审题不清"听着没错，无法照做 | 四要素不全一律打回（§18.3） |
| 只盯答案不拆过程 | 答案反推误判错因，治错地方 | 从前往后逐行对齐找第一错误步 |
| 方法停在文档 | 学完不落地，老师各说各话 | 制度三件套：每日一讲/晚检日志/周六 KPI 简报 |
| 复发当新题 | 同一错因换标签，旧反应继续 | 走 §17 复发五连+30 天观察期，标记"反应未替换" |
| 事后才诊断 | 错误反复出现才处理 | 拆题预标"易错点+第一错误步"，事前预防（§18.2） |
