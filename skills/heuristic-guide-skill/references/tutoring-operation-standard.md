## 一、核心原则

**不直接给答案。引导孩子自己想出来。**

这是学霸基本法和所有家教、搜题App的根本区别。家教老师来了讲一遍就走了，孩子听懂没有不知道。搜题App给个答案和解析，看完还是不会。

学霸基本法的AI老师通过五步引导法（邱董审定版），让孩子自己把题目想通。

---

## 二、五步引导法（标准话术 · 一字不差）

AI老师在完成六维诊断后，对照原题按以下五步引导：

### 第一问：已知条件筛查
> **"题目里有几个已知条件？都用上了吗？还是哪句话没理解？"**

**目的：** 检查学生是否完整提取了题目中的所有已知条件。
**常见问题：** 学生漏条件、看错数、忽略隐含条件。
**AI判断：** 答不出→逐句读题，每读一句问"这句话告诉了我们什么"。

### 第二问：条件推导
> **"由这个已知条件，你能得到什么结论？"**

**目的：** 检查学生是否能从已知条件推理出中间结论。
**常见问题：** 学生知道条件但不知道能推出什么。
**AI判断：** 卡住→提示相关定理或公式，但不直接说结论。

### 第三问：思路选择
> **"要证明这个问题，有几种思路？你想用哪一种？现在已经有几个条件可用，还缺少什么？"**

**目的：** 训练学生的解题策略思维，不是蒙头就做。
**常见问题：** 学生没有整体思路就开始写。
**AI判断：** 说不出思路→列举2-3种可能方向，让学生选一种。

### 第四问：逻辑验证
> **"你能推得它成立吗？"**

**目的：** 让学生自己完成完整的逻辑推导。
**常见问题：** 学生跳步、逻辑链断裂。
**AI判断：** 写不下去→返回到第三问，检查是否选错了思路。

### 第五问：反向命题（最高阶）
> **"这个题目如果让你来命题，你会怎么出？"**

**目的：** 检验学生是否真正理解了解题思路的本质。能出题=真会了。
**常见问题：** 学生能解题但说不出为什么这样考。
**AI判断：** 能出至少一个合理的变式题→标记"已掌握"；不能→返回第一问重新筛查。

## 三、五步引导法 vs 市场竞品

| 环节 | 家教老师 | 搜题App | 学霸基本法AI |
|:----|:---------|:--------|:------------|
| 诊断 | 凭经验判断 | 只给答案 | 六维精准诊断 |
| 教学 | 讲一遍就走 | 给解析文字 | 五步引导追问 |
| 验证 | 问"听懂了吗" | 没有验证 | 真会检验+变式命题 |

| 时间 | 1小时/次 | 随时 | 24小时在线 |
| 价格 | 200-500元/节 | 免费但无效 | 29.9元/月 |

## 四、辅导流程总览

```
学生拍照上传作业
    ↓
AI六维错因诊断（30秒）
    ↓ 诊断结果 →
├─ 概念模糊 → 第一问：已知条件筛查
├─ 计算失误 → 第二问：条件推导
├─ 审题偏差 → 第一问（重点）
├─ 思路中断 → 第二问+第三问
├─ 规范缺失 → 第四问
├─ 知识断层 → 返回前置知识点学习
    ↓
五步追问完成
    ↓
真会检验：遮挡重做 / 变式挑战 / 给AI讲题
    ↓
通过 → 知识点标记为绿色（已掌握）
    ↓
错题自动归档 → 1/3/7/21天间隔复习
```

## 五、宣传对比话术

| 家教 | 学霸基本法 |
|:----|:----------|
| "这个公式用错了，重算一遍" | "题目里有几个已知条件？都用上了吗？" |
| "听懂了吗？"孩子点头其实没懂 | "你能推得它成立吗？"让孩子自己推一遍 |
| "这道题就这样，下一题" | "如果让你来命题，你会怎么出？" |
| 一小时后走人，下次课再约 | 24小时在线，随时问随时答 |
| 200元一节 | 29.9元一个月 |

## 六、本规范的使用场景

1. **宣传视频旁白**：用口语化的方式说出五问过程
2. **AI教师实时对话**：后端tutor prompt引用五步引导法话术
3. **家长沟通**：向家长解释我们的辅导方式和家教有什么不同
4. **销售素材**：朋友圈/社群文案突出"不是讲答案，是引导思考"
