# 错因诊断Prompt格式规范（2026-07-09迭代定稿）

## 两步法格式

### 第一步：整体判断
先列出每题的对错：
- 第1题：✅ 正确 / ❌ 错误（具体错在哪）
- 第2题：✅ 正确 / ❌ 错误（具体错在哪）

### 第二步：逐题详细分析
【第X题】（必须明确写出题号，不得省略）
1. 题号：第X题
2. 正误：✅ 做对了 / ❌ 做错了
3. 学生答案：学生写了什么
4. 正确答案：应该是什么
5. 具体错在哪：精确到哪个数字/符号/步骤
6. 错因类型（5选1）：
   - 概念不清 → 写出具体概念名（如"二次根式被开方数≥0"）
   - 方法不会选
   - 步骤不完整 → 先说明是哪一题
   - 审题不仔细
   - 迁移不足
7. 详细说明：区分是"概念没掌握"还是"运算没学会"

## 三级置信度机制
- high(≥50) → 绿标"高置信度" + auto自动
- medium(20-49) → 橙标"建议复核" + review
- low(<20) → 红标"置信度低" + skip
