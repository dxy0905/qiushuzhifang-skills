# 第十七章 因式分解

## 核心内容

因式分解是与整式乘法互逆的恒等变形，是初中代数的重要工具。本章学习两种基本方法：提公因式法和公式法（平方差公式、完全平方公式），为后续学习分式化简、解方程等打下基础。

---

## 各节知识点

### 17.1 因式分解的概念

**定义：** 把一个多项式化成几个整式的积的形式，叫做因式分解（也叫分解因式）。

**与整式乘法的关系：**
- 整式乘法：整式 × 整式 → 多项式（积化和）
- 因式分解：多项式 → 整式 × 整式（和化积）

> **互逆关系：** 因式分解是整式乘法的逆变形。

**判断标准：**
1. 左边必须是多项式
2. 右边必须是整式乘积的形式
3. 分解要彻底（不能再分解为止）

> **注意：** 因式分解是恒等变形，结果与原来的多项式相等。

> **⚠️ 易错：** 不是因式分解的常见错误——将整式乘法结果当成因式分解，或分解不彻底。

---

### 17.2 提公因式法

**公因式：** 多项式各项都含有的公共因式。

**确定公因式的方法：**
1. **系数**：取各项系数的最大公约数
2. **字母**：取各项相同字母
3. **指数**：取相同字母的最低次幂

**提公因式法：**
$$ma + mb + mc = m(a + b + c)$$

**提取步骤：**
1. 确定公因式
2. 用公因式去除多项式，得到另一个因式
3. 写成公因式与另一个因式乘积的形式

> **检验方法：** 用整式乘法展开右边，看是否等于左边。

#### 提公因式的几种特殊情形

**系数为负时：**
$$-x^2 + 2x = -x(x - 2)$$

**公因式为多项式时：**
$$a(x - y) + b(x - y) = (x - y)(a + b)$$

**变形技巧：**
- $(y - x)^n$ 与 $(x - y)^n$ 的关系：
  - 当 $n$ 为奇数时，$(y - x)^n = -(x - y)^n$
  - 当 $n$ 为偶数时，$(y - x)^n = (x - y)^n$

### 17.3 公式法

#### 平方差公式

**公式：**
$$a^2 - b^2 = (a + b)(a - b)$$

**结构特点：**
- 两项都是平方项
- 两项符号相反（一正一负）
- 可以写成 $(\ )^2 - (\ )^2$ 的形式

**使用步骤：**
1. 将多项式写成平方差的形式
2. 直接套用公式 $a^2 - b^2 = (a+b)(a-b)$

**示例：**
- $x^2 - 9 = x^2 - 3^2 = (x + 3)(x - 3)$
- $4x^2 - 25 = (2x)^2 - 5^2 = (2x + 5)(2x - 5)$
- $x^4 - y^4 = (x^2)^2 - (y^2)^2 = (x^2 + y^2)(x^2 - y^2) = (x^2 + y^2)(x + y)(x - y)$

> **注意：** 平方差公式分解后，若某个因式还能继续分解，必须继续分解彻底。

#### 完全平方公式

**公式：**
$$a^2 + 2ab + b^2 = (a + b)^2$$
$$a^2 - 2ab + b^2 = (a - b)^2$$

**结构特点：**
- 三项式
- 首末两项是平方项（符号为正）
- 中间项 = ±2 × 首项底数 × 末项底数

**识别口诀：** 首平方，尾平方，二倍乘积在中央。

**示例：**
- $x^2 + 6x + 9 = x^2 + 2 \cdot x \cdot 3 + 3^2 = (x + 3)^2$
- $4x^2 - 12x + 9 = (2x)^2 - 2 \cdot 2x \cdot 3 + 3^2 = (2x - 3)^2$
- $x^2 + x + \dfrac{1}{4} = x^2 + 2 \cdot x \cdot \dfrac{1}{2} + (\dfrac{1}{2})^2 = (x + \dfrac{1}{2})^2$

#### 因式分解的一般步骤

1. 先看各项有无公因式 → 提公因式
2. 再看能否用公式（平方差、完全平方）
3. 检查是否分解彻底（每个因式不能再分解）

---

## 因式分解方法总结

| 方法 | 适用形式 | 公式 |
|------|---------|------|
| 提公因式法 | 各项有公因式 | $ma + mb + mc = m(a + b + c)$ |
| 平方差公式 | 两项、平方相减 | $a^2 - b^2 = (a+b)(a-b)$ |
| 完全平方公式 | 三项、三构成平方 | $a^2 \pm 2ab + b^2 = (a \pm b)^2$ |

## 典型题型

### 题型一：提公因式法

**例1：** 分解因式 $6x^3 + 9x^2$
> **解：** 公因式为 $3x^2$
> $6x^3 + 9x^2 = 3x^2(2x + 3)$

**例2：** 分解因式 $2a(x - y) - 3b(y - x)$
> **解：** $\because y - x = -(x - y)$
> $\therefore 2a(x - y) - 3b(y - x) = 2a(x - y) + 3b(x - y)$
> $= (x - y)(2a + 3b)$

### 题型二：平方差公式

**例3：** 分解因式 $9x^2 - 16y^2$
> **解：** $9x^2 - 16y^2 = (3x)^2 - (4y)^2 = (3x + 4y)(3x - 4y)$

**例4：** 分解因式 $(x + y)^2 - 4$
> **解：** $(x + y)^2 - 4 = (x + y)^2 - 2^2 = (x + y + 2)(x + y - 2)$

### 题型三：完全平方公式

**例5：** 分解因式 $x^2 - 8x + 16$
> **解：** $x^2 - 8x + 16 = x^2 - 2 \cdot x \cdot 4 + 4^2 = (x - 4)^2$

**例6：** 分解因式 $4x^2 + 12xy + 9y^2$
> **解：** $4x^2 + 12xy + 9y^2 = (2x)^2 + 2 \cdot 2x \cdot 3y + (3y)^2 = (2x + 3y)^2$

### 题型四：综合应用（两种方法）

**例7：** 分解因式 $3x^3 - 12x$
> **解：** $3x^3 - 12x = 3x(x^2 - 4) = 3x(x + 2)(x - 2)$
> （先提公因式，再用平方差公式）

**例8：** 分解因式 $x^3y - 2x^2y^2 + xy^3$
> **解：** $x^3y - 2x^2y^2 + xy^3 = xy(x^2 - 2xy + y^2) = xy(x - y)^2$
> （先提公因式，再用完全平方公式）

## 易错点

1. **因式分解与整式乘法混淆**：如将 $x^2 - 4 = (x + 2)(x - 2)$ 说成整式乘法。因式分解是"和化积"。

2. **提公因式不彻底**：只提取了部分公因式，没有提取全部公因式（包括系数和字母的最低次幂）。

3. **提公因式后漏写 1**：如 $a^2 + a = a(a \ + \ )$，忘记写 1 得到 $a(a)$，应为 $a(a + 1)$。

4. **平方差公式识别错误**：$a^2 + b^2$ 不能用平方差公式分解（除非先通过其他方式转化）。

5. **完全平方公式中间项符号错误**：$a^2 - 2ab + b^2 = (a - b)^2$，中间项为负结果差为正。

6. **忘记判断中间项是否为二倍乘积**：如 $x^2 + 4x + 4$ 可以用完全平方（$2 \cdot x \cdot 2 = 4x$ ✓），但 $x^2 + 5x + 4$ 不是完全平方（$2 \cdot x \cdot 2 = 4x \neq 5x$）。

7. **分解不彻底**：分解后某个因式还能继续分解却没有继续。例如 $x^4 - 16 = (x^2 + 4)(x^2 - 4)$ 还要继续分解 $x^2 - 4 = (x+2)(x-2)$。

8. **系数带负号时提公因式错误**：如 $-3x^2 + 6x = -3x(x - 2)$，括号内第一项变为正。

9. **变形时符号处理不当**：$(y - x)$ 和 $(x - y)$ 的相互转化容易出错。
