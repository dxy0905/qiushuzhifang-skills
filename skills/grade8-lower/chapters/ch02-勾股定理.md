# 第二十章 勾股定理

## 一、核心内容

本章学习勾股定理及其逆定理，是几何学中最重要的定理之一，揭示了直角三角形三边之间的数量关系。重点包括勾股定理的证明与应用、勾股定理的逆定理判断直角三角形、以及勾股定理在实际问题中的应用（最短路径问题）。

---

## 二、各节知识点

### 20.1 勾股定理

**1. 勾股定理**

直角三角形两条直角边的平方和等于斜边的平方。

如果直角三角形两直角边长分别为 $a$、$b$，斜边长为 $c$，那么

$$a^2 + b^2 = c^2$$

> **说明**：我国古代把直角三角形中较短的直角边称为"勾"，较长的直角边称为"股"，斜边称为"弦"。

**2. 勾股定理的证明方法**

- **赵爽弦图**：用四个全等的直角三角形拼成正方形，通过面积关系证明
- **毕达哥拉斯证法**（常用于教材）：用两个不同方式计算同一正方形面积

**3. 勾股定理的应用**

- 已知直角三角形任意两边，求第三边
  - 已知 $a, b$，求 $c$：$c = \sqrt{a^2 + b^2}$
  - 已知 $a, c$，求 $b$：$b = \sqrt{c^2 - a^2}$
- 解决实际问题中的长度计算

### 20.2 勾股定理的逆定理

**1. 逆定理**

如果三角形的三边长 $a$、$b$、$c$ 满足 $a^2 + b^2 = c^2$，那么这个三角形是直角三角形，且 $c$ 所对的角是直角。

**2. 勾股数**

能够成为直角三角形三条边长的三个正整数，称为勾股数。

常见勾股数：
- $(3, 4, 5)$ 及其倍数 $(6, 8, 10), (9, 12, 15)$
- $(5, 12, 13)$
- $(7, 24, 25)$
- $(8, 15, 17)$
- $(9, 40, 41)$

**3. 原命题与逆命题**

- 原命题：如果 $a$，那么 $b$
- 逆命题：如果 $b$，那么 $a$
- 互逆命题：原命题与逆命题互为逆命题

> **注意**：原命题成立，逆命题不一定成立。

### 20.3 勾股定理的应用

**1. 最短路径问题**

将立体图形表面展开为平面图形，利用"两点之间线段最短"结合勾股定理求解。

- **圆柱体**：将侧面展开为矩形，利用勾股定理求最短路径
- **长方体**：有多种展开方式，需要比较不同路径的长度

**2. 实际应用**
- 测量距离（如河宽、山高）
- 工程中的直角确定
- 航海和航空中的距离计算

## 三、典型题型

### 题型1：利用勾股定理求边长

**例1**：在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C = 90^\circ$，$a = 3$，$b = 4$，求 $c$。

**解**：由勾股定理，$c = \sqrt{a^2 + b^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$

**例2**：在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C = 90^\circ$，$a = 5$，$c = 13$，求 $b$。

**解**：由勾股定理，$b = \sqrt{c^2 - a^2} = \sqrt{13^2 - 5^2} = \sqrt{169 - 25} = \sqrt{144} = 12$

### 题型2：利用勾股定理的逆定理判断直角三角形

**例3**：判断以 $a=6$、$b=8$、$c=10$ 为边的三角形是否为直角三角形。

**解**：$a^2 + b^2 = 6^2 + 8^2 = 36 + 64 = 100 = 10^2 = c^2$
$\because a^2 + b^2 = c^2$，$\therefore$ 该三角形是直角三角形。

**例4**：判断以 $a=2$、$b=3$、$c=4$ 为边的三角形是否为直角三角形。

**解**：$a^2 + b^2 = 2^2 + 3^2 = 4 + 9 = 13 \ne 16 = 4^2 = c^2$
$\because a^2 + b^2 \ne c^2$，$\therefore$ 该三角形不是直角三角形。

### 题型3：最短路径问题

**例5**：一个圆柱高 $8$，底面半径为 $3$，在圆柱下底面的 $A$ 点处有一只蚂蚁，想吃到上底面与 $A$ 相对的 $B$ 点处的食物，求蚂蚁爬行的最短路径长（$\pi$ 取 $3$）。

**解**：将圆柱侧面展开为矩形，
底面周长 $= 2\pi r = 2 \times 3 \times 3 = 18$
展开后半周长 $= 9$
高 $= 8$
$AB = \sqrt{8^2 + 9^2} = \sqrt{64 + 81} = \sqrt{145}$

### 题型4：实际问题

**例6**：一架 $2.5$ 米长的梯子靠在一面墙上，梯脚距离墙脚 $0.7$ 米。如果梯子的顶端下滑 $0.4$ 米，梯脚将向外滑动多少米？

**解**：
初始状态：$AC = \sqrt{2.5^2 - 0.7^2} = \sqrt{6.25 - 0.49} = \sqrt{5.76} = 2.4$（米）
下滑后顶端高度：$2.4 - 0.4 = 2.0$（米）
新梯脚距离：$\sqrt{2.5^2 - 2.0^2} = \sqrt{6.25 - 4} = \sqrt{2.25} = 1.5$（米）
向外滑动：$1.5 - 0.7 = 0.8$（米）

### 题型5：勾股定理与面积法

**例7**：在 $\mathrm{Rt}\triangle ABC$ 中，$\angle C = 90^\circ$，$a = 5$，$b = 12$，求斜边上的高 $h$。

**解**：斜边 $c = \sqrt{5^2 + 12^2} = \sqrt{169} = 13$
由面积法：$\frac{1}{2}ab = \frac{1}{2}ch$
$\Rightarrow h = \frac{ab}{c} = \frac{5 \times 12}{13} = \frac{60}{13}$

## 四、易错点

### ❌ 易错1：找错直角边和斜边

**错**：在 $\triangle ABC$ 中，若 $a=3,b=4,c=5$，则 $a^2 + c^2 = b^2$。
**对**：在 $\triangle ABC$ 中，若 $a=3,b=4,c=5$，则 $a^2 + b^2 = c^2$，$\angle C = 90^\circ$。

> 关键：先确定最大边（斜边）是谁。

### ❌ 易错2：忽略直角条件直接使用勾股定理

**错**：在 $\triangle ABC$ 中，$AB = 3, AC = 4$，则 $BC = 5$。
**对**：只有 $\triangle ABC$ 是直角三角形且 $\angle A = 90^\circ$（或确定直角边和斜边）时，才能使用勾股定理。

### ❌ 易错3：最短路径展开方式不全面

**错**：长方体最短路径只考虑一种展开方式。
**对**：长方体有三种不同的展开方式，需要分别计算后取最小值。

### ❌ 易错4：逆定理使用中混淆

**错**：$a^2 + b^2 = c^2$ 推出 $\angle A = 90^\circ$。
**对**：$a^2 + b^2 = c^2$ 推出 $\angle C = 90^\circ$（$c$ 是最大边，最大边对的角是直角）。

### ❌ 易错5：开方遗漏负根

在几何问题中，边长取正值。
**错**：$c^2 = 25$，则 $c = \pm 5$。
**对**：$c^2 = 25$，$c > 0$，则 $c = 5$。

## 五、公式卡片

| 公式 | 说明 |
|:---|:---|
| $a^2 + b^2 = c^2$ | 勾股定理（$c$ 为斜边） |
| $c = \sqrt{a^2 + b^2}$ | 已知两直角边求斜边 |
| $b = \sqrt{c^2 - a^2}$ | 已知斜边和一直角边求另一直角边 |
| $h = \dfrac{ab}{c}$ | 直角三角形斜边上的高（面积法） |
