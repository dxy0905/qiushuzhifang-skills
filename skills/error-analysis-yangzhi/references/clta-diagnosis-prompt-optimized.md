# CLTA 错因诊断 Prompt 模板（学霸基本法实战优化版）

> 来源：学霸基本法项目实战迭代（2026-07-06）  
> 场景：拍照上传作业 → OCR识别 → AI诊断 → 追问引导

## 核心要求

诊断不是贴标签，必须写出完整的因果关系：

1. **具体到哪个概念** — 不是"概念不清"，而是"二次根式被开方数必须≥0这个概念不理解"
2. **解释正确理解** — 用通俗语言说明正确答案和推理过程
3. **给出追问引导** — 设计1-2个问题让学生自己发现错误
4. **设计变式练习** — 1道同类但不同情境的题目

## 5分类法（带具体输出要求）

| 错因类型 | 必须输出的内容 |
|:---------|:---------------|
| 概念不清 | 具体哪个概念/定理/公式没理解 + 正确理解应该是什么 |
| 方法不会选 | 面对什么条件时不知道该用什么方法 + 应该用什么方法 |
| 步骤不完整 | 具体漏了哪一步 + 这一步为什么不能跳 + 完整步骤 |
| 审题不仔细 | 具体漏了哪个条件/看错了什么 + 正确理解题目要求 |
| 迁移不足 | 新旧情境的差异点 + 为什么本质相同但学生没看出来 |

## 诊断输出格式

```
1. 错因类型：[5类之一] → [具体概念/步骤/条件的名称]
2. 判断依据：引用学生原话或解题过程
3. 正确理解（重点）：通俗语言解释
4. 追问引导（重要）：1-2个引导性问题
5. 变式练习：1道同类题
```

## 实战示例

学生答"√(x-3)有意义，x≥0"时的诊断：

```
错因类型：概念不清
→ 具体概念：二次根式有意义的条件——混淆了"x≥0"和"x-3≥0"
→ 正确理解：根号下是x-3这个整体不是x本身，应满足x-3≥0即x≥3
→ 追问引导：
   ① 二次根式√a的被开方数a有什么要求？
   ② 如果改成√(x+5)有意义，x范围是什么？
→ 变式练习：若√(2x+4)有意义，求x取值范围
```

## 系统集成方式

在 FastAPI 后端 `services/agent_service.py` 中定义 `CLTA_DIAGNOSE_PROMPT`，
前端通过 `/api/v2/diagnose/analyze` 调用。

响应格式（api_v2）：
```json
{
  "code": 0,
  "data": {
    "analysis": "完整诊断文本（含错因+正确理解+追问+变式）",
    "error_types": ["概念不清", "..."],
    "suggestions": ["学习建议1", "..."]
  },
  "message": "ok"
}
```

前端解包：`var diag = data.code !== undefined ? data.data : data;`
