# 速查表

## 一、有理数

### 分类
$$
\text{有理数}\begin{cases}
\text{整数}\begin{cases}\text{正整数}\\ \text{0}\\ \text{负整数}\end{cases}\\
\text{分数}\begin{cases}\text{正分数}\\ \text{负分数}\end{cases}
\end{cases}
$$

### 绝对值
$$
|a| = \begin{cases}
a & (a > 0)\\
0 & (a = 0)\\
-a & (a < 0)
\end{cases}
$$

### 比较大小
- 正数 $>$ $0$ $>$ 负数
- 两个负数，绝对值大的反而小

## 二、有理数的运算

### 交换律
- $a + b = b + a$
- $a \times b = b \times a$

### 结合律
- $(a + b) + c = a + (b + c)$
- $(a \times b) \times c = a \times (b \times c)$

### 分配律
- $a \times (b + c) = a \times b + a \times c$

### 运算顺序
**先乘方 → 再乘除 → 最后加减 → 有括号先算括号里的**

### 科学记数法
$$
N = a \times 10^n \quad (1 \le |a| < 10)
$$

## 三、整式

### 单项式
- 系数：数字因数
- 次数：所有字母指数之和
- 如：$-5x^2y^3$ 系数 $-5$，次数 $5$

### 同类项判断
字母相同 **且** 相同字母的指数相同 ✅

### 合并同类项
**系数相加，字母和指数不变**

### 去括号
- $+(a-b+c) = a-b+c$
- $-(a-b+c) = -a+b-c$

## 四、解一元一次方程

### 步骤
**去分母 → 去括号 → 移项 → 合并同类项 → 系数化为1**

### 移项
**移项要变号**：$+ \to -$，$- \to +$

## 五、几何

### 直线、射线、线段
| 图形 | 端点 | 长度 |
|------|------|------|
| 直线 | 0 | 不可度量 |
| 射线 | 1 | 不可度量 |
| 线段 | 2 | 可度量 |

### 线段公理
**两点之间，线段最短**

### 角度换算
$$
1^\circ = 60', \quad 1' = 60''
$$

### 余角与补角
- 互余：$\angle 1 + \angle 2 = 90^\circ$
- 互补：$\angle 1 + \angle 2 = 180^\circ$
- 同角（等角）的余角相等
- 同角（等角）的补角相等
