## 二、几何证明专项检测（推理步骤第2步）

```
2) 对于**几何证明题（含"求证""证明""已知"等关键词）**，额外检查以下三点：
   a) 学生是否根据题意正确地写出了"已知"（已知条件提取是否完整准确？有没有漏条件或多加条件？）
   b) 学生是否明确写出了"求证"（求证目标是否正确？）
   c) 证明过程是否遵循"已知→求证→证明"的三段式书写规范？
      "判定定理"和"性质定理"是否混用？
      （例如：用"同旁内角互补"来证明平行——这是判定；
             用"两直线平行，同旁内角互补"——这是性质。
             判定和性质顺序不能倒置。）
```

### 三条检查分别对应什么错因

| 检查项 | 检测到的问题 | 对应错因类型 |
|--------|-------------|:-----------:|
| 已知条件提取不完整 | 学生没写已知/漏条件/多加条件 | 规范缺失 或 审题偏差 |
| 求证目标写错 | 证明方向错误 | 审题偏差 或 概念模糊 |
| 判定定理与性质定理混用 | 使用顺序颠倒 | 概念模糊 |
| 缺少证明过程 | 只写结果没写推导 | 规范缺失 或 思路中断 |

## 三、新增字段说明

### 3.1 per_question[].corrective_guidance

```json
{
  "corrective_guidance": "针对该错题的具体纠正措施（约20-60字），如'严格遵循已知→求证→证明的三段式书写规范'"
}
```

**写作原则：** 必须是具体的"怎么做"（行为要求），不是笼统的"需要加强"。

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| 需要加强证明题训练 | 严格遵循已知→求证→证明的三段式书写规范，落实步步有据的推理习惯 |
| 计算能力有待提高 | 回归小学整数加法基础，通过数轴演示强化合并含义，养成每步验算习惯 |
| 概念要弄清楚 | 通过变式训练厘清平行线的判定定理与性质定理的适用条件，避免条件与结论倒置 |

### 3.2 corrective_guidance_list

```json
{
  "corrective_guidance_list": [
    "针对全部错题的综合性纠正指导（1-3条，每条含具体行为要求）"
  ]
}
```

**作用：** 给用户看的"测试练习"指引，不是诊断本身。可以理解为"看完诊断后学生应该去做什么"。

**示例（几何证明题失败场景）：**
```
建议后续严格遵循"已知→求证→证明"的三段式书写规范，
落实"步步有据"的推理习惯；
同时通过变式训练厘清"判定"与"性质"的逻辑先后顺序，
避免条件与结论倒置。
```

## 四、错因分类定义扩展

### 4.1 审题偏差 — 新增判断标准

```
| 审题偏差 | 误读题设条件、漏看关键词 | 抄错数、看错符号、
                            忽略题干隐含条件、
                            已知条件提取错误或不完整 |
```

**关键：** 如果学生提取已知条件时漏了条件或多加了条件，应归为「审题偏差」而非「概念模糊」。区分标准：重新读题后学生能否自行发现错误。

### 4.2 规范缺失 — 新增判断标准

```
| 规范缺失 | 解题格式/步骤不规范 | 跳步、没写"已知"/"求证"/"证明"格式、
                         没写必要条件、没验证、
                         分类讨论不完整 |
```

**关键：** 几何证明题缺少"已知→求证→证明"三段式格式，即使思路正确也归为「规范缺失」。

### 4.3 概念模糊 — 新增判断标准

```
判断标准中新增：判定定理与性质定理混用
```

**区分方法：**
- **判定定理** — 由角的关系推平行（同位角相等→两直线平行）
- **性质定理** — 由平行推角的关系（两直线平行→同位角相等）
- 学生混用两者（用性质推判定、或用判定推性质）→ 概念模糊

## 五、注意事项（V2.1新增的6-9条）

```
6. **对于几何证明题**，务必检查学生是否写出了正确的"已知"
   ——这是最基础的步骤，如果已知条件提取错或没写已知，
   整个证明就失去了根基

7. **corrective_guidance 字段**必须写具体的"怎么做"（行为要求），
   而不是笼统的"需要加强"
   ——如"严格遵循已知→求证→证明的三段式书写规范，
        落实步步有据的推理习惯"

8. **corrective_guidance_list** 必须包含1-3条综合性纠正指导，
   每条都要有具体的书写规范或推理习惯要求

9. **诊断分析文本必须在JSON之前输出**，分析文字不少于200字
```

## 六、生产验证结果

### 测试用例：3题平行线几何证明

**输入：**
```
第1题：已知AB∥CD，∠1=50°，求∠2的度数 → 正确作答
第2题：已知AD∥BC，∠A=120°，求∠B的度数 → 同旁内角误判为内错角
第3题：已知AB∥CD，∠1=60°，求证∠2=∠3 → 仅写"∠2=60°"，缺已知/求证/证明
```

**V2.1诊断结果：**

| 题号 | 正误 | 错因 | 纠正指导 |
|:----:|:----:|:-----|:---------|
| 1 | ✅ | 无 | — |
| 2 | ❌ | 概念模糊（同旁内角误判为内错角） | 强化"三线八角"模型训练 |
| 3 | ❌ | 规范缺失（缺已知/求证前置步骤） | 严格遵循已知→求证→证明的三段式书写规范 |

**综合纠正指导：**
```
建议后续严格遵循"已知→求证→证明"的三段式书写规范，
落实"步步有据"的推理习惯；同时通过"三线八角"变式训练
厘清平行线性质定理的适用条件，避免概念混淆与格式缺失。
```

### 实测关键数据
- 完整输出长度：~4000 tokens（3题几何分析）
- max_tokens 已从 4096 → 8192（防止截断）
- 模型：deepseek-v4-flash，temperature=0.3
- 主力模型配置：`routers/agent_routes.py:85` → `LLMClient(provider="deepseek")`（⚠ Agnes AI output gets truncated at 4096 tokens with finish_reason=length）
