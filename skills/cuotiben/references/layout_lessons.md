# 布局迭代教训（2026-07-08会话）

## 用户布局偏好（定稿）

1. **按钮** — 两行显示（`<br>`换行），去掉`[]`，默认灰色，步骤激活变蓝
   - `.ub`: `font-size:12px;padding:6px 10px;border-radius:8px`
   - 默认: `color:#999;background:#f5f5f5`
   - active/hover: `color:var(--blue);background:var(--blue-light)`

2. **三栏结构**（最终定稿V7）
   ```
   左栏 20%    |   中栏 flex:1     |   右栏 20%
   资料清单     |   图片预览          |   知识点归纳
   暂无文件     |   ──分割线──        |   练习测试
   ──────────── |   错因分析           |   ───────────
   上传/文件    |   ──聊天区──        |   理解继续
   拍照/上传    |   师生对话           |   保存退出
   增强/识别    |   输入框            |   还原默认
   错题/笔记    |                    |
   ```

3. **文本偏好**
   - "上传资料清单" → "资料清单"
   - "上传资料开始学习" → "开始学习"
   - 按钮文字去掉`[]`方括号
   - 不分栏按钮文字两行：上传/文件、拍照/上传、增强/识别、错题/笔记

4. **左右对称**
   - `.l-footer` 和 `.r-footer` 同高110px
   - `.ub` 和 `.rb` 样式完全一致
   - 右栏底部位置固定

## 关键教训

- **用户说"对调"前**，先确认具体指哪个内容块 vs 整列互换
- **每次只改一个元素的位置**，改完让用户刷新确认再继续
- **用户说的"第二栏"=中栏，"第三栏"=右栏**
- **聊天区/输入框始终在第二栏最底部** — 用户多次强调不动
- **不要一次改多个位置** — 每次只改一个区域，确认后再改下一个

### 2026-07-09新增教训

- **学员发言区不动** — 用户说「学员发言（问答）区不用调整，位置依然放于原位置即可」→ 原位置=中栏最底部
- **对调须确认类型** — 用户说「对调」时先问是「内容块互换」还是「整列互换」
- **诊断最终在知识点tab** — 错因分析显示在第三栏「知识点归纳」tab（rtab-kg），诊断后自动 switchRtab('kg')
- **成绩目标移登录页** — 现在成绩/期末目标/中考目标从个人信息页移至登录页首行，减少操作步骤。个人页和登录页的输入框ID要不同避免冲突（phonePm vs phone）
- **名称修改调宽度** — 字段名修改后（昵称→老师昵称、昵称→姓名昵称）要同步调整标签宽度（36px→60px/70px）适应新文本
- **框体统一样式** — 所有输入框统一 font-size:12px、padding:6px 8px。字段名在上方 display:block、输入框在下方，使行列整齐对齐。同一行内各元素宽度需协调（老师昵称80%、性别60%、形象/声音50%）
- **登录页手机验证独立行** — 手机号+验证码从3列布局中独立为单独一行，不嵌套在td内。colspan=2跨两列居中显示
