# 2026-07-08 OCR数学符号修复实战记录

## 测试案例

学生作业OCR结果（二次根式单元）：
```
4.使二次根式Vx+3有意义的x的取值范围是
1≤3
```

## 修复对照

| 原始OCR | 修复后 | 方法 |
|---------|--------|------|
| `V3` | `√3` | V→√ 直接替换 |
| `Vx+3` | `√(x+3)` | V→√ + √括号补全 |
| `1≤3` | `x≤3` | 不等式上下文中1→x（非多位数） |
| `X` | `x` | 大写X在行首/不等式前→小写x |
| `V0. 01` | `√0.01` | V→√ + 数字中点空格修复 |
| `进步1）` | `进步！）` | OCR将！识别为1 |

## 正则表达式

```python
# 变量x被识别为1（仅在不等式/方程上下文中）
text = re.sub(r'(?<![.\d])(1)(?=[≤≥<>=](?:\s*\d|\s*x|\s*√|\s*[a-z]))', 'x', text)

# 大写X→x（数学上下文中）
text = re.sub(r'(?<=[≤≥<>=+\-×÷√(])\s*X\b', 'x', text)
text = re.sub(r'\bX\s*(?=[≤≥<>=])', 'x', text)
text = re.sub(r'^X\b', 'x', text)

# 数字中点空格
text = re.sub(r'(\d)\.\s+(\d)', r'\1.\2', text)

# 取值范围上下文
text = re.sub(r'(取值范围是)\s*1\s*([≤≥])', r'\1x\2', text)
```

## 关键经验

1. **不要替换所有"1"** — 仅替换不等式左边/运算符后的独立"1"
2. **不要替换"X"在英文词中** — 仅在数学上下文中（运算符前后）
3. **数字空格修复要精准** — 仅当数字间有点和空格时，不影响正常单词间距
4. **选择题选项加空格** — `A.√7` → `A. √7`（正则：`([A-Z])\.([√×±])`）
5. **大图(>400px)不走LaTeX-OCR** — 会输出乱码
