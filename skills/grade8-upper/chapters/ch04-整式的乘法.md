# 第十六章 整式的乘法

## 核心内容

本章是代数运算的进阶，从幂的运算性质出发，逐步学习整式的乘法（单项式×单项式、单项式×多项式、多项式×多项式），再学习同底数幂的除法与整式除法，为零指数幂和负整数指数幂打下基础。

---

## 各节知识点

### 16.1 同底数幂的乘法

**法则：** 同底数幂相乘，底数不变，指数相加。

$$a^m \cdot a^n = a^{m+n} \quad (a \neq 0, \ m, n \ \text{为正整数})$$

**推广：** $a^m \cdot a^n \cdot a^p = a^{m+n+p}$

> **记忆口诀：** 同底数幂相乘，底数不变指数加。

> **易错点：** 不是同底数幂时，不能直接应用此法则。需先化为同底再计算。

---

### 16.2 幂的乘方

**法则：** 幂的乘方，底数不变，指数相乘。

$$(a^m)^n = a^{mn} \quad (a \neq 0, \ m, n \ \text{为正整数})$$

**区别：**
- 幂的乘方：$(a^m)^n = a^{mn}$
- 同底数幂乘法：$a^m \cdot a^n = a^{m+n}$

> **易错点：** 容易混淆"指数相加"和"指数相乘"。注意区分幂的乘方和同底数幂乘法。

---

### 16.3 积的乘方

**法则：** 积的乘方，等于把积的每一个因式分别乘方，再把所得的幂相乘。

$$(ab)^n = a^n b^n \quad (a, b \neq 0, \ n \ \text{为正整数})$$

**推广：** $(abc)^n = a^n b^n c^n$

> **注意：** 积的乘方法则本质是乘法的交换结合律与幂的定义推导而来。

---

### 16.4 整式的乘法

#### 单项式乘以单项式

**法则：** 单项式与单项式相乘，把它们的系数、同底数幂分别相乘，对于只在一个单项式里含有的字母，则连同它的指数作为积的一个因式。

> **步骤：** （1）系数相乘（2）同底数幂相乘（3）单独字母照写

#### 单项式乘以多项式

**法则：** 单项式与多项式相乘，就是用单项式去乘多项式的每一项，再把所得的积相加。

$$m(a + b + c) = ma + mb + mc$$

> **本质：** 乘法分配律的直接应用。

#### 多项式乘以多项式

**法则：** 多项式与多项式相乘，先用一个多项式的每一项乘另一个多项式的每一项，再把所得的积相加。

$$(a + b)(c + d) = ac + ad + bc + bd$$

**常用公式（平方差公式和完全平方公式在下一章因式分解中也会用到，这里提前学习）：**

**平方差公式：**
$$(a + b)(a - b) = a^2 - b^2$$

**完全平方公式：**
$$(a + b)^2 = a^2 + 2ab + b^2$$
$$(a - b)^2 = a^2 - 2ab + b^2$$

> **记忆口诀：** 首平方，尾平方，二倍乘积在中央。（注意符号）

**其他常用乘法公式：**
$$(x + a)(x + b) = x^2 + (a + b)x + ab$$

---

### 16.5 同底数幂的除法

**法则：** 同底数幂相除，底数不变，指数相减。

$$a^m \div a^n = a^{m-n} \quad (a \neq 0, \ m > n, \ m, n \ \text{为正整数})$$

#### 零指数幂

**规定：** 任何不等于 0 的数的 0 次幂都等于 1。

$$a^0 = 1 \quad (a \neq 0)$$

> $0^0$ 无意义。

#### 负整数指数幂

**规定：** 任何不等于 0 的数的 $-n$（$n$ 为正整数）次幂，等于这个数的 $n$ 次幂的倒数。

$$a^{-n} = \frac{1}{a^n} \quad (a \neq 0, \ n \ \text{为正整数})$$

---

### 16.6 整式的除法

#### 单项式除以单项式

**法则：** 单项式相除，把系数与同底数幂分别相除作为商的因式，对于只在被除式里含有的字母，则连同它的指数作为商的一个因式。

#### 多项式除以单项式

**法则：** 多项式除以单项式，先把这个多项式的每一项除以这个单项式，再把所得的商相加。

$$(am + bm + cm) \div m = a + b + c$$

---

## 幂的运算法则汇总

| 名称 | 公式 | 口诀 |
|------|------|------|
| 同底数幂乘法 | $a^m \cdot a^n = a^{m+n}$ | 底不变，指相加 |
| 幂的乘方 | $(a^m)^n = a^{mn}$ | 底不变，指相乘 |
| 积的乘方 | $(ab)^n = a^n b^n$ | 各因式分别乘方 |
| 同底数幂除法 | $a^m \div a^n = a^{m-n} \ (a \neq 0)$ | 底不变，指相减 |
| 零指数幂 | $a^0 = 1 \ (a \neq 0)$ | 非零数的 0 次幂为 1 |
| 负整数指数幂 | $a^{-n} = \dfrac{1}{a^n} \ (a \neq 0)$ | 取倒数再乘方 |

---

## 典型题型

### 题型一：幂的运算

**例1：** 计算 $a^3 \cdot a^5$
> **解：** $a^3 \cdot a^5 = a^{3+5} = a^8$

**例2：** 计算 $(a^3)^4 \div a^5$
> **解：** $(a^3)^4 \div a^5 = a^{12} \div a^5 = a^{12-5} = a^7$

### 题型二：整式乘法

**例3：** 计算 $2x^2 \cdot 3x^3$
> **解：** $2x^2 \cdot 3x^3 = (2 \times 3) \cdot (x^2 \cdot x^3) = 6x^5$

**例4：** 计算 $(2x + 1)(x - 3)$
> **解：** $(2x + 1)(x - 3) = 2x \cdot x + 2x \cdot (-3) + 1 \cdot x + 1 \cdot (-3)$
> $= 2x^2 - 6x + x - 3 = 2x^2 - 5x - 3$

### 题型三：乘法公式

**例5：** 计算 $(x + 2)(x - 2)$
> **解：** $(x + 2)(x - 2) = x^2 - 2^2 = x^2 - 4$

**例6：** 计算 $(3x + 1)^2$
> **解：** $(3x + 1)^2 = (3x)^2 + 2 \cdot 3x \cdot 1 + 1^2 = 9x^2 + 6x + 1$

### 题型四：零指数与负指数

**例7：** 计算 $(-3)^0 + 2^{-2}$
> **解：** $(-3)^0 + 2^{-2} = 1 + \dfrac{1}{2^2} = 1 + \dfrac{1}{4} = \dfrac{5}{4}$

---

## 易错点

1. **幂的乘方和同底数幂乘法混淆**：$(a^m)^n = a^{mn}$（指数相乘）vs $a^m \cdot a^n = a^{m+n}$（指数相加）。

2. **积的乘方漏乘**：$(ab)^n = a^nb^n$ 每个因式都要乘方，如 $(2a)^3 = 2^3 \cdot a^3 = 8a^3$，不是 $2a^3$。

3. **符号错误**：多项式乘法中负号处理错误，如 $(x-2)(x+3)$ 计算时忘记 $-2 \times 3 = -6$。

4. **零指数幂误用**：$0^0$ 无意义，只有非零数的 0 次幂才等于 1。

5. **负指数理解错误**：$a^{-n} = \dfrac{1}{a^n}$，不是 $-\dfrac{1}{a^n}$ 或 $\dfrac{1}{a^{-n}}$。

6. **乘法公式展开不全**：完全平方公式 $(a+b)^2 = a^2 + 2ab + b^2$，少了中间项 $2ab$。

7. **多项式乘多项式漏项**：$(a+b)(c+d)$ 应该得到 4 项，容易漏掉某些交叉项。

8. **同底数幂除法条件忘记**：$a^m \div a^n = a^{m-n}$ 的前提是 $a \neq 0$，且 $m > n$。
