## 核心知识点速查

### 代数部分（第二十五～二十七章）

| 知识点 | 公式 / 描述 |
|--------|-------------|
| 一元二次方程一般形式 | $ax^2+bx+c=0 \quad (a \neq 0)$ |
| 判别式 | $\Delta = b^2-4ac$ |
| 求根公式 | $x = \dfrac{-b \pm \sqrt{b^2-4ac}}{2a}$ |
| 根与系数关系（韦达定理） | $x_1+x_2 = -\dfrac{b}{a},\; x_1x_2 = \dfrac{c}{a}$ |
| 配方法 | $x^2+px \rightarrow (x+\dfrac{p}{2})^2 - (\dfrac{p}{2})^2$ |
| 二次函数一般式 | $y=ax^2+bx+c \quad (a \neq 0)$ |
| 顶点式 | $y=a(x-h)^2+k$，顶点 $(h,k)$ |
| 顶点坐标公式 | $(-\dfrac{b}{2a},\; \dfrac{4ac-b^2}{4a})$ |
| 对称轴 | $x = -\dfrac{b}{2a}$ |
| 反比例函数一般形式 | $y = \dfrac{k}{x} \quad (k \neq 0)$ |
| k的几何意义 | $|k| = |x \cdot y|$ = 矩形面积 |

### 几何部分（第二十八～三十章）

| 知识点 | 描述 |
|--------|------|
| 旋转三要素 | 旋转中心、旋转方向、旋转角 |
| 中心对称 | 旋转 $180^\circ$ 后与自身重合 |
| 垂径定理 | 垂直于弦的直径平分弦及其所对的两条弧 |
| 圆周角定理 | 同弧所对圆周角是圆心角的一半 |
| 切线的判定 | $d=r \Leftrightarrow$ 直线与圆相切 |
| 切线性质 | 切线 $\perp$ 过切点的半径 |
| 切线长定理 | 从圆外一点引两条切线长相等 |
| 弧长公式 | $l = \dfrac{n\pi r}{180}$ |
| 扇形面积公式 | $S = \dfrac{n\pi r^2}{360} = \dfrac{1}{2} l r$ |
