# 七年级下册·术语表

- **对顶角** — 两条直线相交，两边分别互为反向延长线的两个角（ch01）
- **邻补角** — 有一条公共边，另一边互为反向延长线的两个角，和为180°（ch01）
- **同位角** — 两条直线被第三条直线所截，位置相同的一对角，F型（ch01）
- **内错角** — 截线两侧、两条直线内部的一对角，Z型（ch01）
- **同旁内角** — 截线同侧、两条直线内部的一对角，U型（ch01）
- **平行线** — 同一平面内不相交的两条直线（ch01）
- **命题** — 判断一件事情的语句，由题设和结论组成（ch01）
- **平移** — 图形沿某一方向移动一定距离的变换（ch01）
- **平方根** — 若$x^2=a$，则x是a的平方根（ch02）
- **算术平方根** — 非负的平方根（ch02）
- **立方根** — 若$x^3=a$，则x是a的立方根（ch02）
- **无理数** — 无限不循环小数（ch02）
- **实数** — 有理数+无理数的统称（ch02）
- **有序数对** — 有顺序的两个数组成的数对(a,b)（ch03）
- **平面直角坐标系** — 由x轴、y轴和原点组成的坐标系统（ch03）
- **象限** — 坐标系分成的四个区域（ch03）
- **二元一次方程** — 含两个未知数，次数为1的整式方程（ch04）
- **二元一次方程组** — 由两个二元一次方程组成的方程组（ch04）
- **代入消元法** — 用代入的方式消去一个未知数（ch04）
- **加减消元法** — 通过加减运算消去一个未知数（ch04）
- **不等式** — 用不等号连接的式子（ch05）
- **不等式的解集** — 所有解的集合（ch05）
- **一元一次不等式** — 含一个未知数、次数为1的不等式（ch05）
- **一元一次不等式组** — 两个一元一次不等式组成的组（ch05）
- **总体** — 所有考察对象的全体（ch06）
- **个体** — 每一个考察对象（ch06）
- **样本** — 从总体中抽取的部分个体（ch06）
- **全面调查** — 对所有调查对象进行的调查（ch06）
- **抽样调查** — 从总体中抽取样本进行调查（ch06）
- **频数** — 各组中数据的个数（ch06）
- **频数分布直方图** — 用条形面积表示频数的统计图（ch06）
