# 第二章 有理数的运算

## 核心内容

本章在有理数概念的基础上，系统学习有理数的加、减、乘、除、乘方运算及混合运算，掌握科学记数法，提升运算能力。

## 各节知识点

### 2.1 有理数的加法

- **同号两数相加**：取相同的符号，并把绝对值相加
  - $(+5) + (+3) = +8$，$(-5) + (-3) = -8$
- **异号两数相加**：取绝对值较大的数的符号，并用较大的绝对值减去较小的绝对值
  - $(+5) + (-3) = +2$，$(-5) + (+3) = -2$
- **互为相反数的两数相加得 $0$**：$(-5) + (+5) = 0$
- **一个数与 $0$ 相加**，仍得这个数
- **加法交换律**：$a + b = b + a$
- **加法结合律**：$(a + b) + c = a + (b + c)$

### 2.2 有理数的减法

- **减法法则**：减去一个数等于加上这个数的相反数
  - $a - b = a + (-b)$
- 减法转化为加法后，再按加法法则计算

### 2.3 有理数的乘法

- **同号得正，异号得负**，再把绝对值相乘
  - $(+5) \times (+3) = +15$，$(-5) \times (-3) = +15$
  - $(+5) \times (-3) = -15$，$(-5) \times (+3) = -15$
- **任何数与 $0$ 相乘都得 $0$**
- **倒数**：乘积为 $1$ 的两个数互为倒数
  - $a \times \frac{1}{a} = 1$（$a \neq 0$）
  - $0$ 没有倒数
- **乘法交换律**：$a \times b = b \times a$
- **乘法结合律**：$(a \times b) \times c = a \times (b \times c)$
- **乘法分配律**：$a \times (b + c) = a \times b + a \times c$

### 2.4 有理数的除法

- **除法法则**：除以一个不等于 $0$ 的数，等于乘以这个数的倒数
  - $a \div b = a \times \frac{1}{b}$（$b \neq 0$）
- **两数相除，同号得正，异号得负**，再把绝对值相除
- $0$ 除以任何一个不等于 $0$ 的数都得 $0$

### 2.5 有理数的乘方

- **乘方**：求 $n$ 个相同因数的积的运算
  - $a^n = \underbrace{a \times a \times \cdots \times a}_{n\text{个}}$
  - $a$ 叫底数，$n$ 叫指数，$a^n$ 叫幂
- **正数的任何次幂都是正数**
- **负数的奇次幂是负数，负数的偶次幂是正数**
  - $(-2)^3 = -8$，$(-2)^4 = 16$
- **$0$ 的任何正整数次幂都得 $0$**

### 2.6 科学记数法

- 将一个大于 $10$ 的数表示成 $a \times 10^n$ 的形式（$1 \le a < 10$，$n$ 为正整数）
- $n = $ 原数的整数位数 $- 1$
  - 如：$567000000 = 5.67 \times 10^8$
- 小于 $-10$ 的数：$|a| \times 10^n$ 再加负号

### 2.7 有理数的混合运算

- **运算顺序**：先乘方，再乘除，最后加减；有括号先算括号里的
- 同级运算从左到右依次进行
- 善用运算律简化计算

## 典型题型

1. **加减混合运算**：将减法转化为加法，利用运算律简化
2. **乘除混合运算**：将除法转化为乘法，先定符号再算绝对值
3. **混合运算**：按运算顺序逐级计算
4. **科学记数法转换**：大数与科学记数法互转
5. **应用运算律**：利用分配律等简化复杂运算

## 易错点

1. ❌ 异号相加时误用绝对值相减后忘记取符号
   - ✅ 先定符号再算绝对值
2. ❌ 减法转加法时符号处理错误
   - ✅ $a - b = a + (-b)$，括号里的符号要变
3. ❌ 乘除时符号判断错误
   - ✅ 负号个数为奇数得负，偶数得正
4. ❌ 乘方运算混淆 $-3^2$ 与 $(-3)^2$
   - ✅ $-3^2 = -9$，$(-3)^2 = 9$
5. ❌ 科学记数法中 $a$ 的范围写错
   - ✅ $1 \le a < 10$，不是 $0 \le a < 10$
