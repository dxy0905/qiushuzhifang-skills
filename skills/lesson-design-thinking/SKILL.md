# 从"讲知识"到"设计思考"——教师备课规范

## 适用范围
邱数智方教育部全体教师（严教、麻老师、朱老师、邓老师、张训）

## 核心理念

> **记忆是思考的残留物。** 学生最后留下的，不是老师讲得最完整的部分，而是他们真正动脑处理过的内容。

备课的核心问题要从：
> ❌ "我要怎样把这个知识点讲明白？"
> ✅ **"学生在这个环节会实际思考什么？"**

---

## 备课六步法

### 第一步：确定"学生要思考什么"

备课时，先问自己三个问题：

| # | 问题 | 示例（分数除法） |
|:-:|:-----|:----------------|
| 1 | 这节课学生最应该思考的核心问题是什么？ | "除以一个分数"到底是什么意思？ |
| 2 | 这个知识点在回答一个什么问题？ | 半米绳子每¼米剪一段，能剪几段？ |
| 3 | 学生想通这个问题后，应该能理解什么？ | 除以一个分数等于乘以它的倒数 |

**输出：** 一句话的核心思考目标，写在教案最上方。

---

### 第二步：把知识还原成问题

知识点本身是某个问题的答案。没有问题的答案，只是信息。

**方法：** 对每个知识点，追问"这个知识在回答什么问题？"

| 知识点（答案） | 还原成问题 |
|:---------------|:-----------|
| 除以一个分数等于乘以它的倒数 | 半米绳子每¼米剪一段，可以剪几段？ |
| 光合作用是把光能转化为化学能 | 一棵小树长成大树的重量从哪里来？ |
| 三角形内角和等于180° | 为什么三角形的三个角加起来总是180度？ |
| 勾股定理 a²+b²=c² | 直角三角形的三条边之间有什么关系？ |

**输出：** 每个知识点对应1-2个核心问题，写在教案中"问题设计"栏。

---

### 第三步：设计一条思考路径

好的问题需要被组织成一条可以推进的思考路径。借用故事的结构：

```
冲突 → 因果关系 → 子问题拆解 → 走向答案
```

**具体方法：**

1. **制造一个学生能感受到的冲突**
   - 学生的直觉答案 vs 事实不符
   - 两个已知信息看似矛盾
   
2. **给出清楚的因果关系**
   - 为什么直觉错了？关键在哪里？
   
3. **把大问题拆成几个子问题**
   - 每个子问题指向一个思考台阶
   
4. **让学生一步步走向答案**
   - 每个子问题解决后，离答案就更近一步

**示例——光合作用：**

```
冲突：一棵小树长成大树，重量从哪里来？
     → 学生直觉"来自土壤"
     → 追问：如果主要来自土壤，为什么土壤没有明显减少？

因果：重量主要来自空气中的二氧化碳，不是土壤

子问题：水有没有参与？光起什么作用？叶绿体是做什么的？

答案：光合作用——光能→化学能，CO₂+H₂O→有机物+O₂
```

**输出：** 用 Mermaid 或箭头图画出思考路径，写在教案"教学过程"栏。

---

### 第四步：检查"学生实际会思考什么"

这是最关键也最容易出错的一步。备课时要问自己：

```
我设计的这个活动中，学生实际会思考什么？
有没有可能偏离学习目标？
```

**典型偏差检查：**

| 活动类型 | 学生可能在想 | 是否偏离目标 |
|:---------|:------------|:------------|
| 看了个有趣的视频 | "这个动画好酷" | ⚠️ 可能偏离 |
| 小组讨论问题 | "老师什么时候叫我组" | ⚠️ 可能偏离 |
| 动手操作教具 | "这个教具怎么玩的" | ⚠️ 可能偏离 |
| 算一道有陷阱的题 | "原来这里有个坑" | ✅ 在目标上 |

**输出：** 在教案每步活动旁标注「学生预期思考内容」，用AI模拟验证。

---

### 第五步：用AI检查思考路径

AI不是用来出教案的，是用来检查和优化思考路径的。

**四个提示词模板：**

```
提示① 反推问题：
"我要教【知识点】，这个知识点是在回答什么问题？"

提示② 找冲突：
"学生在理解【知识点】时，可能有哪些直觉误解？怎样把这些误解设计成一个课堂问题？"

提示③ 拆路径：
"请把这个核心问题拆成几个适合学生逐步思考的子问题。"

提示④ 验证偏差（最重要）：
"下面这个活动中，学生实际会思考什么？哪些思考可能偏离学习目标？应该怎样调整？
【粘贴你的活动设计】"
```

**要求：** 每位教师在备课时至少使用模板④一次，用AI验证思考路径是否成立。

---

### 第六步：自我检查清单

备课完成后，逐项检查：

#### 通用检查
- [ ] 我是否明确了"学生要思考什么"？（不是"我要讲什么"）
- [ ] 知识点是否还原成了问题？
- [ ] 有没有一个能制造冲突的切入点？
- [ ] 学生沿着我的路径走，能一步步到达答案吗？

#### 活动设计检查
- [ ] 这个活动中，学生**实际**会思考目标知识，还是会被其他东西带偏？
- [ ] 兴趣材料（视频/故事/游戏）是为思考路径服务，还是反而喧宾夺主？
- [ ] 有没有用AI验证过学生的思考路径是否成立？

#### 评价一致性检查（CLTA对齐）
- [ ] "学什么"（思考目标）和"怎么评"（课后检测）是对应的吗？
- [ ] 学生思考过的内容，就是我要检测的内容吗？
