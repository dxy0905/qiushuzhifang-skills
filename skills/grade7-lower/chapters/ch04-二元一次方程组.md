# 第十章 二元一次方程组

## 核心内容
从一元到二元，引入方程组的理念。学习二元一次方程组的解法（代入消元和加减消元），并应用于实际问题。

## 1. 二元一次方程

### 定义
含有**两个未知数**，且含未知数的项的次数都是**1**的整式方程。
标准形式：$ax + by = c$（$a \neq 0$且$b \neq 0$）

### 解
使方程两边相等的两个未知数的值，记作$(x_0, y_0)$。
**有无数组解**（解不唯一）。

## 2. 二元一次方程组

### 定义
由两个二元一次方程组成的方程组。

### 解
同时满足两个方程的公共解。

## 3. 代入消元法
1. 将一个方程变形为$y = kx + b$或$x = ky + b$形式
2. 代入另一个方程，消去一个未知数
3. 解出一元一次方程
4. 回代求另一个未知数

## 4. 加减消元法
1. 使两个方程中某个未知数的系数**相等或互为相反数**
2. 相减（系数相等时）或相加（互为相反数时），消去一个未知数
3. 解出一元一次方程
4. 回代求另一个未知数

## 5. 三元一次方程组（了解）
含有三个未知数，每个方程含未知数的项次数为1。
解法：消元→二元一次方程组→一元一次方程（逐步消元）

## 6. 实际问题与方程组

### 解题步骤
1. **设**两个未知数
2. **列**两个方程
3. **解**方程组
4. **检验**是否符合实际意义
5. **答**

### 常见模型
| 类型 | 等量关系 |
|:-----|:---------|
| 和差倍分 | 大+小=和，大-小=差 |
| 行程问题 | 路程=速度×时间 |
| 工程问题 | 总量=效率×时间 |
| 商品问题 | 售价-进价=利润 |
| 数字问题 | 两位数=10×十位+个位 |

## 典型题型
- 代入/加减法解方程组（选择最优方法）
- 含参方程组的解
- 与坐标系结合（解即为两直线交点坐标）
- 实际应用题（鸡兔同笼等经典模型）

## 易错点
- ⚠️ 代入时要加括号（特别是系数不为1时）
- ⚠️ 加减时注意符号问题（减一个负数=加正数）
- ⚠️ 解完后忘记回代检验
- ⚠️ 实际应用忘记检验是否符合生活实际
