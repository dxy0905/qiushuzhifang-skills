# 第三章 代数式

## 核心内容

本章从具体的数过渡到用字母表示数，学习代数式的概念、列代数式和代数式求值，发展抽象思维能力。

## 各节知识点

### 3.1 用字母表示数

- 字母可以表示任意一个数
- 用字母表示数具有**一般性**和**简洁性**
- 常见表示：
  - 加法交换律：$a + b = b + a$
  - 乘法分配律：$a(b + c) = ab + ac$
  - 路程公式：$s = vt$

### 3.2 代数式

- **代数式**：用基本运算符号（$+$、$-$、$\times$、$\div$、乘方）把数和字母连接而成的式子
  - 单独一个数或一个字母也是代数式
  - 如：$3x$，$a + b$，$\frac{1}{2}ah$，$x^2$
- **不是代数式**：含等号（$=$）或不等号（$>$、$<$）的式子
- 写法规范：
  - 数字与字母相乘，数字写在前面：$3x$ 不写 $x3$
  - 数字与字母相乘，乘号省略：$ab$ 不写 $a \times b$
  - 带分数写假分数：$\frac{3}{2}x$ 不写 $1\frac{1}{2}x$
  - 除法写分数形式：$\frac{a}{b}$ 不写 $a \div b$

### 3.3 列代数式

- 把实际问题中的数量关系用代数式表示出来
- 关键：理解关键词对应的运算
  - "和" → $+$
  - "差" → $-$
  - "积" → $\times$
  - "商" → $\div$
  - "比 $a$ 大 $b$" → $a + b$
  - "$a$ 的 $b$ 倍" → $ab$

**常见模型**：
| 实际问题 | 代数式 |
|---------|--------|
| $x$ 与 $y$ 的和 | $x + y$ |
| $a$ 的 $3$ 倍与 $b$ 的差 | $3a - b$ |
| $m$ 与 $n$ 的积的 $2$ 倍 | $2mn$ |
| $a$ 与 $b$ 的和的平方 | $(a + b)^2$ |
| $a$、$b$ 两数的平方和 | $a^2 + b^2$ |

### 3.4 代数式求值

- 用具体数值代替代数式中的字母，按运算顺序计算出的结果
- 步骤：
  1. 写出原代数式
  2. 代入数值（注意：负数要加括号，分数乘方要加括号）
  3. 按运算顺序计算

**示例**：当 $x = -2$ 时，求 $3x^2 - 2x + 1$ 的值
- 代入：$3 \times (-2)^2 - 2 \times (-2) + 1$
- 计算：$3 \times 4 + 4 + 1 = 17$

## 典型题型

1. **判断代数式**：判断给定的式子是否为代数式
2. **列代数式**：根据文字描述列出代数式
3. **代数式求值**：代入具体数值计算
4. **实际问题建模**：用代数式表示实际问题中的数量关系

## 易错点

1. ❌ 代数式书写不规范
   - ✅ 数字在前字母在后，除号写成分数形式
2. ❌ 列代数式时运算顺序错误
   - ✅ "和的平方"与"平方和"要区分清
3. ❌ 代入负数时不加括号
   - ✅ 代入负数时一定要加括号，如 $(-2)^2$ 而非 $-2^2$
4. ❌ 代入分数乘方时不加括号
   - ✅ $(\frac{1}{2})^2$ 而非 $\frac{1}{2}^2$
5. ❌ 将含等号的式子误认为代数式
   - ✅ 代数式不含等号或不等号
