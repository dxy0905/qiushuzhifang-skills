## 一、核心理念

### 1.1 预习定位（调研报告核心结论）

| 认知 | 要点 |
|:-----|:-----|
| 预习是"侦察"而非"强攻" | 重在发现问题、形成期待，不追求全部搞懂；看不懂做标记，课堂重点听 |
| 预习是自主学习第一环 | "先学后教、以学定教"落地的关键前提，学生带着问题进课堂 |
| 预习≠归纳教材要点 | 通过活动引导思考、渗透数学问题，对知识形成过程有初步体验 |
| 现状诊断 | 当前初中生预习总体"有意识、低水平、缺方法、少反馈"——改进关键不在学生自觉，而在教师科学设计+方法指导+检查反馈 |

### 1.2 学教评一致性（CLTA）在预习中的映射

预习单是"学—教—评"闭环的第一环，五个栏目对应CLTA五要素：

| CLTA要素 | 预习单栏目 | 设计要点 |
|:--------:|:----------:|:---------|
| 学习目标 | 预习目标 | 明确"学什么、学到什么程度"，学生主体、可观可测 |
| 学情分析 | 旧知回顾 | 前测激活先备知识，暴露认知盲区（数学知识连续性强，"前面的坑不填，后面的路走不通"） |
| 学习活动 | 新知初探 | 低门槛任务（填空/选择/简单归纳），绝大多数学生看书能完成 |
| 评估任务 | 尝试练习 | 1—2道典型题检验预习效果，不要求全对，重在发现"哪里不会" |
| 以学定教 | 疑问记录 | 学生记录困惑、教师收集反馈，作为课堂二次备课的依据 |

> 预习单五要素口诀：**目标引路 → 旧知搭桥 → 初探新知 → 练习检验 → 疑问进课堂**

## 二、学生预习四大误区（识别与纠偏）

| 误区 | 典型表现 | 纠偏要点 |
|:-----|:---------|:---------|
| ① 走马观花式 | 只看不动笔，课本干干净净，扫一眼标题定义便合上书 | 强制"圈画标注"：重点/概念/公式圈出，空白处写眉批，问题作记号 |
| ② 刷题式 | 提前把练习册做完，上课觉得"都会"而走神，变式题照样错 | 预习做题限1—2道典型题，目的是发现不会而非全对；课堂重点听思路与易错点 |
| ③ 完美主义式 | 死磕每个不懂的细节，耗时徒增焦虑，破坏节奏 | 卡住的地方画问号标记，课堂重点听即可 |
| ④ 过度超前式 | 假期把整本书学完，"先入为主"错误认知难纠正 | 预习=侦察不是强攻，保护课堂新鲜感与探索欲 |

## 三、学生预习方法库（指导学生会预习）

### 3.1 六步预习法（读·查·思·比·记·练）

| 步骤 | 操作 | 要点 |
|:----:|:-----|:-----|
| 读 | 逐字逐句阅读新课内容，弄清中心问题 | 从总体上把握知识结构 |
| 查 | 旧概念/公式记不清时查旧教材或笔记 | 力争自查不留问题，前后知识衔接 |
| 思 | 多问"为什么"：重点难点、概念条件与含义 | 尝试推导公式、先做例题再对照、训练一题多解、学会质疑 |
| 比 | 新旧知识对照阅读 | 找相同点、类似点、差别，纳入已有知识链（如一元一次方程→一元一次不等式类比） |
| 记 | 做预习笔记 | 简短内容圈画批注；难点疑点写进笔记本 |
| 练 | 做课后基础练习检验效果 | 不要求全对，重在发现"哪里不会" |

### 3.2 三步预习法（带3个问题读课本 · 15—20分钟 · 适合绝大多数学生）

```
第一步 [3问精读]：①这一节主要讲什么？（合上书能用一句话概括）
                  ②哪些词、公式、定理是"新面孔"？（圈出来混个"脸熟"）
                  ③课本例题在讲什么？（先不看答案自己做一遍，再对照检查步骤、思考更简便方法）
第二步 [画问号]：把卡住的地方画上记号，明确"哪里不会"
第三步 [留问题]：记录1—3个最想在课堂上解决的问题，带着问题进课堂
```

### 3.3 其他方法速查表

| 方法 | 适用场景 | 操作要点 |
|:-----|:---------|:---------|
| 圈画标注法 | 通用（必用） | 重点圈画+空白处眉批，切忌只看不动笔 |
| 笔记预习法 | 通用 | 眉批笔记+摘录笔记（重点概念、关键语句）+疑惑记下课上质疑 |
| 温故知新法 | 新旧知识联系型新课 | 预习新内容时联系旧知识，复习巩固+初步理解，使知识系统化 |
| 尝试训练法 | 计算类、训练类新课 | "做题—遇阻—回看例题—再练"循环检验预习效果 |
| 动手操作法 | 公式推导、几何图形 | 剪、拼、折、移、摆、画、量、观察、比较（如三角形内角和：画锐/直/钝角三角形量角再剪拼验证） |
| 任务落实法 | 预习初期不知从何下手 | 教师设计任务（表格/问题形式），学生带着任务有的放矢 |

### 3.4 分课型预习策略

| 课型 | 预习重点 | 示例 |
|:-----|:---------|:-----|
| 概念课 | 通读定义、抓关键词、辨析内涵外延 | 预习"一元一次方程"：圈"一元"（一个未知数）、"一次"（未知数次数1）、"方程"（含未知数的等式），三个关键词连起来理解；结合正反例思考限制条件（如"为什么a≠0"） |
| 命题课（定理/公式） | 弄清条件与结论、尝试推导过程 | "平方差公式"：用多项式乘法一步步展开再观察规律，忘记公式也能自行推导；几何定理看重证明思路，关键步骤旁标注推理依据 |
| 例题课（习题课） | 遮答案先做→对照→找更简方法→析错因 | 做错的要分析错误原因，课堂重点听讲 |
| 单元复习课 | 整体梳理知识框架 | 思维导图串联概念/公式/定理；对比相似知识异同（如平行四边形、矩形、菱形、正方形性质与判定整理对比） |

### 3.5 时间与节奏管理

- **日常预习**：每天固定15—20分钟，节奏"3分钟目标定位 + 10分钟精读课本 + 7分钟做题检验"，安排在当天作业完成之后
- **单元预习**：周末安排约1小时进行单元整体预习，梳理知识框架
- **把握分寸**：预习是"侦察"而非"强攻"，看不懂的地方做标记，课堂重点听讲即可

## 四、教师编写预习提纲（预习单设计 · CLTA五要素）

### 4.1 预习单五要素标准结构

```
【基本信息】科目/年级/班级/姓名/课题/预习日期/预习时长/预习评价（优秀·良好·一般·需改进）

【一、预习目标】——对应"学什么、学到什么程度"
  了解本节课主要学习内容；初步掌握的核心知识点；预习需达成的小目标
  （以学生为主体表述，通俗易懂，可观察可检测）

【二、旧知回顾】——对应"学情前测/激活旧知"
  设计与新知识相联系的旧知复习题（2—3道），起到温故知新作用

【三、新知初探】——对应"学习活动"（难度要低）
  把概念、性质、公式设计成填空题、选择题或简单归纳，
  让绝大多数学生通过看书自学能完成

【四、尝试练习】——对应"评估任务"
  1—2道典型题检验预习效果；完成情况自评（全部完成·大部分完成·部分完成·未完成）

【五、疑问记录】——对应"以学定教"
  "本节课你的困惑"留白：不懂的知识点/概念、不会做的题目、其他想课堂提问的内容
```

### 4.2 设计三原则

1. **目标导向**：任务围绕预习目标设计，不偏离；目标表述以学生为主体、通俗易懂、依据学情保持弹性
2. **难度适宜**：任务要具体、量要适当、难度适中，具有诱发性和趣味性，要求明确可操作
3. **分层设计**：
   - 基础层：教材中最基础的概念与简单练习——让每位学生都能体会到成功
   - 拓展层：思维导图梳理、知识迁移、生活中的数学——满足学有余力学生需求

### 4.3 分课型预习提纲设计要点

| 课型 | 新知初探栏目设计 |
|:-----|:----------------|
| 概念课 | 关键词填空 + 正反例判断（"下列哪个是方程？"） |
| 命题课 | 条件/结论梳理表格 + 推导步骤关键处留空 |
| 例题课 | 遮答案试做 + "做到哪一步卡住了"记录栏 |
| 单元复习课 | 框架图填空 + 相似概念对比表 |

### 4.4 AI生成预习单提示词模板（完整版·CLTA五要素）

```
你是初中数学AI预习单设计师，精通学教评一致性（CLTA）理念。
学生BKT掌握概率：[<0.3基础层 / 0.3-0.7提高层 / >0.7拓展层]

请为以下知识点设计一份五要素预习单：

学科：初中数学  年级：[年级]  课题：[课题]  课型：[概念课/命题课/例题课/复习课]

结构要求（每栏都要有）：
一、预习目标：2条，以学生为主体（"我能…"），用可观察可检测的行为动词
二、旧知回顾：2—3道前置知识复习题（与该课新知识直接相关）
三、新知初探：把核心概念/公式设计成填空、选择或简单归纳，难度低，
   保证学生看书10分钟内能完成
四、尝试练习：1—2道典型题（隐藏答案），留"完成情况自评"空格
五、疑问记录：留白，附引导语"写下一个你最想问的问题"

分层要求（按BKT概率调整）：
- 基础层：概念直接解释+判断题；例题填空式；总用时≤8分钟
- 提高层：自己说概念+试做例题+预测陷阱；总用时≤12分钟
- 拓展层：一句话概括+挑战变式题+质疑课本；总用时≤10分钟

预习完成标准：
1. 能说清"这节课讲什么"
2. 有一个问题要问
```

## 五、分层预习机制（V2.0保留 · BKT掌握概率）

| BKT概率 | 分层 | 学生特征 | 预习策略 |
|:-------:|:----:|:---------|:---------|
| <0.3 | 🟢 基础层 | 知识点薄弱，前置知识可能断层 | 多引导·重基础·少而精（概念解释+判断→跟着做填空→模仿题） |
| 0.3-0.7 | 🟡 提高层 | 有认识但不牢固 | 标准三步+试做例题+预测陷阱+思维路障 |
| >0.7 | 🔴 拓展层 | 基本已掌握 | 一句话概括+挑战题（找思路即可）+质疑课本 |

| 维度 | 基础层 🟢 | 提高层 🟡 | 拓展层 🔴 |
|:-----|:---------|:---------|:---------|
| 总用时 | ≤8分钟 | ≤12分钟 | ≤10分钟 |
| 目标 | 看懂 | 制造认知缺口 | 深度思考 |

## 六、"检查—反馈—二次备课"闭环机制（教师必做）

> 预习"布置了等于没布置"的根因：不检查、不批阅、不反馈。三环节缺一不可。

1. **检查**（防流于形式）：批阅预习单 / 课前小组互查 / 课堂提问
2. **反馈**（落实效果）：预习共性问题课堂集中讲解，个别问题单独辅导；批改后的预习单及时反馈给学生
3. **二次备课**（以学定教）：根据预习反馈调整教学设计——"学生能自己学会的，老师可以不讲"，课堂着重释疑与方法指导

## 七、课堂衔接与评价激励

- **课前3分钟展示**：思维导图、关键词卡片或口头汇报展示预习成果——检验效果+激发成就感
- **变式拓展**：课堂教学采用"变式、拓展例题"策略，避免照搬课本例题导致学生因"已预习"产生依赖心理
- **多问"为什么"**：引导学生真正理解，防止"先入为主"的浅层认知
- **小组合作**：组建学习小组、培养小组长协助督查预习，优生带差生；组内互助+小组竞争+表彰奖励
- **过程性评价**：关注"疑问质量、任务创意、进步幅度"，评选"预习之星""最佳疑问奖"，用"彩虹评价表"反馈进步

## 十、落地实施建议

1. **分阶段推进**：七年级是预习习惯养成的关键期，教师宜"扶"着教——方法示范、任务具体、逐课指导；八九年级逐步"放"——学生自主设计预习提纲、自主管理预习过程
2. **控制预习量**：任务宜精不宜多，日常预习15—20分钟，避免预习变相加负
3. **构建"预习—课堂—作业"闭环**：预习发现的问题课堂解决，课堂生成的疑问在作业与反馈中巩固
4. **定期评估**：问卷、访谈、成绩跟踪定期评估预习实施效果，及时调整任务设计与指导策略
5. **家校协同**：家长是"督促者而非代劳者"——提醒督促、营造环境、适当帮助鼓励，不代替思考、不代替完成；引导家长摒弃"预习=超前学习""预习=刷题"的错误观念

## 十一、预习完成标准（检验铁律）

学生能答上两句话：
1. **"这节课讲什么"**
2. **"有什么问题要问"**

答不上→预习无效，需回炉方法指导（不是加量，是教方法）。
