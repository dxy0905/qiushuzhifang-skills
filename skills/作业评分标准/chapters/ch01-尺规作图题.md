# 第1章 尺规作图题评分（纯作图题）

## 核心要点
福建中考尺规作图题以解答题形式呈现（2021第22题、2022第23题、2024第22题、2025第22题、2026第20题），
采分遵循"踩点给分"，按作图痕迹、步骤、工具、结果四维评分。

## 四维评分细则（满分100）

### ① 痕迹保留（40分）
- **满分条件**：文字含"以X为圆心/画弧/两弧交于/截取"等步骤性描述
- **痕迹特征识别**：
  - 角平分线/垂直平分线 → "两段弧交于一点"
  - 作等角 → "三次画弧"
  - 圆 → 以定点为圆心画整圆
- **扣分**：仅写结果无步骤 → 20分；明确"擦了/没画弧" → 0分

### ② 步骤规范（30分）
- **标准序列**：作射线 → 定圆心 → 画弧 → 取交点 → 连/作线
- **满分条件**：≥3 个步骤性描述且顺序正确
- **扣分**：1-2 步 → 15分；无步骤 → 0分
- **典型缺失**：垂直平分线只写"作中点"未写"画弧取交点"

### ③ 工具合规（15分）
- **满分条件**：无违规工具描述
- **违规即0分**：量角器、刻度尺、测量、直尺量

### ④ 结果正确（15分）
- **满分条件**：描述目标图形性质（平行/相切/垂直平分/等腰/正方形/菱形/对称/内接/外接/三点共线等）
- **基础分**：无性质描述 → 5分

## 真题示例

### 2026年第20题（8分，作图占3分）
矩形 ABCD 中尺规作图确定点 F（"F 是所求作的点"）。
- 评分：作图痕迹清晰 + 步骤完整 → 3分全得
- 常见失分：画弧痕迹擦除、未标明交点

### 2021年第22题（10分，作图部分约4分）
求作四边形 ABCD（CD∥AB 且 CD=2AB）。
- 关键步骤：作等长线段（转移弧）+ 作平行线（等角转移）
- 评分点：两段基本作图的痕迹都要保留

## 参考评分文本模板
```
【作图题参考评分 X/100（依据福建中考近5年尺规作图题评分标准）】
① 痕迹保留 X/40：...
② 步骤规范 X/30：...
③ 工具合规 X/15：...
④ 图形结果 X/15：...
（注：系统仅依据文字识别评分，痕迹是否清晰需结合原图人工确认，以阅卷为准）
```

## 关键提醒
- **不得**据此硬判 correct=true/false（系统看不到图，correct 保持 null 需复核）
- 评分仅出现在 error_analysis（错因分析）文本中，帮助学生理解得分点
