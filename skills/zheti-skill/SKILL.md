## 一、核心理念

```
刷题是走上坡路的错觉
拆题才是坐电梯的真相

窄门之所以窄，是因为它违背本能
——它慢、它费脑、它初期让人痛苦

但数学高手的秘密恰恰在于：
用战术上的深度，替代战略上的数量
```

**一句话总结：** 拆透一道压轴题，胜过无脑刷一页卷子。

## 二、拆题5法（解题者视角）

### 2.1 总览

```
┌─────────────────────────────────────────────┐
│               拆题5法                          │
├─────────────────────────────────────────────┤
│                                               │
│  ① 拆条件   → 给显性信息贴"数学资产"标签      │
│  ② 拆结论   → 逆向推导的GPS                    │
│  ③ 拆步骤   → 锁定"卡顿帧"                     │
│  ④ 拆题型   → 画知识树状图                      │
│  ⑤ 拆数据   → 极限推演                          │
│                                               │
└─────────────────────────────────────────────┘
```

### 2.2 拆条件（翻译数学资产）

**核心：** 别只看字面，把条件翻译成数学"资产"。

| 题干关键词 | 数学翻译（资产） |
|:-----------|:-----------------|
| "中点" | 中线、中位线、垂直平分线 |
| "恒成立" | 最值问题 |
| "角平分线" | 角相等、到角两边距离相等 |
| "垂直" | 90°、勾股定理、垂径定理 |
| "平行" | 同位角/内错角相等、同旁内角互补 |
| "圆" | 半径相等、圆周角、垂径定理 |
| "最值" | 二次函数顶点、不等式、将军饮马 |
| "恒过定点" | 含参方程的解与参数无关 |

**教学提示词：**
```
这道题给出了以下条件：[列出条件]
请你帮学生拆解每个条件——把"字面意思"翻译成"数学资产"。
每拆一个条件，问学生："这个条件告诉我们什么？能用什么定理/公式？"
```

### 2.3 拆结论（逆向推导GPS）

**核心：** 从终点倒推，把大目标拆成小台阶。

```
问自己：
"要得到这个答案，最后一步我必须算出什么？"
→ "那要算出这个，又需要先知道什么？"
→ 一直追到已知条件为止
```

**四步法：**
```
Step 1: 写出最终结论（要求什么？）
Step 2: 问"最后一步我需要知道什么？"
Step 3: 问"要得到这个，又需要知道什么？"
Step 4: 重复直到碰到已知条件
```

**教学提示词：**
```
学生不会做这道题。请你不要直接告诉他怎么做，
而是用"逆向推导法"引导他：

"要得到答案，最后一步你必须算出什么？"
"好，那要算出这个，你又需要知道什么？"
一直问到学生说"这个题目已经告诉我了"为止。
```

### 2.4 拆步骤（锁定卡顿帧）

**核心：** 找到学生停笔的那一步——那是真正的卡点。

```
对照答案时，别只看对错。
找到你停笔的那一步，问：
"这一步用到了哪个隐藏的定理？"
"我为什么没看见？"

精准打击卡点，比重做十道题都值钱。
```

**教学提示词：**
```
学生的解题过程：[粘贴学生过程]
正确答案：[粘贴标准答案]

请做三件事：
1. 找到学生停笔/写不下去的那一步（卡顿帧）
2. 分析这一步需要用到哪个知识点/定理
3. 追问学生一个引导性问题，帮ta自己跨过这个卡点
```

### 2.5 拆题型（知识树状图）

**核心：** 做完题后，强行归类——把"新题"变成"旧题的重组"。

```
这是"将军饮马"的变种？
还是"胡不归模型"的包装？
还是"手拉手模型"的变形？

一旦归类，你就把"新题"变成了"旧题的重组"。
```

**题型分类树（初中数学）：**
```
├── 几何
│   ├── 全等三角形（SAS/SSS/ASA/AAS/HL）
│   │   ├── 手拉手模型
│   │   ├── 一线三等角
│   │   └── 倍长中线
│   ├── 相似三角形
│   │   ├── A字型/8字型
│   │   └── 旋转相似
│   ├── 圆
│   │   ├── 垂径定理
│   │   ├── 切线证明
│   │   └── 圆幂定理
│   └── 解直角三角形
├── 代数
│   ├── 方程与不等式
│   ├── 函数（一次/二次/反比例）
│   └── 概率统计
└── 综合
    ├── 将军饮马（最短路径）
    ├── 胡不归/阿氏圆
    └── 存在性问题
```

**教学提示词：**
```
这是学生刚做完的一道题：[粘贴题目]
请你：
1. 帮学生判断这道题属于哪个题型（用上面的分类树）
2. 指出它跟同类题型的共同结构
3. 告诉学生："看到XXX关键词，就要想到XXX模型"
```

### 2.6 拆数据（极限推演）

**核心：** 把题目数字改了再算——理解数字在保护什么、陷阱藏在哪里。

```
把60°改成30°再算一遍。
把2改成3再算一遍。
把"整数"改成"分数"再算一遍。

算完你就懂了：
原来这个数字在保护什么？
陷阱又藏在哪里？
```

**教学提示词：**
```
原题：[粘贴题目]

请设计2个数据变式：
1. 改变一个关键数字（让学生看到数字变化对结果的影响）
2. 改变一个条件（让学生看到条件变化是否改变解题方法）

每道变式后追问："数字变了，解法变了吗？为什么？"
```

## 三、反向折题4层（命题者视角）

### 3.1 核心跃升

```
拆题是"观众视角"——看魔术怎么变
反向折题是"导演视角"——设计魔术怎么演

这是从"学霸"跨越到"命题者思维"的必经之路。

终极心法：
拆题是"把书读厚"
反向折题是"把书读薄"
```

### 3.2 第一层：条件与结论对折（逆向出题）

```
拿到一道做过的题：
把结论当成已知条件
把某个原条件改成问题

原题："已知A+B，求C"
反问："要得到A+B，题目必须给C和D吗？"

当你发现缺少某个条件题就不成立时，
你就摸到了这道题的"命门"。
```

**教学提示词：**
```
原题：[粘贴原题]

请你带学生做"条件与结论对折"练习：
1. 把原题的结论改成已知条件
2. 把原题的某一个条件改成问题
3. 新题目是什么？它成立吗？
4. 如果少给一个条件，题目还成立吗？——这就是"命门"
```

### 3.3 第二层：图形折叠（空间想象力降维）

```
几何题最适用：
把辅助线当作"折痕"
把图形的一部分镜像翻折过去

反向问：
"如果我把这个三角形折进另一个图形里，
哪些线段会重合？"

这种"物理折叠"能让你一眼看穿隐藏的等量关系，
比硬算快三倍。
```

**教学提示词：**
```
几何题：[粘贴几何题]

请你带学生在脑海中做"图形折叠"：
1. 找一条辅助线（或潜在的对称轴）
2. 想象把图形的一部分沿这条线翻折过去
3. 问：哪些线段/角会重合？说明什么等量关系？
4. 这个等量关系能推导出什么？
```

### 3.4 第三层：步骤折叠（看透评分点）

```
把标准答案的10个步骤，硬压缩成3个"思维组块"
（比如：①建系→②找等量→③求最值）

反向折：
"阅卷老师只看哪3个式子给分？"

屏蔽干扰步骤，直击核心算法。
```

**教学提示词：**
```
标准答案：[粘贴答案]

请你做"步骤折叠"：
1. 把10个步骤压缩成3个"思维组块"
2. 给每个组块起个名字（如"建系→找等量→求最值"）
3. 告诉学生："阅卷老师只看这3步给分"
4. 让学生用自己的话复述这3个组块
```

### 3.5 第四层：错因折叠（出题人陷阱还原）

```
把你的错误解法写出来，反向推导：
"如果出题人想让我掉进这个坑，
他应该怎么设置数据和关键词？"

当你把错解"折"回题干，
就等于给命题人当了一次助理。
下次看见类似字眼，条件反射就能躲开。
```

**教学提示词：**
```
学生的错误解法：[粘贴学生错误解法]
原题：[粘贴原题]

请你带学生做"错因折叠"：
1. 把错误解法写出来
2. 反向问：如果出题人想让学生犯这个错，
   应该怎么设计题目中的数字/条件？
3. 找到题干中"引诱"学生犯错的关键词
4. 下次看到这个关键词，应该警惕什么？
```

## 四、AI教师集成方案

### 4.1 在诊断分析后自动触发「折题引导」

当诊断完成且 per_question 中有错误题时，AI教师自动判断是否适合进行折题训练：

```
适合折题训练的信号：
- 错因类型 = "方法不会选" 或 "迁移不足" 或 "概念不清"
- 学生表现出愿意深入理解（对话中说了"为什么""怎么来的"）
- 题目属于中等偏上难度（有拆解价值）

不适用：
- 计算失误（只需要多练）
- 审题不仔细（需要养成习惯）
```

**Prompt注入：**
```
【折题引导模式】
检测到学生做错了这道题，请先带学生做"拆题"：
1. 拆条件：把每个条件翻译成数学资产
2. 拆结论：从后往前推导
3. 只到学生说出"哦，原来是这样"为止

如果学生已经做对了但想深入理解，请带学生做"反向折题"：
1. 条件与结论对折：把结论变成条件，设计新题
2. 图形折叠：找辅助线折痕
```

### 4.2 流式对话中的折题融合

在流式对话中，AI教师根据学生提问自动选择折题策略：

| 学生问题 | 触发策略 | AI教师回应示例 |
|:---------|:---------|:---------------|
| "这题怎么做？" | 拆条件+拆结论 | "先看看题目给了什么条件……好，那我们要做什么？从后往前推一下" |
| "我懂了" | 反向折题 | "真的懂了？那我们来换个玩法——把结论当成已知，你出个题？" |
| "为什么这么算？" | 拆步骤 | "你停在了哪一步？我们看看这一步用到了什么定理" |
| "又是这种题" | 拆题型 | "对！这就是将军饮马的变种。它们共同的套路是什么？" |
| "这个数字改一下还会吗？" | 拆数据 | "好问题！把60°改成30°，结果会变吗？试试看" |

### 4.3 专属「折题练习」生成

结合现有练习生成功能，增加"折题专项"：

```
{
  "mode": "zheti",
  "type": "拆条件|拆结论|拆步骤|拆题型|拆数据|反向折题",
  "source_question": "原题内容",
  "student_answer": "学生答案（可选）",
  "count": 3
}
```

## 五、教育部员工使用指南

### 5.1 各岗位使用定位

| 岗位 | 使用侧重 | 原因 |
|:-----|:---------|:-----|
| **严教（部长）** | 全面掌握5+4法，教研会议分享 | 统领教学方向，带领教研 |
| **麻老师** | 拆条件+拆结论为主 | 七年级学生刚接触几何，适合从"拆条件"入门 |
| **朱老师** | 拆题型+图形折叠为主 | 八年级几何证明深，适合题型归类和空间折叠 |
| **邓老师** | 拆步骤+拆数据+反向折题为主 | 九年级压轴题多，适合步骤折叠和命题者思维 |
| **张训** | 培训展示+课件设计 | 将折题法融入网络画板培训课程 |
| **AI教师** | 全策略按需触发 | 见§4集成方案 |

### 5.2 推荐练习频率

```
每日1道：拆题训练（1道压轴题，拆5法走一遍）
每周1次：反向折题（同1道题，4层各折一遍）
两周见效：看到新题，骨架就在眼前
```

### 5.3 班主任/教师给学生的话

```
"刚开始拆一道题可能花40分钟，
但一个月后，你看到新题的一瞬间，骨架就在眼前。

真正的捷径，就是那条看起来最绕、
实则最快的'解剖之路'。"
```
