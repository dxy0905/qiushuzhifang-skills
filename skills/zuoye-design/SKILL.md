## 一、核心设计理念

### 从"布置作业"到"设计作品"

作业不是简单地布置几道题。新课改理念下的作业，是：
- **课程目标的检测载体**
- **学生能力发展的脚手架**
- **教师教学反馈的数据源**

### 设计前的三个核心问题

| 问题 | 对应板块 | 追问要点 |
|:-----|:---------|:---------|
| 我为谁设计？ → | 学情分析 | 知识起点、能力差异、常见困难 |
| 我要达成什么目标？ → | 作业目标 | 与教学一致、可检测、有层次 |
| 学生需多久完成？ → | 时间控制 | 小学≤60min，初中≤90min |

## 二、八大板块结构

一份规范的作业设计必须包含以下8个板块：

```
┌──────────────────────────────────────┐
│ 板块1：课标要求   ← 具体条目，非抄文件   │
│ 板块2：教材分析   ← 位置+核心+编排特点   │
│ 板块3：学情分析   ← 用数据和具体描述说话  │
│ 板块4：作业目标   ← 三层结构+可检测      │
│ 板块5：设计意图   ← 每道题都有"为什么"   │
│ 板块6：作业内容   ← 基础+提高+拓展三层   │
│ 板块7：效果评价   ← 评价量规+三评机制    │
│ 板块8：参考答案   ← 含错因分析+讲评策略  │
└──────────────────────────────────────┘
```

### 板块1：课标要求

**规范：** 不是大段抄课标原文，而是写对应课标的具体条目。

必须包含：
- 课程标准版本（如《义务教育数学课程标准（2022年版）》）
- 所属学习领域（如"数与运算"、"图形与几何"）
- 具体条目（如"学生能结合具体情境认识分数"）
- 对本课/本作业的指导意义

**示例：**
> "本课对应《义务教育数学课程标准（2022年版）》第二学段'数与运算'领域。课标要求：学生能结合具体情境认识分数，能比较两个同分母分数的大小，能进行简单的分数加减运算。"

### 板块2：教材分析

**规范：** 不是抄目录，是做分析。

三要素：
1. **位置分析**：前联什么、后延什么
2. **核心内容**：知识结构
3. **编排特点**：情境和呈现方式

**示例：**
> "本课位于人教版三年级下册第七单元'分数的初步认识'第2课时。在此之前……在此之后……教材的编排特点是'动作—图形—符号'三级递进，本课作业设计应延续这一逻辑。"

### 板块3：学情分析

**规范：** 有数据、有具体描述。

必须包含：
- 知识起点与掌握程度（含数据）
- 能力差异分布
- 常见困难与典型错误
- 学习习惯特征
- 特殊学生情况

### 板块4：作业目标（三层结构）

| 层级 | 定位 | 达标标准 | 行为动词 |
|:-----|:-----|:---------|:---------|
| 基础目标 | 保底·确认"会不会" | 正确率≥90% | 计算、说出、写出 |
| 能力目标 | 应用·判断"懂不懂" | 思路完整 | 运用、分析、解决 |
| 拓展目标 | 迁移·检测创新力 | 有创新点 | 自编、设计、评价 |

**写作模板：**
```
基础目标：能[行为动词][学习内容]，[达标标准]。（对应课标[具体条目]）
能力目标：能在[具体情境]中[运用/分析][知识/方法]，[完成描述]。（对应课标[具体条目]）
拓展目标：能[创造/评价/自编][高阶任务]，[完成描述]。（对应课标[具体条目]）
```

### 板块5：设计意图

每道题必须写清楚：
- 这道题检测哪个目标
- 用了什么情境/方式
- 锻炼什么能力
- 难度定位和教学功能

### 板块6：作业内容（三层分层）

| 层级 | 功能 | 题型特征 | 预期用时 | 典型错因 |
|:-----|:-----|:---------|:---------|:---------|
| 基础巩固 | 走通基本流程 | 直接套用，步骤清楚 | ≈40% | 步骤不完整、计算错误 |
| 提高拓展 | 识别易错点 | 有变式、有干扰 | ≈35% | 审题不仔细、概念不清 |
| 实践探究 | 迁移到新情境 | 情境新、条件变 | ≈25% | 迁移不足、方法不会选 |

### 板块7：效果评价

**评价量规模板：**
| 维度 | ★合格 | ★★良好 | ★★★优秀 |
|:-----|:------|:--------|:---------|
| 目标1 | 能… | 能正确… | 能完整… |
| 目标2 | … | … | … |

**三评机制：**
1. **AI评** — 从多维度自动评改
2. **同桌互评** — 圈关键步骤、标逻辑漏洞
3. **学生自评** — 对照量规勾选星级

### 板块8：参考答案

| 题号 | 答案 | 出错错因 | 讲评策略 |
|:----:|:-----|:---------|:---------|
| 题1 | … | 步骤不完整 | 带全班走一遍完整流程 |
| 题2 | … | 审题不仔细 | 养成"先圈关键条件"的习惯 |

## 三、数智赋能规范

### AI工具选用表

| AI工具 | 教学功能 | 设计意图要点 | 离线方案要求 |
|:-------|:---------|:-------------|:-------------|
| AI数字人 | 情境创设 | 为什么用这个角色 | ✅ 必须 |
| AI检索 | 素材搜集 | 解决什么教学问题 | ✅ 必须 |
| AI评改 | 即时反馈 | 评改维度对应目标 | ✅ 必须 |
| AI错因分析 | 个性推送 | 推送策略对应错因 | ✅ 必须 |

### 离线方案模板
```
【AI工具】xxx
【设计意图】xxx
【离线方案】如AI不可用，改用[替代方式]
```

## 四、学教评一致性（CLTA）闭环

```
课标要求 → 作业目标 → 作业内容 → 评价量规
   ↓           ↓           ↓           ↓
 课标条目    三层目标    对应题目    评价维度
```

### 一致性自查清单

| 检查项 | 标准 | □ |
|:-------|:-----|:-:|
| 作业目标源于课标要求 | 每个目标能找到对应课标条目 | □ |
| 作业内容对应作业目标 | 每道题标注对应目标编号 | □ |
| 评价量规覆盖所有目标 | 每个目标都有评价维度 | □ |
| 作业时间在红线内 | 小学≤60min，初中≤90min | □ |
| 设计意图每道题都写 | 不能只列题 | □ |
| 参考答案含错因分析 | 不只给答案 | □ |
| 离线备用方案齐全 | AI环节都有 | □ |

## 五、错因5分类法融合

### 出题时标注

每道题标注预期错因类型：
- 概念不清 / 方法不会选 / 步骤不完整 / 审题不仔细 / 迁移不足

### 讲评时不按题号按错因

1. 收集全班错因分布
2. 从最多的错因开始讲
3. 每类错因：展示典型错例 → 追问引导 → 同类变式检测
4. 总结今日高频错因 + 一句话方法提醒

## 七、避坑清单

| 反模式 | 表现 | 纠正 |
|:-------|:-----|:------|
| 课标抄文件 | 大段抄原文 | 只写具体条目 |
| 教材抄目录 | "本课是XX单元第X课时" | 三要素分析 |
| 学情写套话 | "学生基础较好" | 用数据说话 |
| 目标写空话 | "巩固知识" | 行为动词+达标标准 |
| 三层=三层难度 | 挑战题=超级难题 | 挑战题=迁移应用题 |
| 意图凑字数 | "考查了学生…" | 写为什么这么做 |
| 评价缺位 | 没有量规 | 三维度量规 |
| 答案只给数 | 只写最终答案 | 错因分析+讲评策略 |
| AI做装饰 | 用AI没写原因 | 每个AI环节加设计意图 |
| 情境只做导入 | 只在开头用一次 | 情境贯穿全程 |
