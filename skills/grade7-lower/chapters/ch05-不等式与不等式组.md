# 第十一章 不等式与不等式组

## 核心内容
从等式到不等式，研究不等关系的数学表达。学习不等式的性质、一元一次不等式（组）的解法及数轴表示。

## 1. 不等式

### 概念
用不等号（$>$、$<$、$\geq$、$\leq$、$\neq$）连接而成的式子。

### 不等式的解
使不等式成立的未知数的值。**解集**是所有解的集合。

## 2. 不等式性质

| 性质 | 内容 |
|:----|:-----|
| 性质1 | $a>b \Rightarrow a\pm c > b\pm c$ |
| 性质2 | $a>b, c>0 \Rightarrow ac > bc$（正数乘除不变号） |
| 性质3 | $a>b, c<0 \Rightarrow ac < bc$（**负数乘除要变号！**） |
| 传递性 | $a>b, b>c \Rightarrow a>c$ |

## 3. 一元一次不等式解法
1. 去分母（注意负数变号）
2. 去括号
3. 移项
4. 合并同类项
5. 系数化为1（注意负数除要变号）
6. 解集在数轴上表示

## 4. 数轴表示
- $x > a$：从$a$向右，空心圆圈
- $x \geq a$：从$a$向右，实心圆点
- $x < a$：从$a$向左，空心圆圈
- $x \leq a$：从$a$向左，实心圆点

## 5. 一元一次不等式组

### 解集口诀
> **同大取大，同小取小，大小小大中间找，大大小小找不到**

| 类型 | 解集 |
|:-----|:-----|
| $x > a$ 且 $x > b$（$a<b$） | $x > b$（同大取大） |
| $x < a$ 且 $x < b$（$a<b$） | $x < a$（同小取小） |
| $x > a$ 且 $x < b$（$a<b$） | $a < x < b$（大小小大中间找） |
| $x < a$ 且 $x > b$（$a<b$） | 无解（大大小小找不到） |

## 6. 实际问题
"不少于/不高于/至少/至多/超过/不足"等关键词转化为不等号。
注意：实际问题的解要取整数（人数、数量等）

## 典型题型
- 不等式的性质运用（判断变形是否正确）
- 解一元一次不等式并把解集在数轴上表示
- 求不等式组的整数解
- 含参不等式（已知解集求参数）
- 方案选择问题（结合实际取整数）

## 易错点
- ⚠️ 乘除负数忘记变号（最常见错误）
- ⚠️ 去分母时每一项都要乘，漏乘常数项
- ⚠️ 数轴表示时实心/空心混淆
- ⚠️ "大大小小找不到"忘记考虑无解的情况
