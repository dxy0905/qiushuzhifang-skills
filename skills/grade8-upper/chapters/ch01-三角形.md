# 第十三章 三角形

## 核心内容

本章是几何学习的基石，从三角形的边、角关系出发，逐步深入到三角形的高、中线、角平分线等重要线段，进而研究三角形的内角和外角性质，最后扩展到多边形内角和的计算。

---

## 各节知识点

### 13.1 三角形的边

**定义：** 由不在同一直线上的三条线段首尾顺次相接所组成的图形叫做三角形。

**三角形的表示：** 顶点为 A、B、C 的三角形记作 $\triangle ABC$。

**三要素：**
- 顶点（3个）：A、B、C
- 边（3条）：$AB$、$BC$、$CA$
- 内角（3个）：$\angle A$、$\angle B$、$\angle C$

**分类：**
- 按边分：不等边三角形、等腰三角形（底≠腰）、等边三角形（底=腰）
- 按角分：锐角三角形、直角三角形、钝角三角形

**三边关系定理：**
- 三角形任意两边之和 **大于** 第三边：$a + b > c$，$a + c > b$，$b + c > a$
- 三角形任意两边之差 **小于** 第三边：$|a - b| < c$

> **应用：** 判断三条线段是否能构成三角形，只需验证最短两边之和 > 最长边。

**等腰三角形相关概念：**
- 腰：相等的两条边
- 底边：第三边
- 顶角：两腰所夹的角
- 底角：腰与底边的夹角

---

### 13.2 三角形的高、中线与角平分线

#### 高（altitude）

**定义：** 从三角形一个顶点向其对边所在直线画垂线，顶点和垂足之间的线段叫做三角形的高。

**性质：**
- 锐角三角形的三条高交于三角形内部（垂心）
- 直角三角形的三条高交于直角顶点
- 钝角三角形的三条高所在直线交于三角形外部

**面积公式：** $S = \dfrac{1}{2} \times \text{底} \times \text{高}$

#### 中线（median）

**定义：** 连接三角形一个顶点和对边中点的线段叫做三角形的中线。

**性质：**
- 三角形三条中线交于一点（重心）
- 重心将中线分成 2:1 的两段（顶点到重心 : 重心到对边中点）
- 中线将三角形面积平分

#### 角平分线（angle bisector）

**定义：** 三角形一个内角的平分线与对边相交，顶点和交点之间的线段叫做三角形的角平分线。

**性质：** 三角形三条角平分线交于一点（内心）

> **注意：** 三角形的角平分线是一条 **线段**，而角的平分线是一条 **射线**。

---

### 13.3 三角形的稳定性

**定理：** 三角形具有稳定性——三边长度确定后，三角形形状唯一确定。

**应用：** 房屋支架、桥梁结构、自行车架等。

**对比：** 四边形不具有稳定性（易变形），可通过加对角线转化为两个三角形来加固。

---

### 13.4 三角形的内角

**三角形内角和定理：**
$$\angle A + \angle B + \angle C = 180^\circ$$

**证明方法：** 过顶点作平行线，利用平行线性质将三个角拼成一个平角。

**推论：**
- 直角三角形两锐角互余：$\angle A + \angle B = 90^\circ$
- 三角形中最多有一个直角或钝角

---

### 13.5 三角形的外角

**定义：** 三角形的一边与另一边的延长线组成的角叫做三角形的外角。

**性质：**
1. 三角形的一个外角等于与它 **不相邻** 的两个内角之和
   $$\angle ACD = \angle A + \angle B$$
2. 三角形的一个外角大于任何一个与它不相邻的内角

> **易错点：** 外角不等于相邻内角的补角——外角 = 不相邻两内角和，相邻内角+外角=180°。

---

### 13.6 多边形及其内角和

#### 多边形

**定义：** 在同一平面内，由一些线段首尾顺次相接组成的封闭图形。

**相关概念：**
- 对角线：连接多边形不相邻两个顶点的线段
- 凸多边形：每个内角都小于 180° 的多边形
- 正多边形：各边相等、各角都相等的多边形

#### 多边形内角和定理

**n 边形内角和：**
$$S = (n - 2) \times 180^\circ$$

#### 多边形外角和定理

**任意 n 边形外角和：**
$$S_{\text{外}} = 360^\circ$$

**推论：** 正 n 边形的每个内角：$\dfrac{(n-2) \times 180^\circ}{n}$
正 n 边形的每个外角：$\dfrac{360^\circ}{n}$

#### 对角线数量

n 边形的对角线总数：$\dfrac{n(n-3)}{2}$

## 典型题型

### 题型一：三角形三边关系

**例1：** 以下列各组线段为边，能构成三角形的是（ ）
A. 1cm, 2cm, 4cm &emsp; B. 8cm, 6cm, 4cm &emsp; C. 12cm, 5cm, 6cm &emsp; D. 2cm, 3cm, 6cm

> **解：** B。验证最短两边之和 > 最长边：4+6=10>8 ✓

### 题型二：三角形内角和与外角性质

**例2：** 在 $\triangle ABC$ 中，$\angle A = 50^\circ$，$\angle B = 60^\circ$，则 $\angle C =$ ？
> **解：** $\angle C = 180^\circ - 50^\circ - 60^\circ = 70^\circ$

**例3：** 在 $\triangle ABC$ 中，$\angle A = 40^\circ$，$\angle B = 75^\circ$，则 $\angle ACD =$ ？（D 为 BC 延长线上一点）
> **解：** $\angle ACD = \angle A + \angle B = 40^\circ + 75^\circ = 115^\circ$

### 题型三：多边形内角和

**例4：** 一个多边形的内角和是 1080°，求边数。
> **解：** $(n-2) \times 180^\circ = 1080^\circ \Rightarrow n-2 = 6 \Rightarrow n = 8$

### 题型四：中线与面积

**例5：** 在 $\triangle ABC$ 中，AD 是 BC 边上的中线，$S_{\triangle ABC} = 12$，求 $S_{\triangle ABD}$。
> **解：** 中线将三角形面积平分，$S_{\triangle ABD} = 6$

## 易错点

1. **三边关系使用不当**：判断三角形时忘记用"最短两边之和 > 最长边"，而是随便取两边相加。

2. **外角理解错误**：把外角当成相邻内角的补角（这是对的但不够），忘记"外角 = 不相邻两内角和"这一核心性质。

3. **外角与相邻内角混淆**：认为外角等于所有两个内角之和（实际上是与它不相邻的两个内角之和）。

4. **多边形内角和公式漏减**：误记为 $n \times 180^\circ$，忘记减去 2。

5. **高线位置混淆**：钝角三角形的高可能在三角形外部，画高时遗漏。

6. **角平分线与角平分线混淆**：三角形的角平分线是线段（顶点到对边），角的平分线是射线。

7. **对角线计数错误**：n 边形的对角线总数容易记错为 $\dfrac{n(n-1)}{2}$ 或 $n(n-3)$。
