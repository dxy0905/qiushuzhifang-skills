# 第三十四章 随机事件的概率

## 核心内容
在七年级统计概率基础上深入学习概率的计算方法，学会用树状图、列表法分析等可能事件，了解频率估计概率的思想。

## 1. 概率回顾
- **必然事件**：概率=1
- **不可能事件**：概率=0
- **随机事件**：概率在0到1之间
- **概率公式**：$P(A)=\frac{事件A包含的结果数}{所有等可能结果总数}$

## 2. 用列举法求概率

### 直接列举法
适用于结果较少的情况，直接列出所有可能结果。

### 列表法
适用于两步试验，将两步的所有可能结果列成表格。

例：同时抛两枚硬币：
```
     正   反
正  (正,正) (正,反)
反  (反,正) (反,反)
```
P(一正一反)=2/4=1/2

### 树状图法
适用三步及以上试验，逐层分叉列举。

例：抛一枚硬币三次的树状图：
```
第一次   第二次   第三次   结果
        正→(正,正,正)
  正→   反→(正,正,反)
    反→正→(正,反,正)
        反→(正,反,反)
        正→(反,正,正)
  反→   反→(反,正,反)
    正→正→(反,反,正)
        反→(反,反,反)
```

## 3. 用频率估计概率
- 大量重复试验中，事件发生的频率稳定于概率
- 试验次数越多，频率越接近概率
- 适用：不能用列举法求概率的情况（如某事件"中奖率"）

## 4. 概率的应用
- 游戏公平性判断：比较各方获胜概率是否相等
- 方案择优：选择概率大的方案
- 保险精算、天气预报等实际应用

## 典型题型
- 用列表法或树状图求两步试验的概率
- 用树状图求三步试验的概率
- 游戏公平性判断与规则修改
- 频率估计概率的统计应用
- 概率与统计图表的综合题

## 易错点
- ⚠️ 树状图要保证不重不漏，每一层分支数要一致
- ⚠️ 列表法只适用于两步试验，三步及以上要用树状图
- ⚠️ 频率和概率不是一个概念（频率随试验变化，概率是常数）
- ⚠️ 判断游戏是否公平要比较所有参与方的概率
