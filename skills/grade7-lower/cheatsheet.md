# 七年级下册·速查表

## 平行线判定vs性质（判定由角推线，性质由线推角）

| 维度 | 判定 | 性质 |
|:----|:----|:----|
| 核心 | 由角→推线平行 | 由线平行→推角关系 |
| 同位角 | 相等→平行 | 平行→相等 |
| 内错角 | 相等→平行 | 平行→相等 |
| 同旁内角 | 互补→平行 | 平行→互补 |

## 实数运算规则

| 运算 | 平方根 | 立方根 |
|:----|:------|:------|
| 正数 | $\pm\sqrt{a}$（两个） | $\sqrt[3]{a}$（正） |
| 负数 | 不存在 | $\sqrt[3]{-a} = -\sqrt[3]{a}$（负） |
| 0 | 0 | 0 |

## 象限判定

| 条件 | 象限 |
|:-----|:----:|
| $x>0,y>0$ | 一 |
| $x<0,y>0$ | 二 |
| $x<0,y<0$ | 三 |
| $x>0,y<0$ | 四 |
| $x=0$或$y=0$ | 坐标轴上（不属于任何象限） |

## 解方程组方法选择

| 场景 | 推荐方法 |
|:-----|:---------|
| 某个未知数系数为1或-1 | 代入消元法 |
| 两个方程同一未知数系数相等/相反 | 加减消元法 |
| 两个方程系数较复杂 | 加减消元法（乘最小公倍数） |

## 不等式组解集口诀

> 同大取大 | 同小取小 | 大小小大中间找 | 大大小小找不到

## 统计图选择

| 目的 | 用哪种图 |
