## 关键设计原则

### 三层分离
```
_raw/       → 原始资料收件箱（不要求整洁，先存再说）
concepts/   → 概念页（核心知识节点）
skills/     → 方法页（解题技巧）
synthesis/  → 综合页（跨章节专题）
references/ → 参考页（公式总表/章节索引）
_meta/      → 规则层（taxonomy标签词表 + template模板 + dashboard仪表盘）
index.md    → 知识库地图
log.md      → 审计日志
```

### 概念页模板
```
frontmatter: title/grade/chapter/tags/prerequisites(类型化)/related(类型化)
## 概念与定义
## 核心公式与性质
## 前置知识      ← [[链接]]格式
## 常见题型      ← 三列表格（题型|识别信号|参见）
## 常用方法
## 易错点       ← ❌ 开头
## 关联页面
## 待核验项
```

### 方法页模板
```
frontmatter: title/category:skill/tags/applicable_to
## 适用信号      ← 什么题型用这个方法
## 基本步骤      ← 分步列出
## 常见题型与示例
## 易错陷阱      ← ⚠️ 标记
## 关联概念
```

### "慢启动、可验证、持续生长"
- 不从第1章到第29章全部生成→先跑通一个小范围闭环（如"有理数"）
- 验证模板和流程后，再一章一章扩展
- 每轮生成后做链接补全审计

### 学霸基本法实战结果
- 5轮Phase（数→式→方程→函数→几何→剩余章节）
- 42概念页 + 10方法页 = 52个知识文件
- ChromaDB simple模式（无需下载模型）
- 诊断引擎自动查知识库获取前置知识+易错点
