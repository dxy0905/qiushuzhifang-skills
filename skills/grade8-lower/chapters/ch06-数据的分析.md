# 第二十四章 数据的分析

## 核心内容
在七年级统计调查的基础上，深入学习用统计量分析数据特征——集中趋势（平均数/中位数/众数）和离散程度（方差）。

## 1. 平均数

### 算术平均数
$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$

### 加权平均数
$\bar{x} = \frac{w_1 x_1 + w_2 x_2 + \cdots + w_n x_n}{w_1 + w_2 + \cdots + w_n}$
权可以是频数、百分比、重要程度等。

## 2. 中位数
- 一组数据按大小顺序排列
- 奇数个：中间那个数
- 偶数个：中间两个数的平均数
- 优点：不受极端值影响

## 3. 众数
- 一组数据中出现次数最多的数
- 可能没有，也可能有多个
- 优点：反映数据的集中趋势

## 4. 方差（离散程度）
$s^2 = \frac{(x_1-\bar{x})^2 + (x_2-\bar{x})^2 + \cdots + (x_n-\bar{x})^2}{n}$

- 方差越大，数据波动越大，越不稳定
- 方差越小，数据越稳定，越集中
- 标准差：$s = \sqrt{s^2}$（单位与原始数据一致）

## 5. 统计量的选用

| 场景 | 用哪个 |
|:-----|:-------|
| 大致水平，无极端值 | 平均数 |
| 有极端值（如收入中位数） | 中位数 |
| 最常出现的情况 | 众数 |
| 数据是否稳定（如产品质量） | 方差 |

## 典型题型
- 计算一组数据的平均数/中位数/众数/方差
- 已知部分统计量反推数据
- 用方差判断数据稳定性
- 统计分析实际应用（成绩分析、质量检测、决策支持）
- 三种统计量的综合比较与选择

## 易错点
- ⚠️ 中位数要先排序再找，不能直接取中间值
- ⚠️ 加权平均数的权要分析清楚（频数权还是比例权）
- ⚠️ 方差公式中差是"数据减平均数"的平方
- ⚠️ 方差单位是原始数据单位的平方
