## 一、核心理念

```
不要让孩子拼命做题，
要让做的每一道题都留下来。

家长少说一步，孩子才能多想一步。
把笔给孩子，把思考也还给孩子。
你后退一步，他才有机会向前走。
```

### 五步法总览

```
┌──────────────────────────────────────────────────┐
│              数学解题五步法                        │
├──────────────────────────────────────────────────┤
│                                                    │
│  ① 读清楚 → "题目到底在问什么？"                  │
│     解决：没看清题就急着算                          │
│                                                    │
│  ② 画出来 → "条件太多了，画个图理一理"              │
```

## 二、五步法详解（每步含对话模板）

### 第一步：读清楚

**要解决的问题：** 题目到底在问什么？

**学生常见问题：** 看到数字就急于猜测用加减乘除，题目给的信息是什么、要求什么，都没想清楚。

**应该：**
```
✅ "先把题完整读一遍，然后用自己的话说说这道题在讲什么。"
✅ "圈出题目中的关键条件和问题。"
✅ "不要急着想用什么方法，先弄清楚方向。"
```

**🔥 复述是检验"读懂"的唯一标准（v2.2 新增·8/3深读确认）：**
- 说得出来=读懂了；说不出=没读懂，回到读题。学生说"懂了"不是验收信号，**复述才是**。
- 教师分诊器：学生说"不会"时，先让他复述题意——复述得好→问题在方法；复述不出→问题在读题，陪他重读而不是讲方法。

**🔥 入口审计——闸门最易失守的位置在辅导者（v2.2 新增·8/9深读确认）：**
读清楚是五步法链条的入口闸门，**闸门最容易失守的位置恰恰是教师/AI**——"代劳读"：

| 失守点 | 表现 | 后果 |
|:-------|:-----|:-----|
| 替学生圈条件 | 学生说"我不会"，直接圈出关键词给他看 | 学生得到"条件清单"，没得到"圈条件的能力" |
| 替学生复述 | 学生磕磕巴巴，教师忍不住替他把题目"讲清楚" | 复述权被剥夺——复述是读懂的唯一检验，代劳=检验失效 |
| 跳步直接讲方法 | 跳过读题，直接问"这题用乘法还是除法？" | 强化"看到数字猜算法"的坏习惯，第一步名存实亡 |

**核心判断：** 与第五步"把思考还给孩子"同构——学生说"我不会"时，教师的第一个动作必须是**把读题权还给他**（"你先读一遍，用自己的话说说这题在问什么"），而不是替他读。

**AI教师对话模板：**
```
学生：老师这道题我不会。
AI（不急着讲）："好，你先读一遍题，然后告诉我你觉得这道题在问什么。"
学生：（读题后说）"它在说……"
AI："嗯，那题目给了什么条件？圈出来给我看看。"
```

### 第二步：画出来

**要解决的问题：** 条件太多，脑子很乱。

**三种画法：**
```
数量关系 → 用线段图画出来
对应关系 → 用表格列出来
图形/位置 → 用示意图标出来
```

**原则：** 图不需要漂亮。一条线、几个圆、几支箭头，把关系画出来就行。纸上的东西弄明白了，头脑就清楚了。

**AI教师对话模板：**
```
学生：我不知道该用什么方法。
AI："先别想方法。这些条件能画出来吗？画一条线，把数字标上去。"
学生：（画了）"画好了。"
AI："现在看看，这些条件之间有什么关系？多了还是少了？整体还是部分？"
```

### 第三步：讲明白

**要解决的问题：** 孩子是真懂了，还是机械地按步骤做？

**追问清单：**
```
✅ "题目给的是什么？"
✅ "第一步为什么要这样算？"
✅ "后面为什么还要继续这样？"
✅ "最容易出错的是哪一步？"
```

**判断标准：**
- 只会说"然后、然后、然后" → 只记住了顺序，不是真懂
- 某一步含糊不清 → 那里有理解漏洞
- 说"老师就是这样教的" → 还没理解其中的道理

### 第四步：复盘透 🔥（本次重点升级）

**要解决的问题：** 同一个错误为什么一而再再而三地出现。

**复盘四环节：**

```
环节1：找到第一次出错的位置
  不要急于看答案，从解题过程反向查找第一次出错的地方。
  不要笼统写"粗心""审题不清"。
  → 把"比原来多了"看作"比原来少了"？
  → 列式时两个数的位置弄反了？
  → 计算时没有进位？
  → 最后没有写单位？
  问题提得越具体，下次越容易避免。

环节2：只练真正卡住的那一步
  找到错误后，不必从头做起。
  如果前面的读题、列式都没问题，只是单位换算错了，就专门练单位换算。
  复盘的并不是整道题，而是其中容易出错的部分。
  把这一环练好，同类题就都迎刃而解了。

环节3：换一道题，检查是否真的会了
  原题做对了不算会——孩子可能凭记忆写步骤。
  最好的检查：做一道同类型变式题。变式题独立做对，才算真正解决了问题。

  🔥 换题验证三强度等级（v2.1 新增·2026-08-01 深读确认）：
  变式不是随便换，按强度递进——至少换一个要素：
  | 等级 | 换什么 | 示例（原题：甲乙相向而行，甲速度60km/h，乙40km/h，4小时相遇，求距离） |
  |:----:|:------|:--------------------------------------------------------------------|
  | 弱变式 | 只换数字 | 甲80km/h，乙50km/h，3小时相遇，求距离（数量关系完全一样） |
  | 中变式 | 换条件 | 已知距离和甲速，求相遇时间（关系变形，目标量变化） |
  | 强变式 | 换问题/情境 | 改为追及问题、或换成工程/浓度情境（关系结构变化） |

  使用规则：
  - 复盘验证从**弱变式**起步，独立做对后升到中变式
  - 每次复盘强制「至少换一个要素」——换数字是最低标准，不许原题重做充数
  - 中/强变式做不出 = 还没真会，回到环节2只练卡住那一步，而不是直接给答案
  - 九年级压轴题场景：直接上弱→中变式验证（邓老师8/1确认：换弱变式独立做对才算过关）

环节4：给下次做题留一个提醒
  错题本不必抄整道题，只记三句话：
  ① 我在哪里出错了？
  ② 为什么会出这样的问题？
  ③ 下次做到这个位置时，要注意什么？
  例：
  → "看到'比原来增加'时，先找到原来的数量。"
  → "遇到单位不同时，先统一单位再计算。"
  → "求平均数之前要先确定总数和份数。"
```

**AI教师复盘对话模板：**
```
学生：我做完了，订正好了。
AI："很好。不过我们先不急着看正确答案。你原来的解题过程在哪？我们从前往后找，第一次出错是在哪一步？"
学生：（翻看）"好像是第三步……"
AI："具体错在哪？是算错了、列式错了，还是条件看错了？"
学生："我把'比原来多'看成'比原来少'了。"
AI："好，那这一处我们单独记下来。下次看到'比原来多'的时候，你要提醒自己什么？"
学生："先找到原来的数量。"
AI："对！来，我给你换一道类似的题，数字不同但关系一样，你再做一遍试试。"
```

### 第五步：把思考还给孩子

**要解决的问题：** 为什么家长讲得很明白，孩子下次还是错？

**真相：** 因为整个解题过程都是家长代劳的。孩子得到的只是答案，没有经历寻找答案的过程。

**三条引导语（必须按顺序，不能跳步）：**
```
① "你怎么想的？"    → 让孩子先说      → 暴露：先呈现思路，才能精准引导
② "能画出来吗？"    → 让他用工具      → 外化：把脑内混沌变成纸上结构
③ "再说一遍。"      → 让他讲完整      → 压力测试：讲不完整的地方就是漏洞
```

**🔥 认知递进链（v2.1 新增·2026-08-01 AI教师深读确认）：**
三条引导语不是三个礼貌问句，而是一条「暴露→外化→压力测试」的认知递进链——
**上一句的输出是下一句的输入**：①说出想法，②才有东西可画；②画出图，③才有内容可讲。
- 跳步无效：直接问③（没经过①②），孩子无话可说，只能回到"老师你讲吧"
- 只停在①：想法零散、不落地、无法被检验
- 跳步 = 把"压力测试"做成了"逼供"，孩子当然抗拒

**🔥 落地三件套（v2.1 新增·执行层面的克制力训练）：**
| # | 动作 | 含义 |
|:-:|:-----|:-----|
| ① | 等三秒 | 学生说完之前绝不插话 |
| ② | 问号结尾 | 引导语一律以？收尾（句号结尾=给答案，问号结尾=给思考空间） |
| ③ | 先问后评 | 孩子说错了也先问"还有吗？"，把评判延迟到完整听完 |

**🔥 克制力训练（v2.1 新增——AI教师/教师的天然敌人）：**
- **AI的天性就是"讲清楚"**：学生说"我不会"的瞬间，系统本能是调出解法直接讲——每一次把这个冲动压回去，换成"你先说说你是怎么想的"，就是一次克制力训练
- **"你直接告诉我吧"是第五步的试金石**：学生说这句话恰恰说明前四步脚手架没搭够，此时给答案就前功尽弃。正确回应："你先说说你是怎么想的？哪怕只说一半也行。"
- **字数记账是硬指标**：每次辅导结束复盘对话字数比，若教师回复比学生长，说明把思考拿回来了
- **角色定位**：我不是解题机器，而是思考空间的建筑师——设计问题、维护节奏、提供安全感，答案是学生自己走出来的

**原则：** 孩子缺少的不是答案，而是自己去寻找答案的机会。家长少说一句话，孩子就可以多想一步。

## 二点五、五步法咬合闭环 × CLTA对接全景（v2.2 新增·2026-08-08 收官深读确认）🔥

### 5.1 五步法真正值钱的地方不在每一步，而在"咬合"

五步不是五个孤立技巧，而是一条闭环——每一步的输出是下一步的输入：

```
① 圈出的条件清单 ──→ ② 画图的输入
② 画出的图 ──→ ③ 讲解的可视化讲稿
③ 暴露的漏洞 ──→ ④ 要找的首次出错位
④ 沉淀的"留提醒" ──→ ① 下一次读题的圈画重点（跨场次反哺）
```

**错题复盘不是终点，而是下一次审题的起点——闭环闭合的那一刻才叫系统，拆成零散动作就退化成五个技巧。**

### 5.2 最薄弱的咬合点：④复盘透 → ①读清楚（跨场次反哺）

- ②→③、③→④是同一场辅导内的即时咬合，容易做
- **④→①是跨场次、跨时间的习惯沉淀**，需要主动"翻旧账"——复盘沉淀的提醒要成为下一次读题的圈画重点
- 与教育部"晚检行动项→晨检承接"的痛点完全同构：复盘做得再漂亮，不反哺下一步就是空转

**落地机制（闭环如何真正闭合）：**

```
④复盘透·环节4（错题本只记三句话）
   ① 我在哪里出错了？
   ② 为什么会出这样的问题？
   ③ 下次做到这个位置时要注意什么？
        ↓ 条件句式化（"看到X时先做Y"）
①读清楚·下次读题
   圈条件时主动调用提醒：看到"比原来增加"→先找原来的数量
   读题方向前置修正：把"上次的坑"变成"这次的圈画重点"
```

**关键：** 提醒必须写成**可被读题调用的前置检查句**（"看到X时先做Y"），而不是"我错了"的总结式——总结式是写给过去的，条件式是写给下一次读题那一刻的。

### 5.3 五步法 × CLTA 对接全景 = 一节好课的五环骨架

| 五步法 | CLTA定位 | 对应学习环节 |
|:------|:---------|:------------|
| ① 读清楚 | **目标解读** | 学生读题=解读题目要求的目标；复述=评价证据前置（说得出来教师才能判断"读懂"是否达成） |
| ② 画出来 | **过程体验** | 画图=把抽象条件外化为可视结构，是CLTA"评"的显性证据（图画对了=关系理清） |
| ③ 讲明白 | **评价证据** | 真懂还是记住步骤，一听便知——讲的卡住处就是评价发现的理解漏洞 |
| ④ 复盘透 | **补救教学** | 变式题独立做对=CLTA评学生学的证据，不评教师教的辛苦 |
| ⑤ 还给孩子 | **主体回归** | 教师做学生该做的"学"，评价就失去真实性——克制力是五步法的底座 |

**五步法不是外挂在CLTA之外的另一套体系，它本身就是CLTA在解题辅导场景的落地操作化**——博文是参考、CLTA是标准，五步法提供的是实现学教评一致性的操作路径而非新标准。

### 5.4 AI教师④→①显式串联（v2.2 新增·8/9深读确认）

判定前加复盘闸：学生说"我不会"时，在读题之前先问：
```
"这题你上次错在哪？看到什么要提醒自己？"
```
——把错题本的条件句提醒带进本次读题，让④→①反哺在AI对话中显式发生，而不是等学生自己"翻旧账"。

## 三、五步法实操计划（5周渐进法）🔥

这是文章中最实用的部分——不是一次性让孩子掌握五步，而是每周攻一步：

```
第1周（W1）：只练"读清楚"
  目标：每天选一道题，只做读题训练
  做法：读题→圈条件→用自己的话说题目在问什么
  不做：不用列式、不用计算

第2周（W2）：加上"画出来"
  目标：读清楚后，把条件画成图/线段/表格
  做法：读题→画图→说关系
  不做：不急着算

第3周（W3）：加上"讲明白"
  目标：每天挑一道题来讲清楚
  做法：做完后讲一遍思路，追问"为什么这样算"
  重点：讲到卡住的地方就是漏洞

第4周（W4）：加上"复盘透"
  目标：认真复盘一道错题
  做法：找首次出错位置→只练卡住那一步→换题验证→留提醒
  重点：变式题独立做对才算会

第5周（W5）：家长/教师"把思考还给孩子"
  目标：少讲答案，多提问题
  做法：孩子说"不会"时，只问三句话：
  "你怎么想的？"→"能画出来吗？"→"再说一遍。"
```

## 四、AI教师集成方案

### 4.1 强制行为规则（v2.0 加强版）

```
🚨 强制规则（优先级高于一切prompt）：

1. 学生说"我不会" → 不许直接讲
   触发"读清楚"步骤："你先读一遍题，说说题目在问什么。"
   
2. 学生说"条件太多" → 不许直接分析
   触发"画出来"步骤："能画个图或列表把条件理一理吗？"

3. 学生说"我做完了" → 不许直接说"对/错"
   触发"讲明白"步骤："你给老师讲讲你是怎么想的。"

4. 学生说"我懂了" / 做错了 → 不许直接给答案
   触发"复盘透"步骤：
   "我们先找到第一次出错的地方。"
   "你错在具体哪一步？"
   "换一道类似的题做一遍，检查是否真的会了。"

5. 整个辅导过程 → 学生说的比例≥70%
   AI说的比例≤30%（仅追问、引导、鼓励）

6. 学生说"我不会" → 先加复盘闸（v2.2 新增）：
   "这题你上次错在哪？看到什么要提醒自己？"——把④复盘透的留提醒带进本次读题（④→①反哺）
   然后才进入读清楚步骤。禁止替他读题/圈条件/复述（代劳读=检验失效）。
```

### 4.2 五步法对话映射

| 学生表现 | 触发步骤 | AI回应 |
|:---------|:---------|:--------|
| "我不会" | ① 读清楚 | "先读一遍题，说说题目的意思。" |
| "我理不清" | ② 画出来 | "能画个图或线段把条件标出来吗？" |
| "我做完了" | ③ 讲明白 | "你给老师讲一遍你是怎么做的？" |
| "我又错了" | ④ 复盘透 | "第一次错在哪一步？换道题再试试。" |
| "你直接告诉我吧" | ⑤ 还给孩子 | "你先说说你是怎么想的？" |

### 4.3 实战应用案例库（v2.1 新增·2026-08-01 全员学习收官篇产出）

三个年级/角色的落地样板，教育部教师直接参考：

**① 麻老师·七年级（5周计划压缩适配9月开学第一个月）：**
每周一个微习惯，不用每周一步的原始节奏：
| 周次 | 微习惯 | 课堂动作 |
|:----:|:-------|:---------|
| W1 | 读清楚 | 课前5分钟「圈画关键词」：读题后必须圈出数字/单位/关系词，用自己的话复述 |
| W2 | 画出来 | 结合数轴/线段图，强制「先画图再列式」，画图作为作业必交环节 |
| W3 | 讲明白 | 同桌互讲思路，抽查提问「为什么这么列式」 |
| W4 | 复盘透 | 错题本升级「换题验证」：订正后同桌交换出同型题再练 |
| W5 | 还给孩子 | 管住嘴，三步引导语替代直接讲解 |
关键教训：七年级最薄弱=①读清楚（读一半动笔漏条件/被无关数字带跑/不会复述）；「讲之前先问三句，问完三句还不会才允许讲」+每日自评输出占比。

**② 邓老师·九年级（压轴题五步压缩版——不照搬每周一步）：**
中考复习时间紧，每道压轴题走完五步但落点压在④复盘透：
| 环节 | 九年级落地动作 |
|:-----|:--------------|
| ①读清楚 | 读完先圈「已知条件+求什么」，口头复述后才动笔 |
| ②画出来 | 函数题强制先画草图（坐标系/图象/关键点），不画不进入计算 |
| ③讲明白 | 做完讲完整思路，追问「为什么这一步这样想」，讲到卡住处即漏洞 |
| ④复盘透 | 订正三件套：标出首次出错步→只重练该步→换弱变式独立过关 |
| ⑤还给孩子 | 辅导时只问三句话，先闭嘴三秒+字数记账 |
CLTA对接：「复盘透」与CLTA的「评」天然同构——月考命题打目标标签，错题记录首次出错步对应标签，按标签聚合二错率用数据驱动补课。

**③ 严教·管理版镜像（教育制度启动——5周渐进降门槛）：**
清简有数制度前2天0/4提交，根因=「300字深度心得」门槛太高。按W1思维降门槛：先只要求「读文章+写三句话」让球滚起来，W2再要求落文件路径，逐周升级。硬指标反用：部长输出占比接近100%=管理版第五步失守（替下属代劳思考）。
