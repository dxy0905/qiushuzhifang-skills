# 八年级上册·术语表

- **三角形** — 三条线段首尾顺次相接组成的图形（ch01）
- **三角形的高** — 从顶点向对边作垂线，顶点到垂足的线段（ch01）
- **三角形的中线** — 顶点到对边中点的线段（ch01）
- **三角形的角平分线** — 内角平分线与对边相交的线段（ch01）
- **外角** — 三角形的一边与另一边的延长线组成的角（ch01）
- **全等三角形** — 能够完全重合的两个三角形（ch02）
- **对应顶点/边/角** — 全等时重合的顶点/边/角（ch02）
- **轴对称** — 沿一条直线折叠能够完全重合（ch03）
- **垂直平分线** — 垂直且平分一条线段的直线（ch03）
- **等腰三角形** — 两条边相等的三角形（ch03）
- **等边三角形** — 三边都相等的三角形（ch03）
- **整式的乘法** — 单项式/多项式之间的乘法运算（ch04）
- **幂的乘方** — $(a^m)^n = a^{mn}$（ch04）
- **积的乘方** — $(ab)^n = a^n b^n$（ch04）
- **因式分解** — 把一个多项式化成几个整式的积的形式（ch05）
- **提公因式法** — 提取多项式各项的公因式（ch05）
- **公式法** — 利用平方差/完全平方公式分解（ch05）
- **分式** — 分母含字母的有理式（ch06）
- **最简公分母** — 各分母系数的最小公倍数与所有因式的最高次幂的积（ch06）
- **增根** — 分式方程去分母后整式方程的解使公分母为0（ch06）
