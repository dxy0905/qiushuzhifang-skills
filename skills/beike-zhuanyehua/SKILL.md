## 二、CLTA核心理念体系（四条根本原则）

### 基石公式
```
学教评一致性 = 清晰的学习目标 ×（教学活动 + 评估任务）
三者围绕同一目标形成闭环
```

### 四大基本理念

#### （一）学习中心（最本质理念）
> **一句话概括：为学设计教**
> **班俊英（特级教师）感言：** "有了CLTA，我才真正从'教教材'走向了'用教材教'"

**四维度落地操作点：**
1. **课标分析** — 追问"学生学什么、学到什么程度"，而非"我要讲什么"
2. **学情分析** — 量化前测，精准把握学习起点
3. **目标叙写** — 目标反映预期学习结果，清晰具体、可观可测
4. **教学活动** — 依据加涅"九大教学事件"设计学习外部条件

#### （二）基于标准（两重含义）
| 维度 | 含义 | 操作 |
|:----:|:----:|:----:|
| 内容上 | 基于课程标准 | 摘录+分解课标要求 |
| 技术上 | 基于专业标准 | 遵循CLTA教学设计专业标准 |

> **金瑶老师实操感悟：** "课标摘录要'抄'得有法——不能盲目摘录过多，一课一标，精准靶向"

#### （三）目标达成
> 目标是课堂教学的灵魂，没有清晰的目标就没有有效的教学

**学习目标达成度公式：**
```
达成度 = 学习终点 − 学习起点（进步度）× 有意义程度
```

#### （四）学教评一致
> "三围绕"秘诀：围绕课标定目标 → 围绕目标定评估 → 围绕评估定活动

## 三、与传统备课的范式对比

| 维度 | 传统备课 | CLTA专业化备课 |
|:----:|:--------:|:--------------:|
| **起点** | "今天要讲什么" | "学生今天要学会什么" |
| **目标** | "理解…掌握…"（笼统含糊） | "能说出…能写出…"（可观可测） |
| **课标** | 搁置或遗忘 | 摘录+分解，作为设计依据 |
| **学情** | 凭经验猜测 | 前测量化，数据驱动 |
| **活动** | 教师中心，讲授为主 | 学习中心，任务驱动 |
| **评估** | 课后考试（滞后独立） | 嵌入教学（形成性评估） |
| **一致性** | 目标-活动-评估常脱节 | 三者严密对应 |
| **备课工作量** | 目标占10%，活动占90% | **目标占70%**，活动占30% |

> ⚡ **关键认知（张爱军）：** "写完学习目标，整个教案的工作就完成了70%"
> ⚡ **刘培斌老师感言：** "CLTA教学设计的最大感受是——把教案当成论文去创作"

## 四、CLTA六步操作法（完整流程）

```
课标分析 → 教材分析 → 学情分析 → 目标叙写 → 评估任务 → 教学活动
```

### 第一步：课标分析（定方向）

**操作框架：**
| 步骤 | 操作 | 核心追问 |
|:----:|:----:|:--------:|
| 课标摘录 | 从课标中忠实摘录本课时要求，注明课标版本 | 课标原文怎么说？ |
| 课标分解 | 说清"学什么、学到什么程度、怎么学" | 行为动词是什么？核心名词是什么？ |

**课标摘录三原则（从案例中提炼）：**
1. **精准** — 一课一标，不盲目多摘（金瑶教训：初始摘了4条→被批过多）
2. **标注版本** — 如"《义务教育语文课程标准（2022年版）》"
3. **引用原文** — 忠实摘录，不随意更改

**课标分解"层层剥笋法"（三层追问）：**
```
① 学生学什么？→ 拆解核心名词
② 学到什么程度？→ 行为动词具体化（内隐→外显）
③ 怎么学？→ 条件+方法明确化
```

**动词转换技术（案例实战经验）：**
| 笼统内隐词 | 替换为可测外显动词 | 案例出处 |
|:----------:|:-----------------:|:--------:|
| 理解 | 说出、解释、举例 | 通用 |
| 掌握 | 写出、画出、求出 | 通用 |
| 体会 | **说清感受、读出情感** | 张艳红《慈母情深》 |
| 品味 | 描述、评析、阐述 | 班俊英《紫藤萝瀑布》 |
| 感悟 | 归纳、总结、陈述 | 金瑶《姓氏歌》 |
| 领会 | 区分、辨别、说明 | 通用 |

> 💡 **张艳红老师实操经验：** "体会一词，通过查阅资料+结合以读代讲经验，转化为'说清感受、读出情感'"

### 第二步：教材分析（析素材）

**专业标准（两问）：**
1. 教材是如何**体现课标要求**的？
2. 教材是如何**遵循学生认知规律**的？

**推荐句式（张爱军博士培训语录）：**
```
为了达成课标要求中的______，遵循学生学习______的规律，
教材安排了______环节（提供了______材料）。
```

> 💡 **金瑶老师总结：** "教材分析要'解'得有度——牵一发而动全身，是确立学习目标的重要依据"

### 第三步：学情分析（找起点）

**操作流程：**
```
① 设计前测题（3-5道，5分钟）
② 实施前测 → 统计正确率
③ 找出薄弱点 → 制定教学对策
```

### 第四步：目标叙写（ABCD法）

**公式：**
```
在 [条件C] 下，[学生A] 能 [行为动词B] [内容]，[程度D]
```

**目标叙写"三步走"技术（张爱军《备课专业化》核心方法）：**
1. **动词替换** — 将内隐心理动词替换为外显行为动词
2. **条件补充** — 补充行为发生的条件（工具、情境、方式）
3. **程度量化** — 明确行为达到的程度标准

**高质量目标示例（班俊英《紫藤萝瀑布》）：**
```
课标原句："理清文章思路"
分解后目标："借助思维导图，学生能清晰梳理出作者由
'赏花—忆花—悟花'的情感变化线索"
```
> ✅ 张爱军评语：**"可以作为样板给老师们学习"**

**SMART验证：**
- S（具体）— 描述的是学生的学习结果吗？
- M（可测）— 能通过具体行为判断达成吗？
- A（可达成）— 一节课内能完成吗？
- R（相关）— 与课标一致吗？
- T（时限）— 有时间限制吗？

**目标叙写八大常见问题：**
1. ❌ 目标主语用教师（"使学生…"） → 应改为学生主体
2. ❌ 行为动词笼统（"理解""掌握"） → 应改为可观可测动词
3. ❌ 缺乏条件（无"在什么条件下"） → 应补充条件
4. ❌ 程度模糊（无"做到什么程度"） → 应明确程度标准
5. ❌ 目标过多（一节课5-7条） → 限制在3条以内
6. ❌ 硬套三维目标（含过程与方法） → 过程方法以条件形式出现
7. ❌ 目标假大空 → 改为可观察的行为
8. ❌ 目标之外列重难点 → CLTA模板不另设重难点

### 第五步：评估任务设计（证明学会了）

**原则：每个目标→对应一个评估任务**

**操作两步法：**
1. **设计评估任务** — 把学习目标"任务化"（目标→任务转化）
2. **设计评估要点** — 把评估任务分解嵌入教学活动各环节

> 💡 **天净沙·秋思案例启示：** 评估要点设计是初学者的薄弱环节，需要反复打磨

### 第六步：教学活动设计（落实目标）

**专业标准：** 紧扣评估任务，遵循学习的心理发生过程

**加涅九大教学事件（CLTA技术框架）：**
| 序号 | 教学事件 | 操作要领 |
|:----:|:--------:|:---------|
| 1 | 引起注意 | 指向目标+情境性 |
| 2 | 呈现目标 | 时机适当+学生清楚 |
| 3 | 激活旧知 | 与前测呼应+关联新知 |
| 4 | 呈现刺激 | 提供学习材料+指向目标 |
| 5 | 提供学习指导 | 分步骤引导+示范+提示 |
| 6 | 引出行为 | 让所有学生参与+展示 |
| 7 | 提供反馈 | 及时+具体+纠正性 |
| 8 | 评估行为 | 评估要点分解到位 |
| 9 | 促进保持与迁移 | 变式练习+总结归纳 |

**时间分配铁律：**
```
学生活动时间 ≥ 25分钟（占55%以上）
教师讲授时间 ≤ 15分钟（占30%左右）
评估时间 ≈ 5分钟（占15%）
```

## 七、语文学科CLTA专题（新增模块 · 案例实战提炼）

> **张爱军语：** "目标设计，语文是重灾区"

### 7.1 语文学科CLTA的特殊难点
| 难点 | 表现 | 对策 |
|:----:|:----:|:-----|
| 课标摘录 | 语文课标体例多样，难以定位 | 查找对应学段目标与内容 |
| 动词转换 | "体会""感悟""品味"难以外显 | 替换为"说清""描述""评析""读出" |
| 教材分析 | 容易写成"课文内容分析" | 用两问法：体现课标+遵循规律 |
| 教学活动 | 容易写成"初读—再读—感悟"模式 | 以目标为纲，不脱离评估任务 |

### 7.2 语文学科动词转换对照表（案例实战总结）
| 原文目标（笼统） | CLTA改写后（可观可测） | 案例来源 |
|:-----------------|:----------------------|:---------|
| 品味文章语言 | 能描述词语的丰富性和生动形象的语言表达效果及运用之妙 | 《紫藤萝瀑布》 |
| 体会作者情感 | 能借助语调、节奏的变化，基本读出作者的喜悦与歌颂之情 | 《春》 |
| 理清文章思路 | 能借助思维导图清晰梳理出"赏花—忆花—悟花"的情感线索 | 《紫藤萝瀑布》 |
| 感受诗歌意境 | 能结合具体意象，说出"枯藤老树昏鸦"营造的苍凉氛围 | 《天净沙·秋思》 |
| 理解词人情感 | 能结合创作背景，阐述"俱往矣"中蕴含的历史豪情 | 《沁园春·雪》 |

### 7.3 特别提醒：一致性是生命线
> **张爱军评班俊英案：** "传统教学活动设计往往拘泥于活动本身，忘记了一致性。如果与目标不一致，活动再精彩，有意义吗？"
