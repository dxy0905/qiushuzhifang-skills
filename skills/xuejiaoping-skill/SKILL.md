# 学教评一致性教学设计 · CLTA 结构化技能库

> 提取结构，而非摘要。每一条都是可直接操作的专业知识。

---

## 一、核心框架

### Framework 1: CLTA 一致性公式

```
学教评一致性 = 清晰的学习目标 ×（教学活动 + 评估任务）
三者围绕同一目标形成闭环
```

**使用场景：** 检验任意一节课的教学设计是否专业
**判定标准：** 目标—评估—活动三者缺一或不对应 → 不合格

### Framework 2: 六步操作法

```
课标分析 → 教材分析 → 学情分析 → 目标叙写 → 评估任务 → 教学活动
```

**使用场景：** 撰写CLTA教案的标准流程
**顺序强制：** 前三步是"分析段"（发现问题），后三步是"设计段"（解决问题）

### Framework 3: ABCD 目标叙写法

```
在 [条件C] 下，[学生A] 能 [行为动词B] [内容D]，达到 [程度D]
```

**参数说明：**
| 字母 | 含义 | 常见错误 |
|:----:|:-----|:---------|
| A (Audience) | 学生 | 写成"使学生…" |
| B (Behavior) | 可测行为动词 | 用"理解"等内隐词 |
| C (Condition) | 行为发生条件 | 缺失条件 |
| D (Degree) | 达标程度 | 程度模糊 |

### Framework 4: 加涅九大教学事件

| 事件 | 操作要领 | 对应目标 |
|:----:|:---------|:--------:|
| 引起注意 | 指向目标+情境 | 导入 |
| 呈现目标 | 时机适当+学生清楚 | 导入 |
| 激活旧知 | 与前测呼应 | 唤醒 |
| 呈现刺激 | 提供材料+指向目标 | 新授 |
| 提供学习指导 | 分步骤引导 | 新授 |
| 引出行为 | 全员参与+展示 | 练习 |
| 提供反馈 | 及时+具体 | 练习 |
| 评估行为 | 评估要点分解 | 检测 |
| 促进保持与迁移 | 变式+总结 | 结课 |

### Framework 5: 时间分配铁律

```
学生活动 ≥ 25分钟（55%）
教师讲授 ≤ 15分钟（30%）
评估时间 ≈ 5分钟（15%）
总计 45分钟/课时
```

## 二、可执行原则

### Principle 1: 学习中心
> 为学设计教，不是为教找学

**操作标准：**
- 课标分析追问"学生学什么"而非"我要讲什么"
- 目标反映预期学习结果，而非教学内容
- 教学活动以学生活动为主体

### Principle 2: 基于标准
> 课标是备课的法律依据

**两重含义：**
- 内容上：基于课程标准（摘录+分解）
- 技术上：基于CLTA专业标准（遵循六步法）

### Principle 3: 目标达成
> 目标是课堂教学的灵魂

**达成度公式：**
```
达成度 = 学习终点 − 学习起点 × 有意义程度
```

### Principle 4: 学教评一致
> 三围绕

**执行口诀：**
```
围绕课标定目标 → 围绕目标定评估 → 围绕评估定活动
```

## 三、关键技术

### Technique 1: 课标分解·层层剥笋法

| 层次 | 追问 | 产出 |
|:----:|:-----|:-----|
| 学什么 | 核心名词是什么？ | 知识点清单 |
| 学到什么程度 | 行为动词是什么？ | 动词替换 |
| 怎么学 | 条件+方法是什么？ | 学习路径 |

### Technique 2: 动词替换技术

| 内隐词 | 外显动词 | 
|:------:|:--------:|
| 理解 | 说出、解释、举例 |
| 掌握 | 写出、画出、求出 |
| 体会 | 说清感受、读出情感 |
| 品味 | 描述、评析、阐述 |
| 感悟 | 归纳、总结、陈述 |
| 领会 | 区分、辨别、说明 |

### Technique 3: 教材分析·两问法

```
① 教材如何体现课标要求？
② 教材如何遵循学生认知规律？
```

**推荐句式：**
> 为了达成课标要求中的______，遵循学生学习______的规律，教材安排了______环节。

### Technique 4: 目标叙写·三步走

```
步骤1: 动词替换（内隐→外显）
步骤2: 条件补充（工具、情境、方式）
步骤3: 程度量化（明确达标标准）
```

### Technique 5: 评估任务·两步法

```
步骤1: 设计评估任务（目标→任务转化）
步骤2: 设计评估要点（分解嵌入教学活动）
```

## 四、反模式（Anti-patterns）

### Anti-pattern 1: 目标笼统
**表现：** 使用"理解""掌握"等内隐动词
**后果：** 无法判断学生是否达成
**对策：** 替换为可观可测的外显动词

### Anti-pattern 2: 课标摘录过多
**表现：** 一节课摘录4-5条课标
**后果：** 目标分散，无法聚焦
**对策：** 一课一标，精准摘录2-3条

### Anti-pattern 3: 以讲代学
**表现：** 教师全程演示讲授，学生被动观看
**后果：** 学生没有实际操作和思考的机会
**对策：** 学生活动时间≥25分钟

### Anti-pattern 4: 评估缺位
**表现：** 下课才问"听懂了吗"，无形成性评估
**后果：** 教师不知道学生学到了什么程度
**对策：** 每个目标对应一个即时评估任务

### Anti-pattern 5: 脱离课标
**表现：** 凭经验讲题，不写课标摘录
**后果：** 教学内容偏离标准要求
**对策：** 每节课前必须写课标摘录+分解

### Anti-pattern 6: 主语错误
**表现：** 目标以"使学生…""让学生…"开头
**后果：** 目标反映的是教师行为而非学生行为
**对策：** 始终以学生主语开头

### Anti-pattern 7: 目标过多
**表现：** 一节课写5-7条目标
**后果：** 每条都无法深入达成
**对策：** 限制在3条以内

### Anti-pattern 8: 活动与目标脱节
**表现：** 教学活动精彩但与目标不相关
**后果：** 活动没有意义
**对策：** 每一步活动都问"这个活动对应哪个目标？"

## 七、速查表（Cheatsheet）

### 标准课时结构

| 环节 | 时间 | 教师 | 学生 | 评估 |
|:----|:----:|:-----|:-----|:----:|
| 导入 | 5min | 引起注意+呈现目标 | 明确学习方向 | 观察 |
| 探究 | 20min | 指导+反馈 | 操作+讨论+展示 | 过程评价 |
| 巩固 | 10min | 提供变式练习 | 独立完成+互批 | 练习批改 |
| 归纳 | 10min | 总结+促进迁移 | 回顾+整理笔记 | 提问检测 |

### CLTA评价标准
- 学习目标（50分）：基于课标、可观可测、ABCD规范
- 评估任务（20分）：紧扣目标、层次清晰
- 教学活动（20分）：指向目标、科学合理
- 一致性（10分）：目标—评估—活动内在一致
- 总分 ≥75 = 专业水准 / ≥90 = 出版级别
