# 第十九章 二次根式

## 一、核心内容

本章学习二次根式的概念、性质和运算，是后续学习一元二次方程、勾股定理和三角函数的重要基础。重点包括二次根式的化简、乘除运算和加减运算。

---

## 二、各节知识点

### 19.1 二次根式

**1. 二次根式的概念**

形如 $\sqrt{a}(a \ge 0)$ 的式子叫做二次根式，其中 $\sqrt{\ \ }$ 叫做二次根号，$a$ 叫做被开方数。

> **注意**：被开方数 $a$ 必须满足 $a \ge 0$，否则二次根式无意义。

**2. 二次根式的性质**

性质1：$(\sqrt{a})^2 = a \ (a \ge 0)$

性质2：$\sqrt{a^2} = |a| = \begin{cases} a & (a \ge 0) \\ -a & (a < 0) \end{cases}$

性质3：$\sqrt{ab} = \sqrt{a} \cdot \sqrt{b} \ (a \ge 0, b \ge 0)$

性质4：$\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}} \ (a \ge 0, b > 0)$

### 19.2 二次根式的乘除

**1. 乘法法则**

$$\sqrt{a} \cdot \sqrt{b} = \sqrt{ab} \ (a \ge 0, b \ge 0)$$

**2. 除法法则**

$$\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}} \ (a \ge 0, b > 0)$$

**3. 最简二次根式**

满足以下两个条件的二次根式叫做最简二次根式：
- 被开方数不含分母（即被开方数是整数或整式）
- 被开方数中不含能开得尽方的因数或因式

**4. 分母有理化**

把分母中的根号化去，叫做分母有理化。

$$\frac{1}{\sqrt{a}} = \frac{\sqrt{a}}{a} \ (a > 0)$$

$$\frac{1}{\sqrt{a} \pm \sqrt{b}} = \frac{\sqrt{a} \mp \sqrt{b}}{a - b} \ (a \ne b)$$

### 19.3 二次根式的加减

**1. 同类二次根式**

几个二次根式化成最简二次根式后，如果被开方数相同，这几个二次根式叫做同类二次根式。

**2. 加减法则**

二次根式加减时，先将二次根式化为最简二次根式，再合并同类二次根式。

$$\sqrt{a} + \sqrt{b} \text{ 不一定等于 } \sqrt{a+b} \ (\text{不能直接合并！})$$

**3. 混合运算**

二次根式的混合运算顺序与实数运算相同：先乘除，后加减，有括号先算括号里面的。运算律同样适用。

## 三、典型题型

### 题型1：二次根式有意义的条件

**例1**：求使 $\sqrt{x-3}$ 有意义的 $x$ 的取值范围。

**解**：由 $x-3 \ge 0$，得 $x \ge 3$。

**例2**：求使 $\sqrt{2x+1} + \frac{1}{\sqrt{x-2}}$ 有意义的 $x$ 的取值范围。

**解**：$\begin{cases} 2x+1 \ge 0 \\ x-2 > 0 \end{cases}$，解得 $x > 2$。

### 题型2：二次根式的化简

**例3**：化简 $\sqrt{12} + \sqrt{27} - \sqrt{48}$。

**解**：$\sqrt{12} = 2\sqrt{3}$，$\sqrt{27} = 3\sqrt{3}$，$\sqrt{48} = 4\sqrt{3}$

原式 $= 2\sqrt{3} + 3\sqrt{3} - 4\sqrt{3} = \sqrt{3}$

**例4**：化简 $\sqrt{(-5)^2}$。

**解**：$\sqrt{(-5)^2} = |-5| = 5$

### 题型3：分母有理化

**例5**：化简 $\frac{2}{\sqrt{3}}$。

**解**：$\frac{2}{\sqrt{3}} = \frac{2\sqrt{3}}{3}$

**例6**：化简 $\frac{1}{\sqrt{5} - 2}$。

**解**：$\frac{1}{\sqrt{5} - 2} = \frac{\sqrt{5} + 2}{(\sqrt{5} - 2)(\sqrt{5} + 2)} = \frac{\sqrt{5} + 2}{5 - 4} = \sqrt{5} + 2$

### 题型4：二次根式的混合运算

**例7**：计算 $(\sqrt{3} + \sqrt{2})(\sqrt{3} - \sqrt{2})$。

**解**：原式 $= (\sqrt{3})^2 - (\sqrt{2})^2 = 3 - 2 = 1$

**例8**：计算 $(\sqrt{5} + 2)^2$。

**解**：原式 $= (\sqrt{5})^2 + 2 \cdot \sqrt{5} \cdot 2 + 2^2 = 5 + 4\sqrt{5} + 4 = 9 + 4\sqrt{5}$

## 四、易错点

### ❌ 易错1：忽略被开方数的非负性

**错**：$\sqrt{-4}$ 有意义。
**对**：$\sqrt{-4}$ 无意义，因为 $-4 < 0$。

**错**：$\sqrt{x-1}$ 在 $x \ge 1$ 时有意义，$\frac{1}{\sqrt{x-1}}$ 一样。
**对**：$\frac{1}{\sqrt{x-1}}$ 的分母不能为零，所以 $x-1 > 0$，即 $x > 1$。

### ❌ 易错2：$\sqrt{a^2}$ 误写成 $a$

**错**：$\sqrt{(-3)^2} = -3$
**对**：$\sqrt{(-3)^2} = |-3| = 3$

### ❌ 易错3：二次根式加减时错误合并

**错**：$\sqrt{2} + \sqrt{3} = \sqrt{5}$
**对**：$\sqrt{2}$ 和 $\sqrt{3}$ 不是同类二次根式，不能合并

**错**：$\sqrt{2} + \sqrt{2} = \sqrt{4} = 2$
**对**：$\sqrt{2} + \sqrt{2} = 2\sqrt{2}$

### ❌ 易错4：分母有理化时符号错误

**错**：$\frac{1}{\sqrt{3} - \sqrt{2}} = \frac{\sqrt{3} - \sqrt{2}}{(\sqrt{3} - \sqrt{2})^2}$
**对**：$\frac{1}{\sqrt{3} - \sqrt{2}} = \frac{\sqrt{3} + \sqrt{2}}{(\sqrt{3} - \sqrt{2})(\sqrt{3} + \sqrt{2})} = \sqrt{3} + \sqrt{2}$

### ❌ 易错5：合并时忘记化到最简

**错**：$\sqrt{8} + \sqrt{2} = \sqrt{8+2} = \sqrt{10}$
**对**：$\sqrt{8} + \sqrt{2} = 2\sqrt{2} + \sqrt{2} = 3\sqrt{2}$
