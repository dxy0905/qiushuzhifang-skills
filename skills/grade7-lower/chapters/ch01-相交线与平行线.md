# 第七章 相交线与平行线

## 核心内容
本章研究平面内两条直线的位置关系——相交和平行。从相交线引入对顶角、邻补角、垂线、三线八角等概念，进而研究平行线的判定与性质，最后学习平移变换。

## 1. 相交线

### 对顶角与邻补角
两条直线相交形成4个角：
- **邻补角**：有一条公共边，另一边互为反向延长线，和为180°
- **对顶角**：两边分别互为反向延长线，**对顶角相等**

### 垂线
- 两条直线相交成直角 → 互相垂直
- **垂线段最短**（垂线段：垂足到直线外一点的线段）
- **点到直线的距离**：垂线段的长度

## 2. 三线八角
两条直线被第三条直线所截：
- **同位角（F型）**：位置相同的一对角
- **内错角（Z型）**：两条直线内部、截线两侧交替
- **同旁内角（U型）**：两条直线内部、截线同侧

## 3. 平行线判定
1. **同位角相等** → 两直线平行
2. **内错角相等** → 两直线平行
3. **同旁内角互补** → 两直线平行
4. **平行公理推论**：如果$a\parallel c$且$b\parallel c$，则$a\parallel b$
5. **垂直于同一直线**：如果$a\perp c$且$b\perp c$，则$a\parallel b$

## 4. 平行线性质
1. 两直线平行 → **同位角相等**
2. 两直线平行 → **内错角相等**
3. 两直线平行 → **同旁内角互补**

## 5. 命题、定理与证明
- **命题**：判断一件事情的语句（题设+结论）
- **真命题/假命题**
- **定理**：经过推理证实的真命题
- **证明**：推理的过程

## 6. 平移
- 形状、大小不变，位置改变
- 对应点连线平行（或在同一直线）且相等
- 对应线段平行（或在同一直线）且相等
- 对应角相等

## 典型题型
- 利用对顶角相等和邻补角互补求角度
- 三线八角识别（F/Z/U型）
- 平行线判定与性质综合（中档题）
- 拐点问题：过拐点作平行线（折线问题）
- 平移作图与坐标变化

## 易错点
- ⚠️ 对顶角和邻补角概念混淆（对顶角相等但不等同于邻补角互补）
- ⚠️ 平行线性质和判定混用（判定→_由角推线_，性质→_由线推角_）
- ⚠️ 垂线段最短易与两点之间线段最短混淆
