# 实践案例：勾股定理的逆定理·作业设计

本案例展示了zuoye-design四柱框架 + CLTA + 错因5分类法的完整融合。

## 四柱融合方式

| 四柱 | 在案例中的体现 |
|:-----|:--------------|
| **柱1：数智赋能** | AI错因诊断 + AI变式推送 + AI数字人 + AI对话追问，每个工具都有明确的设计意图 |
| **柱2：三层分层** | 基础巩固(保底)→提高拓展(纠偏)→实践探究(迁移)，每层标注4个错因分析要素 |
| **柱3：真实情境** | 校园花坛(身边)→古代沙田(数学史)→家庭测量(动手实践)，情境贯穿全程 |
| **柱4：评价量规** | 三维度★级标准 + AI评+互评+自评三评机制 |

## 错因5分类法融合方式

| 层级 | 对应错因 | 题目设计策略 |
|:-----|:---------|:-------------|
| 基础题 | 步骤不完整 | 表格填空，引导按步骤填写 |
| 提高题 | 审题不仔细 + 方法不会选 | 设易错陷阱，追问设计按错因分类 |
| 挑战题 | 迁移不足 | 换情境（古代沙田、家庭测量），追问引导学生发现相同结构 |
