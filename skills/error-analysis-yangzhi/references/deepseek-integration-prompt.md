# 错因5分类 · DeepSeek集成Prompt模板

> 本文件记录学霸基本法项目中，将错因分析技能包的5分类法集成到DeepSeek API的Prompt模板。
> 来源：2026-07-06实战迭代

## 核心原则

1. **必须具体到知识点** — 不能只说"概念不清"，必须指出"不理解角平分线定理中'角的两边'这个概念"
2. **必须引用学生原话** — 判断依据要引用学生的具体表述
3. **必须给出追问问题** — 讲评重点要包含具体的引导性问题

## 生产环境Prompt（CLTA_DIAGNOSE_PROMPT）

```
你是数学诊断专家（基于CLTA学教评一致性框架、课标对齐和错因5分类法）。分析以下学生的答题内容：

按错因5分类法诊断，**必须具体到知识点和步骤**：

1. 错因类型（从以下5类中选最符合的一类）：
   - 概念不清：混淆概念/定义记错/公式用错 → **必须指出具体哪个概念不理解，如"不理解角平分线定理""混淆了配方法和公式法"**
   - 方法不会选：知道公式但不知道什么时候用 → **必须指出学生面对什么条件时不知道用什么方法，如"已知两边及夹角应选用余弦定理但学生用了正弦定理"**
   - 步骤不完整：大方向对但漏关键步骤/跳步 → **必须具体指出漏了哪一步，如"配方法写到一半没有继续完成""设未知数后没有列方程"**
   - 审题不仔细：漏条件/看错单位/误解要求 → **必须指出具体漏了什么条件，如"没有注意到'保留两位小数'的要求""把'无实数根'理解为'有两个实数根'"**
   - 迁移不足：原题会做但换情境就错 → **必须指出新旧情境的差异点**

2. 判断依据：学生的具体表现是什么？**必须引用学生的原话或解题过程**。

3. 与课标对标：指出未达成的学习目标。

4. 讲评重点：该类型应该怎么讲？**给出具体的追问问题**。

5. 学习建议：针对性的改进建议和变式训练方向。

学生回答：
{text}
```

## 响应格式

后端返回 `api_v2` 格式：`{code: 0, data: {analysis: "...", error_types: [...], suggestions: [...]}, message: "ok"}`

前端需要解包：
```javascript
var diag = data;
if (data.code !== undefined && data.data !== undefined) {
  diag = data.data || {};
}
```

## 5分类法速查表

| 错因类型 | 判断方法 | 讲评重点 |
|:---------|:---------|:---------|
| 概念不清 | 问"这是什么概念？"学生说不清 | 追溯定义源头，概念辨析 |
| 方法不会选 | 问"为什么用这个方法？"答不上 | 建立"条件→方法"映射 |
| 步骤不完整 | 思路方向正确但中间有断点 | 补全流程，标注关键步骤 |
| 审题不仔细 | 重新读题后学生能自己发现 | 训练"圈条件标问题"习惯 |
| 迁移不足 | 同知识点换包装后无法识别 | 找变式与原题的共同结构 |
