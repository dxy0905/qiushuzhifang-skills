# DeepSeek诊断Prompt演化记录（2026-07-06）

## 用户铁律（邱董）

诊断必须**具体到知识点**，不能笼统归因：
- ❌ "概念不清" → ✅ "混淆了'角平分线上的点到角两边的距离相等'中的'角'与'边'的概念"
- ❌ "步骤不完整" → ✅ "配方法写到x²+6x+5=0→(x+3)²=4，漏了移项那一步"
- ❌ "审题不仔细" → ✅ "没注意到x的取值范围是'整数'，用了小数"

## Prompt演化历程

### v1（初始版）
通用诊断，无结构化输出 → 结果太泛

### v2（具体化）
要求写出具体概念名 + 判断依据 + 讲评重点 + 追问问题 + 变式练习

### v3（生产版，当前在用）
```python
CLTA_DIAGNOSE_PROMPT = """你是初中数学诊断专家（基于CLTA学教评一致性框架、课标对齐和错因5分类法）。
分析以下学生的答题内容。

**诊断要求：必须写出完整的因果关系，不能只贴标签。**

按以下格式逐项输出：

1. 错因类型（从以下5类中选最符合的一类）：
   - 概念不清 → **必须写出：具体是哪个概念/哪条定理/哪个公式没理解 + 正确理解应该是什么**
   - 方法不会选 → **必须写出：面对什么条件时不知用什么方法 + 正确的方法选择逻辑**
   - 步骤不完整 → **必须写出：漏了哪一步/跳了哪一步 + 正确的完整步骤**
   - 审题不仔细 → **必须写出：具体漏了什么条件/看错了什么 + 正确理解题意的方法**
   - 迁移不足 → **必须写出：新旧情境的差异点 + 如何识别共同结构**

2. 判断依据：**必须引用学生的原话或解题过程**，说明为什么归为此类

3. 与课标对标：指出未达成的具体学习目标

4. 正确理解（重点）：用学生能听懂的语言，**一步步解释正确的思考过程**

5. 追问引导（重要）：设计1-2个引导性问题，**帮助学生自己发现错误**
   如"二次根式的被开方数有什么要求？""点M到BA和BC的距离相等，BA和BC是同一个角的两边吗？"

6. 变式练习：设计1道同类变式题（同一知识点，换情境或换数字）

学生答题内容：
{text}"""
```

## 关键经验

1. **DeepSeek API Key在.env中可能被安全工具截断**
   用Python读取原始字节确认实际key值，不要相信显示输出中的掩码

2. **错因5分类法的优先级**
   根据2026-07-06多轮测试，最常见的错因排序：概念不清 > 步骤不完整 > 审题不仔细 > 方法不会选 > 迁移不足

3. **api_v2响应格式解包**
   DeepSeek API通过FastAPI包装后返回`{code:0, data:{...}, message:"ok"}`格式，前端必须解包：
   ```javascript
   var diag = data;
   if (data.code !== undefined && data.data !== undefined) {
     diag = data.data || {};
   }
   ```
