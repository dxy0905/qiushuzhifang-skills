# 术语表（Glossary）

## 第二十五章 · 一元二次方程

| 术语 | 英文 | 定义 |
|------|------|------|
| 一元二次方程 | quadratic equation in one variable | 只含一个未知数，且未知数的最高次数是 $2$ 的整式方程 |
| 一般形式 | standard form | $ax^2 + bx + c = 0 \quad (a \neq 0)$ |
| 二次项 | quadratic term | $ax^2$，$a$ 为二次项系数 |
| 一次项 | linear term | $bx$，$b$ 为一次项系数 |
| 常数项 | constant term | $c$ |
| 根（解） | root / solution | 使方程左右两边相等的未知数的值 |
| 判别式 | discriminant | $\Delta = b^2 - 4ac$，判断根的情况 |
| 配方法 | completing the square | 通过配成完全平方来解一元二次方程的方法 |
| 公式法 | quadratic formula | 用求根公式 $x = \dfrac{-b \pm \sqrt{b^2-4ac}}{2a}$ 求解 |
| 因式分解法 | factoring | 将方程化为 $A \cdot B = 0$ 形式求解 |
| 韦达定理 | Vieta's formulas | 根与系数的关系：$x_1+x_2=-\dfrac{b}{a}$，$x_1x_2=\dfrac{c}{a}$ |

## 第二十六章 · 二次函数

| 术语 | 英文 | 定义 |
|------|------|------|
| 二次函数 | quadratic function | 形如 $y = ax^2 + bx + c \quad (a \neq 0)$ 的函数 |
| 抛物线 | parabola | 二次函数的图像 |
| 顶点 | vertex | 抛物线的最高点或最低点 |
| 对称轴 | axis of symmetry | 经过顶点且平行于 $y$ 轴的直线 |
| 开口方向 | opening direction | $a > 0$ 开口向上，$a < 0$ 开口向下 |
| 顶点式 | vertex form | $y = a(x-h)^2 + k$ |
| 交点式 | intercept form | $y = a(x-x_1)(x-x_2)$ |
| 待定系数法 | method of undetermined coefficients | 设函数表达式，代入已知点求系数 |

## 第二十七章 · 反比例函数

| 术语 | 英文 | 定义 |
|------|------|------|
| 反比例函数 | inverse proportional function | 形如 $y = \dfrac{k}{x} \quad (k \neq 0)$ 的函数 |
| 双曲线 | hyperbola | 反比例函数的图像 |
| 分支 | branch | 双曲线的每一支 |
| 比例系数 | proportionality constant | $k$，决定图像所在象限 |
| k 的几何意义 | geometric meaning of k | $|k|$ 等于双曲线上任一点向坐标轴作垂线所得矩形面积 |

## 第二十八章 · 旋转

| 术语 | 英文 | 定义 |
|------|------|------|
| 旋转 | rotation | 图形绕某点沿某方向转动一定角度 |
| 旋转中心 | center of rotation | 旋转过程中固定不动的点 |
| 旋转角 | angle of rotation | 图形转动的角度 |
| 旋转方向 | direction of rotation | 顺时针或逆时针 |
| 对应点 | corresponding point | 旋转前后互相重合的点 |
| 中心对称 | central symmetry | 旋转 $180^\circ$ 后与另一图形完全重合 |
| 对称中心 | center of symmetry | 中心对称中的旋转中心 |
| 中心对称图形 | centrally symmetric figure | 绕某点旋转 $180^\circ$ 后与自身重合的图形 |

## 第二十九章 · 圆

| 术语 | 英文 | 定义 |
|------|------|------|
| 圆 | circle | 到定点距离等于定长的所有点组成的图形 |
| 圆心 | center | 定点 $O$ |
| 半径 | radius | 定长 $r$ |
| 弦 | chord | 连接圆上任意两点的线段 |
| 直径 | diameter | 经过圆心的弦（最长的弦） |
| 弧 | arc | 圆上任意两点间的部分 |
| 半圆 | semicircle | 直径的两个端点分成的两条弧 |
| 优弧 | major arc | 大于半圆的弧 |
| 劣弧 | minor arc | 小于半圆的弧 |
| 圆心角 | central angle | 顶点在圆心的角 |
| 圆周角 | inscribed angle | 顶点在圆上、两边与圆相交的角 |
| 垂径定理 | perpendicular chord theorem | 垂直于弦的直径平分弦及其所对的两条弧 |
| 圆周角定理 | inscribed angle theorem | 同弧所对圆周角等于圆心角的一半 |

## 第三十章 · 直线与圆的位置关系

| 术语 | 英文 | 定义 |
|------|------|------|
| 相离 | separation | 直线与圆没有公共点 |
| 相切 | tangency | 直线与圆只有一个公共点 |
| 相交 | intersection | 直线与圆有两个公共点 |
| 切线 | tangent line | 与圆相切的直线 |
| 切点 | point of tangency | 切线与圆的公共点 |
| 割线 | secant line | 与圆相交于两点的直线 |
| 切线长 | tangent length | 圆外一点到切点之间的线段长度 |
| 切线长定理 | tangent length theorem | 从圆外一点引两条切线长相等 |
| 正多边形 | regular polygon | 各边相等、各角也相等的多边形 |
| 外接圆 | circumscribed circle | 经过多边形各个顶点的圆 |
| 内切圆 | inscribed circle | 与多边形各边都相切的圆 |
| 内心 | incenter | 三角形内切圆的圆心（角平分线交点） |
| 外心 | circumcenter | 三角形外接圆的圆心（中垂线交点） |
