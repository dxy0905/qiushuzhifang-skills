# 🚀 考前速记卡片

## 第二十五章 · 一元二次方程

```
一般形式:         ax² + bx + c = 0  (a≠0)
判别式:           Δ = b² - 4ac
  Δ>0  ⇔ 两个不等实根
  Δ=0  ⇔ 两个相等实根
  Δ<0  ⇔ 无实数根

求根公式:         x = [-b ± √(b²-4ac)] / (2a)

韦达定理:         x₁+x₂ = -b/a,  x₁x₂ = c/a

三种解法:         配方法 → 公式法 → 因式分解法
```

## 第二十六章 · 二次函数

```
一般式:           y = ax² + bx + c  (a≠0)
顶点式:           y = a(x-h)² + k
顶点坐标:         (-b/(2a), (4ac-b²)/(4a))
对称轴:           x = -b/(2a)
开口:             a>0 向上, a<0 向下
交点式:           y = a(x-x₁)(x-x₂)

a| 越大 → 开口越小（图像越瘦）
a| 越小 → 开口越大（图像越胖）

最值:             顶点纵坐标
```

## 第二十七章 · 反比例函数

```
一般形式:         y = k/x  (k≠0)
图像:             双曲线（两支）
k>0:              一、三象限，y随x增大而减小
k<0:              二、四象限，y随x增大而增大
|k| 几何意义:     矩形面积 = |k|
```

## 第二十八章 · 旋转

```
旋转三要素:       旋转中心 + 旋转方向 + 旋转角
旋转性质:         对应点到旋转中心距离相等
                 对应点与旋转中心连线所成角 = 旋转角
                 旋转前≌旋转后

中心对称:         旋转180°
中心对称图形:     绕对称中心旋转180°后与自身重合
```

## 第二十九章 · 圆

```
垂径定理:         直径⊥弦 → 直径平分弦及其所对的两条弧
                 弦的中垂线 → 经过圆心

圆周角定理:       同弧所对圆周角 = 圆心角的一半
                 直径所对圆周角 = 90°

点与圆位置关系:   d<r ⇔ 圆内, d=r ⇔ 圆上, d>r ⇔ 圆外
```

## 第三十章 · 直线与圆的位置关系

```
直线与圆:         d<r ⇔ 相交(2个交点)
                 d=r ⇔ 相切(1个切点)
                 d>r ⇔ 相离(0个交点)

切线性质:         切线⊥过切点的半径
切线判定:         过半径外端且⊥该半径 → 是切线
切线长定理:       从圆外一点引两条切线长相等
                 该点与圆心连线平分两切线夹角

弧长:             l = nπr / 180
扇形面积:         S = nπr² / 360 = lr/2
```
