# 八年级下册·术语表

- **二次根式** — 形如$\sqrt{a}(a\geq0)$的式子（ch01）
- **最简二次根式** — 被开方数不含分母、不含能开得尽方的因数（ch01）
- **同类二次根式** — 化简后被开方数相同的二次根式（ch01）
- **勾股定理** — $a^2+b^2=c^2$（直角三角形两直角边平方和=斜边平方）（ch02）
- **勾股定理逆定理** — 若$a^2+b^2=c^2$，则三角形是直角三角形（ch02）
- **勾股数** — 满足$a^2+b^2=c^2$的正整数（ch02）
- **平行四边形** — 两组对边分别平行的四边形（ch03）
- **矩形** — 有一个角是直角的平行四边形（ch03）
- **菱形** — 有一组邻边相等的平行四边形（ch03）
- **正方形** — 邻边相等且有一个角是直角的平行四边形（ch03）
- **三角形中位线** — 连接两边中点的线段，平行于第三边且等于第三边一半（ch03）
- **变量** — 数值发生变化的量（ch04）
- **常量** — 数值始终不变的量（ch04）
- **函数** — 对于x的每一个确定值，y都有唯一确定的值与之对应（ch04）
- **正比例函数** — $y=kx(k\neq0)$（ch04）
- **一次函数** — $y=kx+b(k\neq0)$（ch05）
- **待定系数法** — 通过已知点坐标确定函数解析式的方法（ch05）
- **平均数** — 一组数据的总和除以个数（ch06）
- **加权平均数** — 考虑权重的平均数（ch06）
- **中位数** — 排序后中间位置的数（ch06）
- **众数** — 出现次数最多的数（ch06）
- **方差** — 衡量数据波动大小的统计量（ch06）
