# 案例：龙岩八年级三角形校本作业分层修订

**日期：** 2026年6月27日
**背景：** 根据2022版新课标和CLTA学教评一致性理念，对龙岩市校本作业第13章《三角形》进行分层设计修订

## 原始问题

| 问题 | 严重程度 |
|:-----|:---------|
| 每节缺少学习目标 | 🔴 P0 |
| 三层练习定位不精准（基础/提高/挑战） | 🔴 P0 |
| 核心素养体现不足，缺联系实际的题目 | 🟡 P1 |
| 答案缺解析（仅给结果） | 🟡 P1 |
| 课前测聚焦有偏差 | 🟢 P2 |
| 缺学生自评量规 | 🟢 P2 |

## 分层框架应用

按分层作业skill框架，将课后测三层重新校准：

| 层级 | 核心问题 | 题目特征 | 题量 |
|:-----|:---------|:---------|:----:|
| 基础题 | 学生会了吗？（保底） | 直接、标准、步骤清楚 | 2-3题 |
| 提高题 | 学生懂了吗？（纠偏） | 有变式、有干扰、有易错点 | 1-2题 |
| 挑战题 | 学生能迁移吗？（运用） | 情境新、条件变、开放 | 1题 |

## 实践案例对比

### 13.1 三角形的概念 · 原版

```
【基础题】1-4题（判断三角形类型、计算周长等）
【提高题】5-6题（分类讨论、找直角三角形等）
【挑战题】7-8题（数三角形个数规律）
```

### 修订后

```
【基础题——确认"会不会"】
保留原1-3题，聚焦"识别三角形类型、用符号表示"

【提高题——判断"懂不懂"】  
保留原4-5题，增加⚠️易错标注（等腰三角形分类讨论要验证三边关系）

【挑战题——检测"会不会迁移"】
改为联系实际：校园三角形花坛测量问题
（原来数三角形个数的题太偏技巧，不适合作为迁移题）

【新增】📊 自我评价量规
```

## 关键经验

1. **不是所有原「挑战题」都适合做迁移题** — 原挑战题是数三角形个数的规律题，实际上是纯数学技巧而非生活迁移。改为联系实际的花坛测量问题才符合分层skill框架。
2. **提高题必须暴露易错点** — 光换数字不够，要针对学生常见的错误认知设计。
3. **答案要标注⚠️易错点和💡解析** — 原答案只给结果，修订版增加了关键步骤解析。
4. **课前测改为诊断已有知识** — 原版直接考新知识（预习检测），改版测试与本课相关的旧知识。
